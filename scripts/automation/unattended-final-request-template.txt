最終稿として、ブログに貼り付ける本文だけを全文で再出力してください。

ルール:
- frontmatter は付けない (slug, title などの YAML は出さない)
- 本文の先頭に `# タイトル` (H1) を付けない
- 「ここから本文」「最終稿として」「以下、本文」「初稿」などのメタ文は一切付けない
- 説明・前置き・後置きを付けず、本文 Markdown だけを上から下まで一度に出す
- 末尾の `## 参考情報` セクションまで含めて完全な一本分を出す
- すまほん / smhn.info は本文・参考情報・リンク欄に絶対に出さない
- 報道・噂ベースであることが自然に分かる表現は本文の早めに残す
- ひまり・らぼまるの会話は短く自然に残す (1〜2 回まで)
- 表示用に残ってしまう Markdown 記号 (孤立した `**` や ```md / ```markdown フェンス) を残さない
- summary-box / check-box / table-card の中に H1〜H3 見出しを置かない

これを一度のメッセージで全文を出してください。
