# 保守系ニュースラボ — Xリブランド方向性メモ

## 1. ブランドの芯

- **名前**：保守系ニュースラボ
- **立ち位置**：保守系の視点でニュースを「整理し、深掘りする」メディア
- **温度感**：硬すぎず、軽すぎず。新聞より柔らかく、まとめサイトより丁寧
- **読者像**：政治に興味はあるが、専門用語や省略表現で離脱しがちな初心者〜中級者

## 2. メディアごとの役割

| メディア | 役割 | 文体 |
|---|---|---|
| ブログ | 整理母艦。腰を据えて読む長文記事 | 落ち着いた解説調 |
| YouTube | 入口。面白く、でもまじめに説明する | 親しみやすい語り口 |
| X | 更新通知＋短い論点整理＋導線 | 簡潔・箇条書き多め |

## 3. ブランドとして「やらない」こと

- 旧路線（二刀流／刀剣／武士など）のモチーフ、語彙、画像を**完全に切る**
- 政党ロゴ・政治家本人の写真をアイコン/ヘッダーに使わない（誤解されない距離感）
- 過剰な煽り見出し・断定（ファクトと印象を混ぜない）
- 旧アカウント時代のキャラ語尾・芸風を引きずらない

1. プロフィール上半分（表示名・@ID・ヘッダー・アイコン）を見ただけで、**「保守系ニュースの解説アカウント」**と一瞬で伝わる
2. 旧アカウントを知っている人が**「方針が変わった」と理解できる**（固定ポストで明示）
3. 初見ユーザーが**「何を発信しているか」を5秒で把握**できる
4. プロフィール文・固定ポストに**ブログとYouTubeへの導線**が含まれる
