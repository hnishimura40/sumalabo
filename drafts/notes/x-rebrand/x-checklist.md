## フェーズ1：旧アカウントのバックアップ（任意・推奨）

- [ ] 設定 → アカウント → データのアーカイブをリクエスト
- [ ] 旧プロフィール画像／ヘッダーをローカル保存
- [ ] 旧プロフィール文・自己紹介リンクをテキストで控える

## フェーズ2：プロフィール変更（順序厳守）

> 順序が大事。**画像 → 文字情報 → @ID → 固定ポスト**。先に @ID を変えるとリプ転送がズレるので最後に。

- [ ] ヘッダー画像を新しいものに差し替え
- [ ] アイコン画像を新しいものに差し替え
- [ ] 表示名を「保守系ニュースラボ」に変更
- [ ] プロフィール文を新文面に差し替え
- [ ] ウェブサイト欄にブログURLを設定
- [ ] 場所欄が旧路線を匂わせていたら削除 or 中立的なものに
- [ ] 誕生日／生年などが個人特定につながる場合は非公開設定を確認
- [ ] **@ID を `hoshu_newslab` に変更**（最後にやる）
  - 旧IDを他人に取られないよう、可能なら捨てアカで一時確保
  - 既存のリンクや埋め込みは旧IDのままだとリダイレクトされるが、永続保証はない

## フェーズ3：固定ポスト

## フェーズ4：プレビュー確認（自分で初見ユーザーになる）

- [ ] 表示名・アイコン・ヘッダー・プロフィール文・固定ポストが**5秒で「保守系ニュースの整理メディア」**と伝わるか
- [ ] 旧路線の痕跡が**プロフィール上半分**に残っていないか
- [ ] リンクをクリックしてブログに飛べるか

## ブラウザ操作の注意点

- **勝手な投稿・削除・公開操作はしない**：このリブランドでは Claude 側から自動で送信しない
- 画面操作は人間が実行する。Claude は手順提示と文面提供まで
- 変更ごとに「保存」ボタンの押し忘れに注意（特にプロフィール編集画面）
- @ID変更後、ブラウザの履歴／ブックマークから古いURLで開くと404になる
- 2段階認証の確認コードが入る変更項目があるので、スマホは手元に
