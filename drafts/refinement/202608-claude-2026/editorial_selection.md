# Editorial Selection

## 読者翻訳設計

- 主題の一言説明: Claudeは、日本語で質問や文章作成ができる会話型AIで、無料から試せるが、仕事で使うなら料金だけでなく入力データと回答確認のルールも必要になる。
- 関係がある人: 日本語でメール、要約、議事録、企画の下書きを作りたい人。部署や会社で生成AIの導入を考える人。
- あまり関係がない人: すでに別の生成AIで用途と社内ルールが固まっており、Claudeを追加する予定がない人。AIへ文書を入力しない人。
- 専門用語:
  - Claude → Anthropicが提供する会話型AI
  - 大規模言語モデル → 大量の文章から言葉のつながりを学び、質問への回答や文章作成を行う仕組み
  - ベンチマーク → 同じ問題を解かせて性能を比べる試験
  - シークレットチャット → 履歴やモデル改善への利用を抑えて会話する機能
- 事実から言えること: 日本語は公式サポート対象で、日本語の入力・出力は設定なしでも始められる。個人向けは無料からあり、有料プランは利用量が増える。仕事ではプラン別のデータ条件と確認工程が重要。
- 事実から言えないこと: 日本語なら常に正しい、敬語をそのまま送信できる、特定プランなら固定回数使える、すべての会社で同じ削減効果が出る、とは言えない。

## 採用

1. 会話言語と画面表示の違い。
2. 日本語性能の公式評価と、その数字の読み方。
3. Free / Pro / Max / Teamの現在の料金表。
4. 個人利用での始め方と、日本語を安定させる短い指示。
5. 仕事で使う前の3点: 入力データ、正確さの確認、社内ルール。
6. 個人向けと商用サービスでデータ条件が異なる点。

## 限定採用

1. 日本企業の活用事例: 「活用が進んでいる」程度の背景にとどめ、成果数字を一般化しない。
2. 多言語ベンチマーク: 日本語対応の裏付けとして使うが、日常業務の正解率とは説明しない。
3. APIや開発者向け設定: 詳細実装は省き、「アプリ側で日本語を指定できる」とだけ説明する。

## 不採用

1. 第三者サービスの宣伝部分。
2. 公式確認が難しい「日本語ならそのまま業務投入できる」という強い評価。
3. 為替換算した固定の日本円価格。
4. 現在の公式案内と食い違うTeam最低5名の条件。
