- トーン：やさしい・整理型・不安を煽らない

  - 1枚1テーマ

## fig1：7月7日までと7月8日以降の違い

### レイアウト構成
- 上部：大見出し
- 中央：左右2カラム比較
  - 左：7月7日まで
  - 右：7月8日以降
- 下部：注意書きボックス
- ひまり：左側で「今はサブスクで使えるの？」と疑問
- らぼまる：右側で「7/8以降はcredits確認だよ」と整理

### 掲載する文字・数値

#### 大見出し
7/7まで：サブスク内  
7/8以降：usage creditsへ

#### 左カラム
7月7日まで

- Pro / Max / Team / 一部Enterprise
- サブスク枠内でも利用可能
- ただし週次上限の最大50%まで

#### 右カラム
7月8日以降

- 公式説明上、usage credits経由へ
- credits設定が関係する可能性
- 実画面は切り替え後に確認

#### 注意書き
7/8以降の表示・支払い画面は実際の切り替え後に確認が必要

### ひまり / らぼまるの役割
- ひまり：読者の最初の疑問を代弁する。「サブスクならそのまま使えるんじゃないの？」
- らぼまる：左右比較を指しながら、「7/7まで」と「7/8以降」を分けて整理する。

### ビジュアル案
- 背景は白〜淡いブルー系
- 左カラムは「今までの枠」、右カラムは「切り替え後の枠」
- 中央に矢印「7/8以降」
- 実在ロゴは使わず、抽象的なAIアイコン・チケット風アイコンで表現

# サムネイル計画

## 選ぶ型

B. 変化実感型

## 理由
今回の記事は、Fable 5そのものの性能紹介ではなく、「7月7日まで」と「7月8日以降」で利用体験が変わることが主題。

そのため、概念説明図よりも、ひまりが「いつものように使おうとしたら、切り替え表示に気づく」場面を描く方がクリック前に内容が伝わりやすい。

感情は「戸惑い」に絞る。  
不安や怒りに寄せすぎず、「あれ、何が変わるの？」という軽い戸惑いにする。

## サムネ仕様

- サイズ：16:9 横長 1600×900
- 方針：体験図
- 実在ロゴ：入れない
- 実在UIコピー：入れない
- 感情：戸惑い、1つに絞る
- 文字：短い1フレーズのみ

## サムネの短い文字案

第一候補：

7/8から何が変わる？

第二候補：

Fable 5、使い方変更？

第三候補：

サブスク枠に注意

## 推奨文字

7/8から何が変わる？

理由：
- 日付の切り替えが一目で伝わる
- 煽りすぎない
- usage creditsという難しい言葉をサムネ上で無理に出さず、本文へ誘導できる
- 実際に知りたい疑問と一致する

## 構図案

### 全体構図
左右分割の体験シーン。

左側：
ひまりがノートPCまたはタブレットでFable 5を使おうとしている。  
画面には実在UIではなく、抽象的なAIチャット画面。  
ひまりは少し戸惑った表情。

右側：
らぼまるが小さなホワイトボードを持って、  
「7/7まで」と「7/8以降」の切り替えを指し示す。  
ただし、サムネ上の文字は増やさず、ホワイトボードは図形と矢印中心。

中央：
大きな矢印またはカレンダー演出で「7/7 → 7/8」を表現。  
ここは文字ではなく、日付カードとして視覚化。

上部または左上：
短い文字  
「7/8から何が変わる？」

### 画面内の抽象UI
実在UIコピーは避け、以下のような抽象表示にする。

- AIチャット風の吹き出し
- 残り枠ゲージ
- creditsカード風アイコン
- チェックマーク
- カレンダー「7/8」

表示してよい短い抽象語：
- Usage
- credits
- 50%
- 7/8

ただし、サムネ全体の文字は増やしすぎない。  
メインコピーは「7/8から何が変わる？」のみを優先。

## ひまり / らぼまるの役割

### ひまり
読者の体験役。

- いつものようにAIを使おうとする
- 画面の変化に気づいて戸惑う
- 表情は「軽い戸惑い」
- 不安・怒り・大げさな驚きにはしない

### らぼまる
整理役。

- ひまりの横で切り替えポイントを示す
- ホワイトボードやカードで「7/7 → 7/8」を整理
- 課金を煽るのではなく、「まず確認しよう」という雰囲気

## NG表現

- 実在するClaudeロゴやAnthropicロゴを入れる
- 実在UIをそのまま模写する
- 「使えなくなる！」と断定する
- 「強制課金」など不安を煽る言葉を使う
- 感情を複数入れる
  - 戸惑い＋怒り＋安心などを混ぜない
- 3要点カードを並べすぎて、サムネを説明図に戻す
- 「無制限」「無料で使える」など本文が約束していない表現を入れる

## サムネ生成用プロンプト案

16:9 1600×900。  
すまラボのキャラクター「ひまり」と「らぼまる」を使ったYouTubeサムネイル風イラスト。  
テーマは「Claude Fable 5の7/8切り替え前に、ひまりがAIチャット画面の変化に気づいて少し戸惑っている場面」。  
概念説明図ではなく、キャラクターが実際に体験している絵にする。  

左側に、金髪の高校生くらいの女の子「ひまり」。ノートPCまたはタブレットの前で、抽象的なAIチャット画面を見ながら、軽く戸惑った表情。  
右側に、小さなラボ助手マスコット「らぼまる」。小さなホワイトボードを持ち、日付カード「7/7 → 7/8」と、抽象的なcreditsカードを指し示している。  
中央にカレンダーが切り替わるような矢印演出。  

文字は最小限。大きく「7/8から何が変わる？」のみ。  
実在ロゴ、実在UIのコピー、実在サービス画面の模写は入れない。  
不安を煽らず、感情は「戸惑い」ひとつに絞る。  
明るく読みやすいテック系サムネイル。背景は淡いブルーと白を基調に、スマホやAIニュース系の記事らしい清潔感のあるデザイン。  
情報カードを詰め込みすぎず、キャラクターの体験シーンを主役にする。
