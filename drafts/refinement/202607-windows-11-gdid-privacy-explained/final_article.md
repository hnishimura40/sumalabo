# Windows 11のGDIDとは？「VPNでも隠せない指紋」の誤解を整理

公開用最終稿は `content/articles/202607-windows-11-gdid-privacy-explained.mdx` と同内容。核は次の4点。

1. GDIDは実在し、Windowsインストール単位に結び付く永続ID。
2. 訪問先サイトに直接見えるWeb指紋ではなく、Microsoft内部の記録。
3. 今回はMicrosoft記録を捜査機関が複数事業者の記録と照合した事案。
4. 日常利用は今日から変わらないが、Microsoftの一般向け説明不足は正当な批判対象。

事実関係、構成、参考URL、本文は公開用MDXを正本とする。
