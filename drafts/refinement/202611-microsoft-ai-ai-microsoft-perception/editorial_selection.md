# Editorial Selection｜Microsoft Perceptionの一般提供

判定: 限定採用

**カテゴリ**　ニュースをかみくだく  
**根拠資料**　[Research Pass（2026年11月21日、日本時間）](research_report.md)

## 採用する切り口

**Microsoft Perceptionが職場の警告をどう仕分け、どこで人が判断するのか。** 会社などの組織で、AIが警告の仕分けや調査、対処の優先順位付けをどう支援するのかを軸にする。複数のAIが作業を分担し、影響の大きい操作には担当者の承認を組み込む仕組みを伝える。公式発表に基づくニュース解説として扱う。[Microsoft Security Blog](https://www.microsoft.com/en-us/security/blog/2026/11/17/security-for-the-agentic-era-powered-by-microsoft-perception/)

**今取り上げる理由**　8月に試験提供が始まった製品について、Microsoftが米国時間11月17日に一般提供を発表した。日本語の公式発表は11月18日付、ITmediaの報道は11月20日付。製品の提供段階が変わったことで、正式に提供された作業と試験段階にある機能の違いを具体的に説明できる。関心の広がりは、引き継ぎ資料では確認できていない。[Microsoftの7月発表](https://blogs.microsoft.com/blog/2026/07/27/rethinking-security-for-the-age-of-ai/)、[日本語の公式発表](https://news.microsoft.com/source/asia/features/microsoft-ignite-2026-empowering-human-ambition-intelligence-and-trust/?lang=ja)、[ITmedia NEWS](https://www.itmedia.co.jp/news/article/2611/20/2000003368/)

**答える疑問**　「AIは職場に届く警告をどう扱うのか」「担当者はどの段階で判断するのか」「一般提供の発表で、職場や自宅の使い方は変わるのか」。警告が届いた場面を起点に、仕分け、調査、対処の順番、人による承認の関係を示す。日本の職場で実際に使えるかは、契約や使いたい機能の提供状況を確かめる判断につなげる。[Microsoft Security Blog](https://www.microsoft.com/en-us/security/blog/2026/11/17/security-for-the-agentic-era-powered-by-microsoft-perception/)、[公式製品ページ・FAQ](https://www.microsoft.com/en-us/security/business/microsoft-perception-agentic-system)

## 論点の取捨選択

- **採用**　製品全体の一般提供と、機能ごとの提供状況。警告の仕分け、攻撃の調査、対処の優先順位付けを一般提供の例にする。一部の機能は試験提供中だと添える。役割は作業の内容で示し、担当の色名や個別機能名の列挙は省く。[Microsoft Security Blog](https://www.microsoft.com/en-us/security/blog/2026/11/17/security-for-the-agentic-era-powered-by-microsoft-perception/)、[Ignite 2026の公式発表資料](https://news.microsoft.com/events/ignite/2026/book-of-news/)
- **限定採用**　「AIによるサイバー攻撃にAIで対抗する」は、攻撃の自動化や高速化をMicrosoftが開発背景に挙げたという範囲で扱う。見出しと冒頭は、組織でAIに任せられる作業と人が承認する範囲を中心にする。[Microsoft Security Blog](https://www.microsoft.com/en-us/security/blog/2026/11/17/security-for-the-agentic-era-powered-by-microsoft-perception/)、[ITmedia NEWS](https://www.itmedia.co.jp/news/article/2611/20/2000003368/)
- **限定採用**　組織のMicrosoft Defenderの管理画面が利用の入口で、利用量に応じて料金がかかる。日本での開始日、対象契約、機能ごとの利用条件、日本語対応の範囲、データの処理・保存場所、円建て単価は、引き継ぎ調査で確認できた範囲を明示する。他社サービスとの連携は作業や機能によって条件が異なるため、対応製品の一覧は省く。[公式製品ページ・FAQ](https://www.microsoft.com/en-us/security/business/microsoft-perception-agentic-system)、[日本語の公式発表](https://news.microsoft.com/source/asia/features/microsoft-ignite-2026-empowering-human-ambition-intelligence-and-trust/?lang=ja)
- **不採用**　「攻撃の約80％を防げる」「AIを使った攻撃を見分けられる」「導入すれば被害や対応時間が減る」という切り口。約80％は、Microsoftが調べた約800万件の警告のうち、仕分けの対象に入った割合。防御効果の根拠にはならず、記事の主題にも不要なため数値は省く。新しいAIモデルの発表、性能比較、人気の高まりを主題にする根拠も確認できていない。[Microsoft Community Hubの集計注記](https://techcommunity.microsoft.com/blog/perception-blog/whats-new-with-microsoft-perception-at-ignite-2026/4571834)、[Ignite基調講演の公式記録](https://news.microsoft.com/events/wp-content/uploads/2026/11/Nadella_TRANSCRIPT_Ignite-Keynote_Nov-2026.pdf)

## 読者翻訳設計

### 主題の一言説明

会社などに届く危険の知らせをAIが仕分けて調べ、担当者が対応する順番を決めやすくするサービスが正式に提供される。

### 関係がある人

会社や学校などで、職場の端末やシステムを管理し、警告を調べる担当者。導入を検討する場合は、いま人が行っている作業のうち何を任せられるか、どの操作に誰の承認が要るか、自組織の契約で使えるかが判断材料になる。

### あまり関係がない人

自宅のパソコンやスマホを使い、職場のシステム管理を担当していない人。この発表を受けて、個人の設定や契約をすぐに見直す必要はない。

### 公開本文で使う専門用語

- Microsoft Perception → 職場のシステムを守るため、警告の仕分けや調査を手伝うMicrosoftのサービス
- AI → 情報の特徴を読み取り、分類や判断の手助けをする技術
- AIエージェント → 警告の仕分けなど、役割を割り当てると決められた手順に沿って作業を進めるAI
- サイバー攻撃 → パソコンやネット上のサービスに侵入したり、情報を盗んだり、使えなくしたりする行為
- 警告 → 不審な動きが見つかったときに、担当者へ届く知らせ
- 一般提供 → 対象の契約や環境で、製品を正式に使える段階
- 試験提供 → 正式に使えるようにする前に、条件を満たす利用者が機能を試せる段階
- Microsoft Defender → 職場のパソコンなどに不審な動きがないかを監視し、担当者に知らせるMicrosoftの製品
- 管理画面 → 職場のシステムの状態や設定を担当者が確認する画面
- 承認 → 操作を実行してよいかを、権限のある担当者が確認して許可すること

### 事実から言えること

- Microsoftは製品の一般提供を発表した。警告の仕分けや対処の優先順位付けなど、正式に提供された機能がある。一部の機能は試験提供の段階にある。
- AIは弱点の発見、警告の仕分けや調査、対応順の整理を分担する。組織が定めた条件で作業を進め、影響の大きい操作には人による承認を組み込む。
- 組織のMicrosoft Defenderの管理画面から利用し、料金は利用量に応じてかかる。日本語の公式発表でも一般提供が告知された。

### 事実から言えないこと

- 日本語での発表だけでは、日本の各組織がいつ、どの契約で使えるか、日本語でどこまで使えるか、データをどこで扱うか、円建てでいくらかかるかは判断できない。
- 製品の一般提供という発表だけでは、個々の機能や他社サービスとの連携を利用できるかは判断できない。
- 警告の仕分けに対応する範囲から、攻撃側のAI利用を判別できるか、実際に攻撃をどの程度防げるか、被害や対応時間がどのくらい減るかは判断できない。
