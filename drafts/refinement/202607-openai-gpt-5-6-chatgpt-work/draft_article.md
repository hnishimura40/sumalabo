## ChatGPT Workとは？OpenAIの新機能で何が変わるのか

OpenAIが発表した「ChatGPT Work」は、ChatGPTを“質問に答えるAI”から“作業を進めるAI”へ近づける新機能です。

> **出所メモ**
> 確認日：2026年7月10日
> 主な確認先：OpenAI公式発表、OpenAI Help Center、ChatGPT Businessページ、ITmedia AI＋など。
> 価格、対象プラン、提供地域、提供時期、利用上限は変わりやすい情報です。公開前に公式ページで再確認してください。

---

## 先に結論

ChatGPT Workは、調査・資料作成・表計算・プレゼン作成などを、ChatGPT上で進めやすくする新しい作業モードです。

要点は3つです。

- **ChatGPTが「答える」だけでなく、作業の流れまで進める方向に変わった**
- **Codexの技術が入り、Chat / Work / Codex の役割分担がはっきりした**
- **ただし、全プラン・全端末で同じように即使えるわけではない**

OpenAIは、ChatGPT Workを「アプリやファイルをまたいで作業し、目標を完成物に近づけるエージェント」と説明しています。WorkはGPT-5.6で動き、複数ステップの作業や、テンプレート・参考ファイルに沿った成果物づくりを強化する位置づけです。

---

## 何が起きたのか

今回の発表で大きいのは、ChatGPTに「Work」という作業向けの入口が加わったことです。

これまでのChatGPTは、質問する、文章を整える、アイデアを出す、といった使い方が中心でした。
ChatGPT Workでは、そこから一歩進んで、資料を作る、表をまとめる、スライドを作る、Webサイトや軽いアプリのようなものを作る、といった「完成物」まで意識した使い方が前面に出ています。

OpenAI公式発表では、ChatGPT WorkはWeb、モバイル、デスクトップをまたいで作業できると説明されています。さらに、デスクトップ版ではローカルファイルやアプリを、ユーザーの許可を得たうえで使えるとされています。

つまり、ニュースの本質は「新しいボタンが増えた」ではありません。
**ChatGPTが、会話アプリから作業アプリへ近づいた**ことがポイントです。

---

## なぜ話題なのか

話題になっている理由は、ChatGPTとCodexの境目がかなり近づいたからです。

Codexは、もともとコード作成や開発作業に強いAIエージェントです。
今回のChatGPT Workでは、そのCodex由来の技術が組み込まれ、コードを書かない作業にも広がってきました。

OpenAIは、Codex技術を組み込むことで、ChatGPTがWeb、モバイル、デスクトップをまたいで「質問に答える」以上の作業をこなせるようになると説明しています。一方で、Codex自体は開発者や技術職向けのコーディングエージェントとして残ります。

ITmedia AI＋も、OpenAIがChatGPTとCodexを統合した「ChatGPT Work」を発表し、GPT-5.6シリーズを搭載すると報じています。ただし、「Codexが完全になくなる」とまでは公式情報からは言えません。

---

## Chat / Work / Codex はどう違う？

ここが一番混乱しやすいので、まずは役割で見るのが分かりやすいです。

| 種類 | ざっくり言うと | 向いていること |
|---|---|---|
| Chat | 聞く・相談する場所 | 質問、調べもの、文章の下書き、アイデア出し |
| Work | 作業を進める場所 | 調査、資料作成、表、スライド、レポート、Sites |
| Codex | 開発を進める場所 | コード作成、修正、テスト、レビュー、リポジトリ作業 |

OpenAI Help Centerでは、デスクトップ版でWorkとCodexを切り替えられること、モバイル版ではChatとWorkを切り替えられる一方、Codexは直接選択するものではないことが説明されています。

ここは、次のように考えると整理しやすいです。

- **Chat**：まず聞きたいとき
- **Work**：何かを作ってほしいとき
- **Codex**：コードや開発まわりを進めたいとき

> **ひまり：** Workって、ChatGPTが勝手に全部仕事してくれるってこと？
> **らぼまる：** そこまでは言いすぎだよ。作業は進めやすくなるけど、確認や承認は人間側に残るよ。

## Codex統合で何が変わる？

Codex統合の意味は、「開発者向けだった作業エージェントの考え方が、資料作成や調査にも広がる」ということです。

Codexは、単にコードを1回返すだけではなく、ファイルを見たり、差分を確認したり、テストしたり、複数ステップの作業を進めるための仕組みです。
ChatGPT Workでは、この考え方が、文書・表・スライド・レポートなどの作成にも広がります。

たとえば、次のような使い方が想定されます。

- 会議メモや資料をもとに、要点を整理する
- 複数ファイルを見ながら、報告書のたたき台を作る
- SlackやGmail、Google Driveなどの情報を使って作業を進める
- 表計算やプレゼン資料の形にまとめる
- Sitesで、簡単なWebページやダッシュボードにする

OpenAIは、ChatGPT WorkがSlack、Microsoft Teams、Google Drive、SharePoint、メール、カレンダー、CRMなどのツールと連携できると説明しています。接続した情報をもとに、文書、デッキ、分析などを作れるとされています。

ただし、ここで大事なのは「何でも勝手に見られる」ではないことです。
連携にはユーザーや組織側の接続・許可が必要で、特に仕事で使う場合は情報管理のルール確認が欠かせません。

## デスクトップ版・Web版・スマホ版で何が違う？

ChatGPT Workは複数の端末で使える方向ですが、できることは同じではありません。

| 使う場所 | できることのイメージ | 注意点 |
|---|---|---|
| Web版 | Workを使って調査や成果物作成を進める | 対象プランや展開状況に左右される |
| スマホアプリ | 外出先でタスク開始、確認、ドラフト確認など | PC作業と同じことが全部できるとは限らない |
| デスクトップ版 | Chat / Work / Codexを1つのアプリで使える | ローカルファイルやアプリの扱いは許可と環境次第 |

OpenAIは、新しいChatGPTデスクトップアプリでChat、Work、Codexをまとめると説明しています。デスクトップ版では、Workがユーザーの許可を得てローカルファイルやデスクトップアプリを使える点が大きな違いです。

ここは誤解されやすいところです。
「スマホでもWorkが使える」ことと、「スマホだけでPC版と同じ作業が全部できる」ことは別です。

スマホでは、外出先で確認する、タスクを始める、進捗を見る、といった使い方が中心になりそうです。
本格的なファイル操作や開発作業は、やはりデスクトップ版の意味が大きくなります。

---

## 対象プランと提供時期は？

対象プランは、Web・モバイルとデスクトップで分けて見る必要があります。

OpenAI公式発表では、Web・モバイル版のChatGPT Workは、まずPro、Enterprise、Edu向けに展開され、PlusとBusinessには数日以内に広がるとされています。
一方、新しいChatGPTデスクトップアプリでは、Chat、Work、CodexがFreeを含むすべてのプランで使えると説明されています。

| 区分 | 公式発表での扱い |
|---|---|
| Web / モバイル版Work | Pro、Enterprise、Eduから開始。Plus、Businessへ順次展開 |
| デスクトップ版 | Freeを含む全プランでChat / Work / Codexを利用可能 |
| 利用上限 | 作業量により変動。複雑な作業ほどプラン内の利用枠を多く使う可能性 |
| 反映タイミング | アカウントやプランにより差が出る可能性 |

ここで注意したいのは、**「Freeを含む全プラン」と「全員が同じ条件で無制限に使える」は別**という点です。

OpenAIは、ChatGPT Workは通常のチャットより長く複雑な作業を想定しているため、利用の仕組みが異なり、作業量によってプラン内の利用枠を多く使う場合があると説明しています。

## GPT-5.6搭載はどう見ればいい？

GPT-5.6は、ChatGPT Workを支える新しいモデル群として見ると分かりやすいです。

OpenAIは、GPT-5.6をSol、Terra、Lunaの3つのモデル階層として説明しています。Solは最上位、Terraは日常作業向けのバランス型、Lunaは高速・低コスト寄りのモデルという位置づけです。

ただし、この記事ではベンチマークの細かい数値まで深掘りしなくてよさそうです。
すまラボ読者向けには、次の理解で十分です。

| モデル | ざっくりした位置づけ |
|---|---|
| GPT-5.6 Sol | より重い作業・高品質な出力向け |
| GPT-5.6 Terra | 日常作業向けのバランス型 |
| GPT-5.6 Luna | 軽めの作業や高速処理向け |

OpenAI公式では、ChatGPT WorkとCodexにおいて、Free / GoユーザーはGPT-5.6 Terraにアクセスし、Plus、Pro、Business、EnterpriseユーザーはSol、Terra、Lunaを選べると説明されています。

つまり、GPT-5.6搭載は大きなニュースですが、読者目線では「名前が変わった」よりも、**長めの作業や成果物づくりが強化された**と捉える方が実用的です。

## 日本では使える？日本語対応は？

日本向けには、「日本は対応国。ただし、Workの反映はアカウントやプラン次第」と書くのが安全です。

OpenAIのHelp Centerでは、ChatGPTの対応国・地域リストにJapanが含まれています。
また、ChatGPTの対応言語一覧にはJapaneseも含まれています。

そのため、日本からChatGPTを使うことや、日本語でChatGPTを使うこと自体は、公式情報上は対応しています。
ただし、ChatGPT Workの全機能が日本の全アカウントに同時に表示されるとは限りません。

記事では、次のように書くのがよさそうです。

> 日本はChatGPTの対応国に含まれ、日本語も対応言語に含まれています。
> ただし、ChatGPT Workの表示時期や使える機能は、プラン、端末、アカウントごとのロールアウト状況によって変わる可能性があります。

これなら、日本読者に必要な安心材料と、誤解を防ぐ注意点の両方を入れられます。

## 確定情報・報道ベース・未確定を分ける

ここを分けておくと、ニュース記事として読みやすくなります。

| 区分 | 内容 |
|---|---|
| 確定情報 | OpenAIがChatGPT Workを発表。WorkはGPT-5.6で動く。Chat / Work / Codexを分けて使う方向。デスクトップ版ではChat / Work / Codexを1つのアプリにまとめる。 |
| 報道ベース | ITmediaなどは、ChatGPTとCodexを統合した「ChatGPT Work」と報道。デスクトップ版の大幅刷新として扱っている。 |
| 未確定・注意 | 日本の全アカウントでいつ表示されるか。日本語環境で全機能がどこまで同じように使えるか。Freeプランでどこまで実用的に使えるか。 |

この整理で大事なのは、**報道の見立てやユーザーの期待を、公式に確定した事実として書かないこと**です。

たとえば、「CodexがWorkに完全吸収された」と書くと強すぎます。
公式には、Codex技術がWorkに組み込まれ、新しいデスクトップアプリでChat / Work / Codexがまとまる一方、Codexは開発向けモードとして残る説明になっています。

## 誤解されやすいポイント

ChatGPT Workは便利そうに見えますが、いくつか誤読しやすい点があります。

チェックしておきたいのは、次の5つです。

- **無料プランで全部使えるわけではない**
- **全ユーザーに同じタイミングで表示されるとは限らない**
- **Web版・スマホ版・デスクトップ版でできることは違う**
- **Codexが消えたわけではない**
- **AIに任せれば確認不要、という話ではない**

特に注意したいのは、デスクトップ版の「Freeを含む全プラン」と、Web・モバイル版の段階展開が別の話であることです。
この2つを混ぜると、「全プランで今日から全部使える」と誤解しやすくなります。

また、ChatGPT Workは長めの作業を進めやすくするものですが、完成物の内容確認は必要です。
資料、数値、社内情報、顧客情報を扱う場合は、AIが作ったものをそのまま使わず、必ず人が確認する前提で考えた方が安全です。

## 誰に関係ある？

ここからは、読者判断のための補助情報です。

ChatGPT Workが特に関係ありそうなのは、仕事や学習で「調べて、まとめて、形にする」作業が多い人です。

| 関係度 | 当てはまる人 |
|---|---|
| 高い | 資料作成、レポート、表計算、プレゼン作成が多い人 |
| 高い | ChatGPT Plus / Pro / Businessなどを仕事で使っている人 |
| 高い | Codexを使っている開発者、または開発に近い作業をしている人 |
| 中くらい | スマホやWebでChatGPTをよく使う人 |
| 低め | たまに質問するだけの人、無料プランで軽く使うだけの人 |

逆に、ChatGPTをたまに検索代わりに使う程度なら、すぐに使いこなす必要はありません。
まずは、Chat、Work、Codexの違いを知っておくだけでも十分です。

## すまラボ的に見ると、何が大きい？

今回のポイントは、AIアプリの選び方が「どのAIが賢いか」だけではなくなってきたことです。

これまでは、ChatGPT、Gemini、Claudeなどを比べるとき、どうしても「回答の賢さ」や「文章の自然さ」に注目しがちでした。
でも、ChatGPT Workのような機能が出てくると、見るべきポイントが少し変わります。

これからは、次のような視点が大事になります。

- 自分の使っているアプリやファイルとつながるか
- スマホ、Web、PCで作業を続けやすいか
- 下書きだけでなく、資料や表まで作れるか
- 会社や学校の情報を安全に扱えるか
- 無料プランと有料プランで何が違うか

つまり、AI選びは「賢いAIを選ぶ」から、**自分の作業に合うAIを選ぶ**方向に変わっていきそうです。

これは、スマホ選びにも少し似ています。
スペックだけでなく、写真、電池持ち、使うアプリ、料金、サポートまで含めて選ぶのと同じです。

## いま急いで使うべき？

結論としては、仕事でChatGPTをよく使う人は早めに確認、軽く使うだけなら様子見で十分です。

次のように判断すると分かりやすいです。

| あなたの使い方 | 判断 |
|---|---|
| ChatGPTで毎週のように資料や文章を作っている | 早めに確認する価値あり |
| Plus / Pro / Businessを契約している | 自分の画面にWorkが出ているか確認 |
| PCでファイルを使った作業が多い | デスクトップ版の意味が大きい |
| スマホでたまに質問するだけ | 急がなくてよい |
| 会社の機密情報を扱う | 先に社内ルール確認が必要 |

特に会社で使う場合は、便利さだけで判断しない方がよいです。
Gmail、Slack、Drive、SharePointなどと接続できるということは、裏返すと、扱う情報の範囲が広がるということでもあります。

## まとめ

ChatGPT Workは、ChatGPTを「聞くAI」から「作業を進めるAI」へ近づけるアップデートです。

今回の発表で押さえるべきポイントは、次の3つです。

- **ChatGPT Workは、調査・資料作成・表・スライドなどの成果物づくりに寄った機能**
- **Codexの技術が入ったが、Codex自体は開発向けとして残る**
- **使える範囲はプラン、端末、提供タイミング、日本でのロールアウト状況によって変わる**

日本はChatGPTの対応国に含まれ、日本語も対応言語に含まれています。
ただし、「日本でも全員がすぐ全部使える」とは言い切れません。

まずは、自分の使っているプランと端末でWorkが表示されるかを確認する。
そのうえで、資料作成や調査、表づくりなど、自分の作業に本当に役立つかを見ていくのがよさそうです。
