## ChatGPT Workとは？OpenAIの新機能で何が変わるのか

OpenAIが発表した「ChatGPT Work」は、ChatGPTを“質問に答えるAI”から“作業を進めるAI”へ近づける新しい機能です。

> **出所メモ**
> 確認日：2026年7月10日
> 主な確認先：OpenAI公式発表、OpenAI Help Center、ChatGPT料金・提供ページ、ChatGPTリリースノート、ITmedia AI＋など。
> 価格、対象プラン、提供地域、提供時期、利用上限は変わりやすい情報です。公開前に公式ページで再確認してください。

## 先に結論

ChatGPT Workは、調査・資料作成・表計算・プレゼン作成などを、ChatGPT上で進めやすくする作業向けの新機能です。

要点は3つです。

- **ChatGPTが「答える」だけでなく、作業の流れまで進める方向に変わった**
- **Chat / Work / Codex の役割分担がはっきりし、Codexの技術もWorkに組み込まれた**
- **ただし、全プラン・全端末で同じように即使えるわけではない**

今回のポイントは、ChatGPTが“返答するAI”から、資料や表づくりまで進める“作業の入口”に近づいたことです。OpenAIはChatGPT Workを、アプリやファイルをまたいで作業し、必要なら数時間かけてプロジェクトに付き合い、目標を完成物に近づけるエージェントとして説明しています。

## 何が起きたのか

今回の発表で大きいのは、ChatGPTに「Work」という作業向けの入口が加わったことです。

これまでのChatGPTは、質問する、文章を整える、アイデアを出す、といった使い方が中心でした。
ChatGPT Workでは、そこから一歩進んで、資料を作る、表をまとめる、スライドを作る、Webページのような成果物を作る、といった「形にする作業」が前面に出ています。

OpenAI公式ページでは、ChatGPT Workはスライド、シート、ドキュメント、Sitesなどを、アプリやワークフローから作れると説明されています。ここでいうSitesは、簡単なWebページやダッシュボードのような成果物と考えると分かりやすいです。

つまり、ニュースの本質は「新しいボタンが増えた」ではありません。
**ChatGPTが、会話アプリから作業アプリへ近づいた**ことがポイントです。

## なぜ話題なのか

話題になっている理由は、ChatGPTとCodexの関係がかなり近づいたからです。

Codexは、もともとコード作成や開発作業に強いAIエージェントです。
今回のChatGPT Workでは、そのCodex由来の技術が、コードを書かない作業にも広がってきました。

ただし、ここは誤解しやすいところです。
**Codexが消えた**という意味ではありません。

OpenAI Help Centerでは、Workは調査や成果物づくり、Codexはソフトウェア開発向けとして説明されています。つまり、WorkとCodexは近づきましたが、役割は分けて見る必要があります。

ITmedia AI＋も、OpenAIがChatGPTとCodexを統合した「ChatGPT Work」を発表し、GPT-5.6シリーズを搭載すると報じています。ただし、報道で「統合」と表現されていても、公式情報上はCodexが開発向けの役割として残る点に注意が必要です。

## Chat / Work / Codex はどう違う？

まずは、Chat、Work、Codexを「何に使う場所か」で分けると分かりやすくなります。

| 種類 | ざっくり言うと | 向いていること |
|---|---|---|
| Chat | 聞く・相談する場所 | 質問、調べもの、文章の下書き、アイデア出し |
| Work | 作業を進める場所 | 調査、資料作成、表、スライド、レポート、Sites |
| Codex | 開発を進める場所 | コード作成、修正、テスト、レビュー、リポジトリ作業 |

OpenAI Help Centerでは、Workは調査や成果物づくり、Codexはソフトウェア開発向けとして説明されています。新しいデスクトップ版ではChat、Work、Codexを1つのアプリ内で扱う方向が示されています。

整理すると、こうです。

- **Chat**：まず聞きたいとき
- **Work**：何かを作ってほしいとき
- **Codex**：コードや開発まわりを進めたいとき

> **ひまり：** Workって、ChatGPTが勝手に全部仕事してくれるってこと？
> **らぼまる：** そこまでは言いすぎだよ。作業は進めやすくなるけど、確認や承認は人間側に残るよ。

## Codex統合で何が変わる？

Codex統合の意味は、開発者向けだった「複数ステップで作業を進めるAI」の考え方が、資料作成や調査にも広がることです。

Codexは、単にコードを1回返すだけではなく、ファイルを見たり、差分を確認したり、テストしたり、複数ステップの作業を進めるための仕組みです。
ChatGPT Workでは、この考え方が、文書・表・スライド・レポートなどの作成にも広がります。

たとえば、次のような使い方が想定されます。

- 会議メモや資料をもとに、要点を整理する
- 複数ファイルを見ながら、報告書のたたき台を作る
- 表計算やプレゼン資料の形にまとめる
- 簡単なWebページやダッシュボードのような成果物を作る
- 対応する接続機能や権限がある場合、SlackやGoogle Driveなどの情報を使って作業を進める

OpenAI公式ページでは、ChatGPT Workがチームのツールから文脈を集め、散らばったメモや下書き、アイデアを完成物に近づけると説明されています。

ただし、「接続できる」と「どんな情報でもすぐ見られる」は別です。
会社のファイル、顧客情報、個人情報を扱う場合は、接続前に社内ルールや管理者設定を確認する必要があります。

## デスクトップ版・Web版・スマホ版で何が違う？

ChatGPT Workは複数の端末で使える方向ですが、できることや反映タイミングは同じではありません。

| 使う場所 | できることのイメージ | 注意点 |
|---|---|---|
| Web版 | Workを使って調査や成果物作成を進める | 対象プランや段階展開の影響を受ける |
| スマホアプリ | 外出先でタスク開始、確認、ドラフト確認など | PC版と同じ作業が全部できるとは限らない |
| デスクトップ版 | Chat / Work / Codexを1つのアプリ内で扱う | ローカルファイルやアプリの扱いは許可と環境次第 |

OpenAIのリリースノートでは、新しいChatGPTデスクトップアプリがChat、Work、Codexを1つにまとめると説明されています。また、Plugin Directoryにも触れられており、WorkやCodexを含む作業環境の整理が進んでいます。

ここは誤解されやすいところです。
「スマホでもWorkが使える」ことと、「スマホだけでPC版と同じ作業が全部できる」ことは別です。

スマホでは、外出先で確認する、タスクを始める、進捗を見る、といった使い方が中心になりそうです。
本格的なファイル操作や開発作業は、デスクトップ版の意味が大きくなります。

## 対象プランと提供時期は？

対象プランは、デスクトップ版とWeb・モバイル版を分けて見る必要があります。

OpenAIのChatGPT Workページでは、デスクトップ版は全プラン向けに提供され、Web・モバイル版はPlus、Pro、Business、Enterprise、Eduへ数日かけて展開されると説明されています。

ただし、Help Centerでは、ChatGPT Workは対象アカウントへ段階的に展開されており、まだ表示されない場合はアカウントにアクセス権が来ていない可能性があると説明されています。

| 区分 | 公式情報上の扱い |
|---|---|
| デスクトップ版 | 全プラン向けに提供。ただし利用できる内容や上限はプラン・アカウントで異なる可能性 |
| Web / モバイル版 | Plus、Pro、Business、Enterprise、Eduへ順次展開 |
| Freeプラン | デスクトップ版で対象に含まれるが、使える範囲や上限は限定される可能性 |
| 反映タイミング | アカウントやプランにより差が出る可能性 |

大事なのは、**「全プラン向け」と「すべての利用者が同じ条件で無制限に使える」は別**という点です。

無料プランでも表示される可能性はありますが、有料プランと同じ作業量・同じモデル・同じ上限で使えるとは限りません。
画面に出ているか、どのモデルが選べるか、どこまで作業できるかは、自分のアカウントで確認する必要があります。

## GPT-5.6搭載はどう見ればいい？

GPT-5.6は、ChatGPT Workを支える新しいモデル群として見ると分かりやすいです。

OpenAIはGPT-5.6について、難しい作業に対する能力を高め、より必要な場面で大きな性能を出せるモデル群として説明しています。モデル名としては、Sol、Terra、Lunaが示されています。

すまラボ読者向けには、細かいベンチマークよりも、次の理解で十分です。

| モデル | ざっくりした位置づけ |
|---|---|
| GPT-5.6 Sol | より重い作業・高品質な出力向け |
| GPT-5.6 Terra | 日常的な作業向けのバランス型 |
| GPT-5.6 Luna | 軽めの作業や高速処理向け |

ITmedia AI＋も、ChatGPT WorkがGPT-5.6シリーズを搭載すると報じています。

ここで注意したいのは、GPT-5.6のAPI料金と、ChatGPTの月額プラン料金を混同しないことです。
API料金は開発者向けの利用料金であり、ChatGPT WorkをChatGPTアプリ上で使うときのプラン料金とは別に見る必要があります。

## 日本では使える？日本語対応は？

日本向けには、「日本は対応国。日本語も対応言語。ただしWorkの反映はプランやアカウント次第」と見るのが安全です。

OpenAI Help CenterのChatGPT対応国リストにはJapanが含まれています。また、ChatGPTの言語設定ヘルプでは、対応言語の一覧にJapaneseが含まれています。

そのため、日本からChatGPTを使うことや、日本語でChatGPTを使うこと自体は、公式情報上は対応しています。
ただし、ChatGPT Workの全機能が日本の全アカウントに同時に表示されるとは限りません。

記事内では、次のように理解しておくのが安全です。

> 日本はChatGPTの対応国に含まれ、日本語も対応言語に含まれています。
> ただし、ChatGPT Workの表示時期や使える機能は、プラン、端末、アカウントごとのロールアウト状況によって変わる可能性があります。

「日本でも使える可能性がある」と「日本のすべての利用者がすぐ全部使える」は別です。
ここは、かなり大事な注意点です。

## 確定情報・報道ベース・未確定を分ける

ニュースを見るときは、公式に確認できること、報道の見立て、まだ分からないことを分けると誤解しにくくなります。

| 区分 | 内容 |
|---|---|
| 確定情報 | OpenAIがChatGPT Workを発表。Workはアプリやファイルをまたいで作業し、資料・表・スライド・Sitesなどの成果物づくりに使う方向。Chat / Work / Codex の役割もHelp Centerで分けて説明されている。 |
| 報道ベース | ITmediaなどは、ChatGPTとCodexを統合した「ChatGPT Work」と報道。GPT-5.6シリーズ搭載や、デスクトップ版の大幅刷新として扱っている。 |
| 未確定・注意 | 日本の全アカウントでいつ表示されるか。日本語環境で全機能がどこまで同じように使えるか。Freeプランでどこまで実用的に使えるか。 |

この整理で大事なのは、**報道の見立てや期待を、公式に確定した事実として書かないこと**です。

たとえば、「CodexがWorkに完全吸収された」と書くと強すぎます。
公式情報では、Workは調査や成果物づくり、Codexはソフトウェア開発向けとして説明されています。

## 誤解されやすいポイント

ChatGPT Workは便利そうに見えますが、いくつか誤読しやすい点があります。

チェックしておきたいのは、次の5つです。

- **無料プランで全部使えるわけではない**
- **全ユーザーに同じタイミングで表示されるとは限らない**
- **Web版・スマホ版・デスクトップ版でできることは違う**
- **Codexが消えたわけではない**
- **AIに任せれば確認不要、という話ではない**

特に注意したいのは、デスクトップ版の「全プラン向け」と、Web・モバイル版の段階展開が別の話であることです。
この2つを混ぜると、「全プランで今日から全部使える」と誤解しやすくなります。

また、ChatGPT Workは長めの作業を進めやすくするものですが、完成物の内容確認は必要です。
資料、数値、社内情報、顧客情報を扱う場合は、AIが作ったものをそのまま使わず、必ず人が確認する前提で考えた方が安全です。

## 誰に関係ある？

ここからは、読者判断のための補助情報です。

ChatGPT Workが特に関係ありそうなのは、仕事や学習で「調べて、まとめて、形にする」作業が多い人です。

| 関係度 | 当てはまる人 |
|---|---|
| 高い | 資料作成、レポート、表計算、プレゼン作成が多い人 |
| 高い | ChatGPT Plus / Pro / Businessなどを仕事で使っている人 |
| 高い | Codexを使っている開発者、または開発に近い作業をしている人 |
| 中くらい | スマホやWebでChatGPTをよく使う人 |
| 低め | たまに質問するだけの人、無料プランで軽く使うだけの人 |

逆に、ChatGPTをたまに検索や相談に使う程度なら、すぐに使いこなす必要はありません。
まずは、Chat、Work、Codexの違いを知っておくだけでも十分です。

## この発表をどう見るべき？

この発表は、AI選びが「どのAIが賢いか」だけではなくなってきたことを示しています。

これまでは、ChatGPT、Gemini、Claudeなどを比べるとき、回答の自然さや文章のうまさに注目しがちでした。
でも、ChatGPT Workのような機能が出てくると、見るべきポイントが少し変わります。

これからは、次のような視点が大事になります。

- 自分の使っているアプリやファイルとつながるか
- スマホ、Web、PCで作業を続けやすいか
- 下書きだけでなく、資料や表まで作れるか
- 会社や学校の情報を安全に扱えるか
- 無料プランと有料プランで何が違うか

つまり、AI選びは「賢いAIを選ぶ」から、**自分の作業に合うAIを選ぶ**方向に変わっていきそうです。

これは、スマホ選びにも少し似ています。
スペックだけでなく、写真、電池持ち、使うアプリ、料金、サポートまで含めて選ぶのと同じです。

## いま急いで使うべき？

仕事でChatGPTをよく使う人は早めに確認、軽く使うだけなら様子見で十分です。

次のように判断すると分かりやすいです。

| あなたの使い方 | 判断 |
|---|---|
| ChatGPTで毎週のように資料や文章を作っている | 早めに確認する価値あり |
| Plus / Pro / Businessを契約している | 自分の画面にWorkが出ているか確認 |
| PCでファイルを使った作業が多い | デスクトップ版の意味が大きい |
| スマホでたまに質問するだけ | 急がなくてよい |
| 会社の機密情報を扱う | 先に社内ルール確認が必要 |

特に会社で使う場合は、便利さだけで判断しない方がよいです。
Gmail、Slack、Drive、SharePointなどと接続できる可能性があるということは、扱う情報の範囲が広がるということでもあります。

## まとめ

ChatGPT Workは、ChatGPTを「聞くAI」から「作業を進めるAI」へ近づけるアップデートです。

今回の発表で押さえるべきポイントは、次の3つです。

- **ChatGPT Workは、調査・資料作成・表・スライドなどの成果物づくりに寄った機能**
- **Codexの技術が入ったが、Codex自体は開発向けとして残る**
- **使える範囲はプラン、端末、提供タイミング、日本でのロールアウト状況によって変わる**

日本はChatGPTの対応国に含まれ、日本語も対応言語に含まれています。
ただし、「日本でもすべての利用者がすぐ全部使える」とは言い切れません。

まずは、自分の使っているプランと端末でWorkが表示されるかを確認する。
そのうえで、資料作成や調査、表づくりなど、自分の作業に本当に役立つかを見ていくのがよさそうです。
