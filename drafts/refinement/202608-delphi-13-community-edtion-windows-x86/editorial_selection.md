# Editorial Selection: Delphi 13 Community Edition

## 採用する事実

- Delphi 13 Community Editionが公式ダウンロードページで提供されている。
- CEは12.1からFlorence世代へ更新された。
- 公式CEページはAndroid 15、iOS 18、ネイティブ64-bit IDE、64-bit language server、分割エディター、Focus Mode、コードナビゲーション改善を挙げる。
- Windows、macOS、Android、iOS向けアプリを単一コードベースから開発できる。
- IDE自体はWindows環境が前提で、Mac／iOS向けではMacやXcode等が別途必要になる。
- KaiはCEに含まれず、対応もしない。
- 無料でも商用利用条件があり、年間5,000 USドルや開発者人数、企業PC利用などの制限がある。

## 限定採用する主張

- 「フル機能」は、主要なIDE・デバッガ・デザイナーを備えるという意味に限定する。有料版と完全同等とは書かない。
- 「Windows x86／Arm対応」はスカウト見出しとして紹介せず、CE公式ページで明示確認できた範囲だけを書く。Windows on ArmはCEで実物確認が必要と注記する。
- 公式FAQの「最新12.1」は更新遅れの可能性が高いが、公式内の表示差として伝え、理由は断定しない。

## 不採用にする主張

- CE 13がRAD Studio 13.1の全機能を含むという断定。
- CE 13でAndroid 16、iOS 26、Windows on Armが必ず使えるという断定。
- MacだけでDelphi IDEを直接動かせるという受け取り方。
- 無料なので企業でも自由に評価・研修・業務利用できるという説明。

## 記事の軸

「無料版が13へ更新された」という朗報を入口にしつつ、読者がインストール前に迷いやすい3点、すなわち対応OSの読み分け、ライセンス資格、Kai非対応を整理する。ニュースの要約だけで終わらせず、「自分は使えるか」「何を別途用意するか」「どこまで公式確認できたか」を判断できる記事にする。

カテゴリは「ニュースをかみくだく」。実機検証ではないため「やってみた・検証」にはしない。確定・要確認を視覚的に分け、公式FAQの旧表記も隠さず示す。

## 読者翻訳設計

- 主題の一言説明: アプリを作るためのソフトDelphiに、条件付きで使える新しい無料版が出た話
- 関係がある人: 趣味でアプリを作りたい人、Delphiを学びたい学生、旧無料版の利用者、条件内の小規模開発者
- あまり関係がない人: Windowsやスマホで完成済みのアプリを使うだけの人、開発予定がない人
- Delphi → Windowsパソコンでプログラムを書き、アプリを作るための開発ソフト
- Community Edition → 学生や趣味の開発者などが条件内で使える無料版
- IDE → 入力、動作確認、間違い探しを一つの画面で行うアプリ作りの作業場
- language server → 入力補完やエラーチェックを裏側で手伝う仕組み
- 単一コードベース → 基本となる一つのプログラムから複数の端末向けアプリを作り分ける考え方
- Kai → コード作成やエラー修正をAIで手伝うDelphiの開発支援機能
- ARM → 一部のWindowsパソコンやスマホで使われるCPUの設計方式
- Feature Manager → Delphiへ追加する機能や対象端末を選ぶ設定画面
- 事実から言えること: Delphi 13 CEの提供、64bit IDE等、4OS向け開発、Kai非対応、利用条件
- 事実から言えないこと: CEが13.1の全機能を含むこと、Windows on Arm等が無料版で必ず使えること
