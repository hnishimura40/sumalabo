# editorial_selection

## 採用（記事の骨子になるもの）

| 項目 | 判断理由 |
|---|---|
| Claude Science は公式発表済みの実在サービス | 噂ではなく公式発表なので、記事の前提として最初に明確化する必要がある。 |
| Claude Science は「新しいAIモデル」ではなく研究者向けワークベンチ | 読者が最も誤解しやすい点なので、記事の中心に置くべき。 |
| 対象は科学者・研究者・研究室向け | 日常利用のAIアプリではないことを整理するために必須。 |
| 何ができるかの大枠 | 論文分析、データ解析、図表作成、研究履歴の管理などをかみ砕いて説明するとニュースの意味が伝わる。 |
| macOS / Linux 向け beta アプリで、スマホ向け機能ではない | すまラボ読者にとって「自分が今すぐ使うものか」を判断する材料になる。 |
| Pro / Max / Team / Enterprise ユーザー向け | 提供形態は重要だが、料金表の細部より「有料プラン前提」と伝える程度でよい。 |
| 医療診断AIではない | 「AIで病気が診断できる」「薬がすぐできる」といった誤解を避けるために重要。 |
| AIがチャット相手から作業環境へ広がっている流れ | 研究者向けニュースを、AI利用者にも関係ある大きな流れとして意味づけできる。 |

## 限定採用（軽く触れるだけ）

| 項目 | 判断理由 |
|---|---|
| Python / R / shell を実行できる | 具体例としては有用だが、詳しく書くと開発者・研究者向けに寄りすぎる。 |
| genomics、proteomics、structural biology などの専門分野 | 「かなり専門的」と伝える材料にはなるが、分野名の深掘りは不要。 |
| 3Dタンパク質構造や化学構造の表示 | 研究ツールらしさを示す例として軽く触れれば十分。 |
| provenance / 再現性管理 | 研究では重要だが、読者向けには「どのデータやコードで作ったかを残せる」と言い換える程度でよい。 |
| レビューエージェント | 「間違いチェックを助ける仕組みがある」程度で十分。過信させない書き方が必要。 |
| Windows は WSL 2 経由 | 対応環境の補足として軽く触れる程度。主題にはしない。 |
| 研究室向け割引プラン | すまラボ読者には直接関係が薄いので、価格欄の補足にとどめる。 |
| 外部計算リソースの Modal 課金 | 専門的なので、追加費用が発生しうる例として必要なら一文だけ。 |
| Anthropic が創薬プログラムを始めるという報道 | 話題性はあるが公式発表とは分け、報道ベースとして短く扱う。 |
| AI創薬はまだ時間がかかるという専門家コメント | 煽りを避ける注意点として有用だが、記事の主役にはしない。 |
| 日本での提供条件 | 未確定扱いとして「公式ページで要確認」と軽く触れる。 |

## 不採用（すまラボ記事には入れない）

| 項目 | 判断理由 |
|---|---|
| 研究分野ごとの詳細解説 | 読者の関心から離れやすく、記事が専門メディア寄りになる。 |
| HPC、SSH、Linux box など計算環境の細部 | 研究者向けの実装情報で、すまラボ記事の読みやすさを下げる。 |
| Modal の詳しい設定や課金構造 | 日常利用の判断には不要で、記事の焦点がぼやける。 |
| 料金プランの細かい比較表 | Claude Scienceの記事ではなくClaude契約比較記事になってしまう。 |
| 研究室向けプランの対象条件の詳細 | 一般向け記事では優先度が低い。 |
| Beta導入企業・研究機関の効率向上コメントの深掘り | 宣伝色が強くなりやすく、第三者検証された成果として扱いにくい。 |
| 「AIで薬がすぐ作れる」方向の見出し・構成 | 未確定要素が大きく、すまラボの信頼性を下げる。 |
| スマホで使える新AI機能のような見せ方 | 公式情報とズレるため不採用。 |

## 記事の狙い

Claude Science は、日常的にスマホやアプリでAIを使う人が今すぐ使う新機能ではなく、研究者向けの専門的なAI作業環境であることを整理する。  
そのうえで、AIが「質問に答えるチャット」から「専門作業を進めるワークベンチ」へ広がっている流れを、誤解なく持ち帰ってもらう。
