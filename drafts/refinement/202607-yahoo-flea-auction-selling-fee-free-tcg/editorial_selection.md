# editorial_selection

## 記事の編集方針

- **カテゴリ:** ニュースをかみくだく
- **記事タイプ:** 流入記事
- **hands-on:** なし
- **主軸:** キャンペーンの紹介ではなく、「実質無料」の正しい意味とサービスごとの条件差を整理する
- **読者判断:** 「誰に得か」は結論ではなく、記事後半の補助情報として扱う
- **最重要ポイント:** 手数料が最初から無料になるのではなく、条件を満たすと後日PayPayポイント（期間限定）で還元される

## 限定採用

ニュースの理解を助けるが、主軸にはしない情報。本文の補足、注意書き、囲み欄などで短く扱う。

| 情報 | 判定 | 採用理由・扱い方 |
|---|---|---|
| 付与されるのはPayPayポイント（期間限定） | 限定採用 | 還元方法の核として本文には入れるが、ポイント制度の細部までは広げない |
| ポイントの利用先はLINEヤフーグループの一部サービスやPayPay／PayPayカード公式ストアに限られる | 限定採用 | 「どこでも使えるポイントではない」という注意として短く触れる |
| ポイントには用途制限がある | 限定採用 | 誤解防止には必要だが、利用可能店舗の詳細一覧までは扱わない |
| Yahoo!フリマの出品上限が30万円から1,000万円未満へ拡大 | 限定採用 | 同時発表された関連アップデートとして、本文後半か補足欄に置く |
| 出品上限の拡大はアプリで順次リリース | 限定採用 | 全利用者に一斉反映ではないことを示す一文だけ入れる |
| 高額トレカも出品しやすくなる可能性がある | 限定採用 | 公式発表内容から読み取れる意味づけとして、断定を避けて扱う |
| 対象カードを期間中に売る予定がある人にはメリットがある | 限定採用 | 「誰に得か」の補助情報として記事後半に置く |
| 期間限定ポイントを使い切れる人ほど恩恵を受けやすい | 限定採用 | 条件から導ける読者判断だが、確定事実とは分けて書く |
| Yahoo!オークションで鑑定付き出品を利用できる人に向く | 限定採用 | オークション利用者向けの判断材料として短く扱う |
| 対象外ブランドを売る人には直接のメリットがない | 限定採用 | 「対象者・対象外」の整理で一文程度にとどめる |
| 現金還元を期待する人には向かない | 限定採用 | ポイント還元の性質を理解させる補助として使う |
| フリマとオークションの条件比較表 | 限定採用 | 文章だけでは違いが分かりにくいため、短い比較表として採用する |
| 「誰に得か」の整理 | 限定採用 | 主軸ではないため、記事後半の「こんな人は確認する価値あり」に限定する |
| 出品上限拡大とキャンペーンを同じ施策として見せる | 限定採用 | 同時アップデートだが制度は別なので、明確に分けて紹介する |

## 記事内での優先順位

### 最優先で伝える

1. 2026年8月9日までの期間限定キャンペーン
2. 対象は5ブランドのトレカ
3. エントリーが必要
4. 手数料は一度発生する
5. 後日PayPayポイント（期間限定）で全額相当が還元される
6. Yahoo!オークションは「鑑定付き」が必須

### 次に伝える

1. Yahoo!フリマとYahoo!オークションでは条件が違う
2. 出品しただけでは対象にならず、売却・落札成立が必要
3. ポイントには利用先の制限がある
4. 現金が返ってくるキャンペーンではない

### 補足にとどめる

1. Yahoo!フリマの出品上限が30万円から1,000万円未満へ拡大
2. アプリで順次リリース
3. どのような人がメリットを受けやすいか
4. 未確認の詳細条件は公式キャンペーンページで確認が必要

## 記事で避ける見せ方

- 「トレカの販売手数料が無料」と見出しだけで断定する
- PayPayポイントを現金と同じように扱う
- すべてのトレカが対象であるように見せる
- Yahoo!フリマとYahoo!オークションを同一条件としてまとめる
- Yahoo!オークションの「鑑定付き」を小さな注意書きだけで済ませる
- 出品すれば自動的に還元されるように書く
- 出品上限拡大をキャンペーン条件の一部として混同する
- 未確認の還元上限、付与日、有効期限を推測で補う
- 「今売らないと損」と過度に急かす
- トレカ投資や相場予測の記事へ広げる

## 最終的な記事の芯

> Yahoo!フリマとYahoo!オークションで対象トレカの手数料が「実質無料」になるキャンペーンが始まった。ただし、手数料が最初からなくなるわけではなく、エントリーなどの条件を満たすと、後日PayPayポイント（期間限定）で還元される仕組み。特にYahoo!オークションは「鑑定付き」での出品が必要な点に注意したい。
