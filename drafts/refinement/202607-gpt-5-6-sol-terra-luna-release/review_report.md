# Review Report — GPT-5.6 一般公開（Sol / Terra / Luna）

ChatGPT（すまラボ台本・記事チャット 6a506358）によるセルフレビュー。初稿 draft_article.md に対する指摘一覧。

重要度：高｜該当箇所：「一般公開までに時間がかかった理由」
「政府協議や追加テストが、公開まで時間を要した理由だった」と因果関係を断定する見出しになっています。確定しているのは公開までの経緯です。
修正案： 見出しを「一般公開までの経緯」または「6月26日のプレビューから一般公開まで」に変更する。

重要度：高｜該当箇所：導入「日本でもすべてのユーザー画面に同時に反映されるわけではない」
24時間の段階ロールアウトは確定していますが、日本国内での具体的な反映状況は未確定です。現状の文章でも大きな誤りではないものの、日本での表示差まで確定事項のように読めます。
修正案： 「日本のユーザー画面でも、アカウントによって反映時期が異なる可能性があります。具体的な反映時刻は確認できていません」と、未確定であることを明示する。

重要度：中｜該当箇所：「最上位のSolは、複雑な作業を長く考えながら進める用途を重視したモデルです」
「長く考える」は主に新機能のmax推論モードの説明であり、Sol本体の定義と混ざっています。Solの確定した特徴は、最上位モデルであり、コーディング・サイバー・科学分野で最高水準という点です。
修正案： 「Solは、コーディング、サイバー、科学分野を重視した最上位モデルです。その能力をさらに引き出すモードとしてmaxとultraが用意されています」と分ける。

重要度：中｜該当箇所：「公開時点で最高水準とされています」
確定factsではTerminal-Bench 2.1の88.8％がSOTAとされています。「最高水準」でも意味は通りますが、どの範囲での最高なのかがややぼやけています。
修正案： 「Terminal-Bench 2.1で88.8％を記録し、同ベンチマークでSOTAとされています」と、評価対象を限定する。

重要度：中｜該当箇所：「ultraは、複数のサブエージェントを並列で動かし、作業を分担させる仕組みです」
「作業を分担させる」は分かりやすい一方、公式説明を一歩広げた解釈です。また、「Sol Ultra」が独立モデルなのか、Solのモードなのかを誤解する余地があります。
修正案： 「ultraは、サブエージェントを並列に動かす推論モードです。別モデルではなく、Solをより強く動かすためのモードとして整理できます」と補足する。

重要度：中｜該当箇所：「Terraが中心的な選択肢になる可能性があります」
断定は避けられていますが、「中心的」という評価には根拠が不足しています。記事の主軸は事実整理なので、この推測は少し強めです。
修正案： 「最高性能を必要としない場合は、性能と価格のバランスを取りやすい選択肢です」と、確定した特徴の範囲に留める。

重要度：中｜該当箇所：「誤解しやすいポイント」全体
「全プランで即日使えるわけではない」はケアできています。一方で、「SolだけがGPT-5.6ではない」という重要な誤解への注意が、冒頭以外ではやや弱いです。
修正案： この節に「GPT-5.6はSolだけを指す名称ではなく、Sol・Terra・Lunaの3モデル構成です」を明記する。

重要度：中｜該当箇所：「利用できるモデルは契約プランによって異なります」
正しいものの、ChatGPT上のプラン差とAPIでのモデル選択が一緒に見えやすいです。APIでは価格を選んで使う構造であり、ChatGPTの契約プランとは整理軸が異なります。
修正案： 「ChatGPTでは契約プランによって使えるモデルが異なります。一方、APIでは用途と価格に応じて3モデルを選びます」と分ける。

重要度：低｜該当箇所：「GPT-5.5と同等の性能を、APIでは約半分の価格で利用可能」
factsとの整合は取れています。ただし、「何に対して約半額なのか」が表だけでは少し曖昧です。
修正案： 確定情報の表現に合わせ、「GPT-5.5と同等の性能を、GPT-5.5のおよそ半分のAPI価格で提供」と比較対象を明記する。比較対象が公式文言で特定されていない場合は、現状の表現を維持する。

重要度：低｜該当箇所：API価格表
Solの5ドル／30ドル、Terraの2.5ドル／15ドル、Lunaの1ドル／6ドルはすべて指定factsと一致しています。円換算も混入していません。
修正案： 数値修正は不要。「100万トークンあたり」「入力／出力」の条件を表の直前または見出しにも残す。

重要度：低｜該当箇所：Terminal-Benchの記述
Sol 88.8％からSol Ultra 91.9％という数値は整合しています。ただし、文章が離れているため「同じベンチマークでの比較」であることをもう少し明確にできます。
修正案： 同一ベンチマークでの比較であることを明示する。

重要度：低｜該当箇所：前報への内部リンク
公開時には「発表時点の全体像はこちら」など、リンク先を読む理由が分かる短いアンカーテキストにする。

判定: 禁則語・円換算・GPT-6憶測の混入なし。数値はすべてfacts一致。高2件・中6件・低4件を最終稿で反映する。
