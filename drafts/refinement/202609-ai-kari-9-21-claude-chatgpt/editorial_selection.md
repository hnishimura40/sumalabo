# editorial_selection.md — Kari記事のEditorial Selection

出所: research_report.mdをもとに編集判断。

## 採否

採用。デスクトップ上のファイル・表計算・ブラウザー操作をAIにまとめて頼める新しい選択肢で、既存のAIサブスクリプションを使えるという説明は読者の費用判断に直結する。ただし、実機検証ではないため、機能の実用性と安全性を断定しない。

## カテゴリと役割

- type: news
- category: ニュースをかみくだく
- 主軸: Kariの正体、できること、料金の二層構造、導入前の権限・データ確認

## 読者翻訳設計

- 主題の一言説明: パソコン内のファイルやブラウザーを、AIと一緒に扱えるデスクトップアプリが正式公開された話。
- 関係がある人: ClaudeやChatGPTをすでに契約し、PDFの要約、表計算、資料の下書き、ウェブでの定型作業をまとめたい人。100人未満の組織で試したい担当者。
- あまり関係がない人: スマホだけでAIを使う人、パソコン内のファイルやブラウザーをAIに触らせたくない人、社内規程で外部AIの利用を認められていない人。
- 専門用語:
  - デスクトップAIエージェント → パソコン上でファイルを読み、複数の操作を順番に進めるAIアプリ
  - API → アプリ同士が決められた方法で情報をやり取りする入口
  - MCP → AIが外部の道具やデータにつながるための共通ルール
  - ローカルファイル → 自分のパソコン内に保存している文書や表
  - プロバイダー → AIモデルや計算環境を提供する会社・サービス
  - ローカルLLM → 自分のパソコンや社内設備で動かす文章生成AI
- 事実から言えること: 正式提供日、対応OS、公式が示す機能、ライセンス区分、提供元が説明するサインイン方式。
- 事実から言えないこと: すべてのChatGPTプランで必ず使えること、API相当の機能が無制限に使えること、すべてのデータが外部へ出ないこと、実務で必ず自動化が成功すること。

## facts / claims / uncertain の採用

- facts: 提供開始日、対応OS、バージョン0.6.0、用途、コミュニティ／コーポレートの境界、無保証。
- claims: サブスク連携、認証情報を保持しない、ブラウザー自動化、レイアウト保持、70種類以上への対応。
- uncertain: 対象となるChatGPTプランの細部、モデル上限、法人価格、規約変更後の継続性、実性能。

## タイトル方針

「AIにPC作業を頼める入口が増えた。Kariは無料でどこまで使える？」を軸にする。無料だけを煽らず、AIサービス側の契約は別に必要だとサブと本文で落ち着かせる。
