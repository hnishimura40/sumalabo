## 漢字化け対策メモ（docs/kanji_pitfalls.md）
- 「使用量」「上限」「履歴」は可。難しければ「使った量」「残り枠」。数字は算用数字。
- 短いラベルはひらがな・和語を優先。「Claude / Fable / Claude Code / API」は英字のまま。実在ロゴは描かない。
- 金額（10ドル/50ドル・100万トークン）は「報道ベース」の注記を添え、煽りに使わない。
