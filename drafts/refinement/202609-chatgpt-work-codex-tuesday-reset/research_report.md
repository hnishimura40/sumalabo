# Research Report: ChatGPT Work・Codex火曜リセット予告

## facts

- 2026年9月22日、Tibo Sottiaux氏は「I promised a reset for Tuesday」と投稿した。
- 同投稿に方式名、対象者、時刻はない。
- banked resetを求める投稿への返信は「OK fine. But it's also still coming in Tuesday」。
- 「3am on a tuesday」の返信先は「the GPT-6 Community Night was 🔥」。
- OpenAI Docs PricingはChatGPT WorkとCodexが利用枠を共有すると明記している。
- OpenAI Docs App Serverはearned resetの利用可能数、付与時刻、有効期限、使用結果を扱う仕組みを記載している。

## claims

- Tibo氏の投稿時刻と「もうすぐ火曜日」という表現から、米国時間を意識している可能性が高い。
- banked reset要求への「OK fine」は、保存型リセットへの期待を生む文脈だが、指示語が曖昧で確定材料ではない。

## uncertain_points

- 今回がbanked resetかautomatic / global resetか。
- 対象プランと対象者。
- 正確な実施時刻。
- リセット対象となる利用枠。
- 「ほかにもいくつかある」の内容。
