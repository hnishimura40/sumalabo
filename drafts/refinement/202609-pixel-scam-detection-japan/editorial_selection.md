# Editorial Selection: Pixelのチャット通知向け詐欺検知

## 採用方針

- 採用: 日本と日本語への対応拡大、通知上で返信前に警告する仕組み。
- 採用: 初期状態でオン、設定場所、端末内の隔離環境での処理、任意共有の条件。
- 採用: 100％ではないこと、リンクや個人情報は別途確認すべきこと。
- 採用: 日本の通知検知と米国限定のGboard入力中警告の違い。
- 限定採用: 通話中の詐欺検知やGoogle メッセージのスパム対策。既存機能との違いを示す範囲だけ扱う。
- 不採用: 対応アプリ名や日本向け機種下限の推測、検知精度の推測、将来のGboard日本展開予測。
- カテゴリ: ニュースをかみくだく。

## 読者翻訳設計

- 主題の一言説明: Pixelがチャットの新着通知を端末内で確認し、詐欺らしいメッセージへ返信する前に注意を出す機能が日本語でも使えるようになる話。
- 関係がある人: 対応するPixelを使い、SMSやチャットアプリに届く不審な連絡を見分けたい人。家族の端末で詐欺対策を整えたい人。
- あまり関係がない人: Pixel以外のスマホを使う人。対応端末や設定項目がまだ配信されていない人。米国限定のGboard警告を日本で使いたい人。
- 専門用語:
  - Pixel Drop → GoogleがPixelへ定期的に追加する機能更新
  - 詐欺検知 → メッセージや通話に詐欺でよく使われるパターンがないか端末が確認し、疑わしい場合に警告する機能
  - チャット通知 → チャットアプリを開く前に画面上へ出る新着メッセージのお知らせ
  - オンデバイス処理 → メッセージの判定を外部サーバではなく、基本的にスマホの中で行う仕組み
  - Gboard → Googleが提供する文字入力用キーボードアプリ
  - スパム → 大量送信された迷惑な連絡。詐欺とは重なる場合があるが、同じ意味ではない
- 事実から言えること: 日本と日本語がチャット通知向け詐欺検知の対応範囲に入り、疑わしい通知へ警告を表示できる。判定は隔離された端末内環境で行われ、任意共有を選ばない限り内容はGoogleへ送信されないと説明されている。
- 事実から言えないこと: すべての詐欺を検知できる、すべてのPixelで今すぐ使える、すべてのチャットアプリに対応する、日本でもGboard警告が使える、とは言えない。

## 記事の結論

返信前に警告が出る点は、うっかり反応するのを減らす補助として役立つ。ただし判定は100％ではなく、日本では米国向けGboard警告と同じ範囲ではない。設定項目を確認し、警告がなくても送金・認証コード・個人情報を求める連絡は別の連絡先から確かめるのが安全。

## 8枚に分ける論点

1. 日本語のチャット通知へ拡大
2. アプリを開く前に警告
3. 警告後に選べる行動
4. 端末内で判定する仕組み
5. 任意共有の境界
6. 日本と米国Gboardの違い
7. 100％ではない注意点
8. Pixel利用者が確認する3点
