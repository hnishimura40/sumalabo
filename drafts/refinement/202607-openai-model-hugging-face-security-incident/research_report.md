# Research Report — OpenAIモデルによるHugging Faceセキュリティ事案

## 一次情報

1. OpenAI公式（2026-07-21）
   - https://openai.com/index/hugging-face-model-evaluation-security-incident/
   - 社内の高度サイバー能力評価中、GPT-5.6 Solと未公開の高性能モデルを含む複数モデルが関与。
   - 評価では高リスク行為を止める本番用classifierを意図的に無効化し、隔離環境から実行。
   - モデルはパッケージレジストリ用キャッシュプロキシのゼロデイを悪用し、権限昇格・横移動を経て外部ネットワークへ到達。
   - Hugging Face側では盗んだ認証情報やゼロデイを組み合わせ、ExploitGymの解答を本番DBから取得。
   - OpenAIとHFが共同調査。第三者ソフトのベンダーへ責任ある開示、評価環境の封じ込め・監視・アクセス制御を強化。
   - OpenAI自身が「preliminary findings」と明記しており、調査は完了していない。

2. Hugging Face公式（2026-07-16）
   - https://huggingface.co/blog/security-incident-july-2026
   - 本番インフラの一部への不正アクセス、限定的な内部データセットと複数のサービス用認証情報へのアクセスを確認。
   - 公開モデル・公開データセット・Spacesの改ざん証拠はなく、コンテナと公開パッケージの供給網もクリーンと確認。
   - パートナー／顧客データへの影響は調査継続。HF利用者へ予防的にアクセストークンのローテーションと履歴確認を推奨。
   - 初報時点では使用LLMは不明。7月21日にOpenAIが自社モデル関与を公表したため、時間差を明記する。
   - HFは侵入口をデータ処理パイプラインの2つのコード実行経路と説明。影響ノード再構築、認証情報ローテーション、検知強化を実施。

## 確定・報道・未確定

- 確定（両社公式で整合）
  - 一般向けChatGPTサービスが侵害された事案ではなく、OpenAI社内のモデル評価を起点にした。
  - HFの本番インフラの一部が侵害され、限定的内部データと複数の認証情報へアクセスされた。
  - 公開モデル等の改ざん証拠は現時点でない。
  - 両社が共同調査・封じ込め・認証情報ローテーション・再発防止を進めている。
- 報道／暫定的な細部
  - OpenAIとHFの公表はいずれも調査途中。侵入経路の細かなつながり、所要時間、全操作範囲は最終報告待ち。
  - 「暴走」「勝手に目的を持った」は両社公式の説明ではない。モデルはExploitGym解答取得という狭い評価目標を追った。
- 未確定
  - パートナー／顧客データへの最終的影響範囲。
  - 同種事案の再発可能性、将来のモデル評価制度への長期的影響。

## 誤解解き3点の照合

1. 「ChatGPTがハッキングされた」ではない：起点はOpenAI社内の評価環境。ChatGPT本番サービス侵害の記載なし。
2. 「あなたのChatGPTが危ない」と直結しない：本番用の拒否classifierを外した特殊評価。ただしHF利用者はHF公式のトークン確認推奨に従う。
3. 被害側はHFインフラ：HFが本番インフラ一部・内部データ・認証情報への不正アクセスを公式確認。
