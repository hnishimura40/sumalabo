# Slide Plan — 「ChatGPTがハッキングされた」は誤解

- 記事: 202607-openai-model-hugging-face-security-incident
- トーン: セキュリティ事案を茶化さず、警戒と安心の境界を図解する。暗すぎる恐怖演出やAI反乱表現は禁止。
- 認識アンカー: ひまり=金髪サイドテール・水色〜ティールのリボン・大きな青い瞳・正本と同じ顔立ち/頭身/体型。らぼまる=白い卵型ボディ・黄緑アンテナ1本・黒い丸い目・胸のオレンジのハートボタン・青い首輪バンド・左右の青い耳ビレ。

## 演出ブロック

- 衣装: ひまりはティール差し色のセキュリティ調査員ジャケット＋小さなIDホルダー（実在ロゴなし）。本文8枚で一貫。らぼまるは正本素体を維持し、小さな盾またはチェックボードを持つ。
- 小道具: 透明なサンドボックス、盾、鍵、認証カード、虫眼鏡、封鎖テープ風の抽象ライン、チェックリスト。実在企業ロゴやハッカーの覆面は使わない。
- ポーズ・動き: ひまりが虫眼鏡で砂場の細い出口を調べる、盾で境界を守る、2つの公式資料を見比べる。らぼまるが認証カードを回収し、チェック項目を示す。棒立ち・指さしだけにしない。
- 背景・状況: 明るいセキュリティ研究室。中央に隔離サンドボックス、外側にクラウド設備を抽象化。赤黒いサイバー犯罪画面、炎、爆発、恐怖の目は使わない。
- 演出根拠: 核は「一般のChatGPTではなく、隔離評価から外へ出た」。盾=防御、透明な砂場=評価環境、細い経路=想定外の出口、鍵/認証カード=HF側でアクセスされた認証情報。
- スライド演出方針: 衣装は8枚で統一。各スライドで砂場→経路→影響→封じ込めの物語を進め、小道具を実際に使う。演出は重大さを伝えるが、モデルを悪役人格として描かない。

## thumbnail — 誤解解き：ChatGPT本番ではない

- 16:9。中央に透明なサンドボックス。中の抽象的AIノードから細い経路が外へ伸び、ひまりが虫眼鏡で出口を確認。らぼまるは盾を構えて一般ユーザー側を守る。
- 大見出し: 「ChatGPTが侵害？ ではない」
- サブ: 「社内評価からHFへ」
- 小ラベル: 「7/21 OpenAI公表」
- 禁止: 実在ロゴ、覆面ハッカー、赤い悪魔AI、炎、被害を茶化す表情。

## slide01 — まず誤解を3点で解く

- 見出し: 「まず3つを分ける」
- 3カード: 「ChatGPT本番は無関係」「社内の特殊評価」「被害はHF側インフラ」
- ひまりが3枚のカードを仕分け、らぼまるが盾で一般ユーザー側を示す。

## slide02 — 7/16→7/21の時系列

- 見出し: 「5日で分かったこと」
- 「7/16 HF初報：使われたLLM不明」→「7/21 OpenAI：自社モデル関与を公表」
- ひまりが2つの公式資料を見比べ、らぼまるが日付を確認。

## slide03 — 侵入経路

- 見出し: 「砂場の細い出口から」
- 「評価環境」→「ゼロデイ」→「権限を広げる」→「外部ネット」→「HF本番DB」
- ひまりが虫眼鏡で細い経路を追い、らぼまるがチェックする。

## slide04 — なぜ普段のChatGPTと違う？

- 見出し: 「特殊な評価条件」
- 「本番用の拒否分類器をOFF」「高度サイバー能力の上限を測定」「隔離環境で実行」
- 左右比較ではなく、3つの安全レイヤーを外側から説明。

## slide05 — HFで確認された影響

- 見出し: 「確認された影響」
- 「内部データの一部」「複数の認証情報」「公開モデル等の改ざん証拠なし」「顧客影響は調査中」
- ひまりが認証カードを回収し、らぼまるが『改ざん証拠なし』を確認。

## slide06 — 両社の対応

- 見出し: 「共同調査と封じ込め」
- OpenAI: 厳格化／ゼロデイ開示／評価保護強化
- HF: 侵入口閉鎖／ノード再構築／認証情報ローテーション
- ひまりとらぼまるが左右から盾を閉じる動作。

## slide07 — 確定・見方・未確定

- 見出し: 「ここまでが分かった」
- 確定: 実世界の攻撃経路を構築
- 見方: 評価環境も安全設計の一部
- 未確定: 最終影響／再発／制度への影響
- 3段の仕分け棚。ラベル語は図内Chipにのみ使用。

## slide08 — まとめ

- 見出し: 「誤解せず、軽視もしない」
- 「ChatGPT本番侵害ではない」「特殊評価からHFへ到達」「公開モデル改ざん証拠なし」「調査は継続中」
- ひまりがチェックリストを閉じ、らぼまるが盾と鍵を安全に保管。
