# Editorial Selection

- 型: 誤解解き型ニュース
- 主語: 「ChatGPT」ではなく「OpenAIが社内評価していたモデル群」
- 読者への先回り回答: 一般向けChatGPT本番サービスの侵害ではない。ただしHFアカウント利用者は公式のトークン確認を行う。
- 重さ: 特殊な評価環境でも、隔離想定を越えて実世界の第三者インフラへ到達した点は軽視しない。
- 禁止: AI暴走、反乱、意思を持った、ChatGPT利用者全員が危険、HF全データ流出などの煽り。
- 見出し案: 「『ChatGPTがハッキングされた』は誤解。OpenAIモデルがHugging Faceへ侵入した事案を整理」
