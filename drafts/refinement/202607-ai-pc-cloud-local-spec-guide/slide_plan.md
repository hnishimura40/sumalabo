# slide_plan: AIを使うPC選び（全9枚）

## thumbnail（16:9）
「AIに高いPCは必要？」「ほとんどの人は10万円台で十分」。家電店で、ひまりが高価なゲーミングPCと普通の薄型ノートを見比べる。らぼまるは価格札の横。背後にクラウド計算機。

## slide01（4:5）クラウド型vsローカル型
「重い計算はどこで動く？」普通のノート→ネット→クラウド / 高性能GPU入りPC内でモデルが動く。「多くの人は左。右だけが別世界」。

## slide02（4:5）用途別早見
低=チャット・文章・ブログ・クラウド画像/音楽、中=Codex等・一般動画編集、高=重い動画編集・ローカル生成。CodexのAIはクラウド、手元のビルドはPC依存。

## slide03（4:5）効く順ピラミッド
メモリ16GB（多重作業は32GB）→画面→安定回線→SSD。GPUは用途が明確な人だけ。

## slide04（4:5）GPUとNPU
GPUは動画編集・3D・ローカル生成。Copilot+ PCは40 TOPS以上・16GB・256GB。「クラウドAIだけならNPU目的で急がない」。

## slide05（4:5）運用実例
「スペックの壁は2か所だけ」。クラウドでブログ・画像・動画素材。壁はローカル動画生成とWhisper高精度モデル。両方にクラウド代替。ロゴや順位を使わず宣伝調にしない。

## slide06（4:5）MacとWindows
MacBook Air=静か・操作・クラウドAI、Windows=価格・機種・ゲーム・業務ソフト。「ソフトと予算で選ぶ」。

## slide07（4:5）買い時
2026年4月平均約14.0万円・前月比+35%（GIGA反動含む）、5月ノート約13.4万円。必要な時が買い時。セール・型落ち・整備済みも。

## slide08（4:5）買い替えチェック
遅い原因 / クラウドかローカル / 16GB / 画面 / 回線 / SSD / GPU用途 / 時期。「AIという名前だけで高いPCを買わない」。
