# 日本通信「blue mobile」とは？格安SIMとの違いをやさしく整理

## 先に結論

日本通信の「blue mobile」は、**ドコモの通信網と日本通信の自社SIM・自社システムを組み合わせる新ブランド**です。

- サービス開始は**2026年11月24日を予定**
- 従来の格安SIMより、自社でサービスを設計できる範囲が広い
- **料金・データ容量・プラン名は未発表**で、他社より得かどうかはまだ判断できない

今回発表された中心は、完成した料金プランではなく、新ブランドの名称と通信サービスの土台です。

ahamo、povo、LINEMO、楽天モバイルなどから、今すぐ乗り換える必要はありません。料金やデータ容量、通話、eSIMなどの詳細が発表されてから比較すれば大丈夫です。

日本通信は、新しい通信サービスブランド「blue mobile」を発表し、2026年11月24日の提供開始を予定しています。

現時点で公式に確認できる主な情報は、次のとおりです。

日本通信は2026年7月27日、NTTドコモと音声通信網・SMS網の相互接続協定を締結したと発表しました。

ドコモの通信網と日本通信のシステムを接続し、音声通話、SMS、データ通信を含むサービスを提供する準備を進めています。

ただし、2026年11月24日は現時点での**予定日**です。料金やデータ容量などの詳細は、サービス開始に向けて順次発表するとしています。

## なぜ話題？「ネオキャリア」とは何か

blue mobileが注目されている理由は、日本通信が従来の格安SIMとは異なる「ネオキャリア」という位置づけを掲げているからです。

一般的な格安SIMは、大手通信会社の回線や通信設備の多くを借りてサービスを提供します。

blue mobileもドコモの基地局や電波を利用しますが、日本通信が自社のSIMやコアネットワークを活用し、自社で管理できる範囲を広げる構想です。

### 大まかな違い

| 種類 | 基地局・電波 | SIMやサービスの管理 | 特徴 |
|---|---|---|---|
| 一般的なMVNO | 大手通信会社から借りる | 借りる部分が多い | 比較的低価格なプランを提供しやすい |
| blue mobileの構想 | ドコモの通信網を利用 | 自社SIM・自社システムを活用 | 独自機能を設計できる余地が広い |
| MNO | 自社の基地局を中心に提供 | 自社で広く管理 | 通信網全体を管理しやすい |

「ネオキャリア」は、法律で新設された通信事業者の分類ではありません。

一般的なMVNOよりも自由度を高め、MNOに近いサービス設計を目指すという、日本通信が掲げる事業上の呼び方です。

## blue mobileの通信はどうつながる？

blue mobileは、ドコモの基地局や電波を利用しながら、SIMや一部の通信制御を日本通信側で管理する構成です。

スマホの通信には、基地局だけでなく、利用者の認証、SIMの管理、音声通話の制御、データ通信の振り分けなど、複数の仕組みが関係しています。

blue mobileの構成は、次のように整理できます。

1. スマホはドコモの基地局や電波につながる
2. ドコモのネットワークと日本通信のシステムを接続する
3. SIMや一部の通信サービスを日本通信側で管理する
4. 日本通信独自のプランや機能を設計する

全国に日本通信の基地局を新設するわけではありません。

一般的なMVNOより自社で管理できる範囲を広げることで、独自サービスを作りやすくするのが狙いです。

## フルMVNOで何ができるようになる？

フルMVNOの特徴は、料金の安さそのものではなく、SIMや通信サービスを自社で設計しやすいことです。

日本通信は自社でSIMを発行・管理できる仕組みを持ち、blue mobileでも自社SIMや自社コアネットワークを活用する方針を示しています。

公式資料などでは、今後可能になる機能の例として、次のような内容が挙げられています。

- 海外ローミング
- eSIM関連機能
- eSIMクイック転送
- 5G SA
- Wi-Fiを使った音声通話
- 利用者ごとに調整したデジタルサービス

ただし、これらは技術面での可能性や今後の構想です。

**2026年11月24日のサービス開始時から、すべて提供されると決まったわけではありません。**対象端末、料金、利用条件、提供時期なども未発表です。

## 誤解しやすい3つのポイント

blue mobileは新しい仕組みを掲げていますが、「新しいから速い」「独自機能があるから安い」とは限りません。

### 1. 自前の基地局を全国展開するわけではない

blue mobileは、ドコモの基地局や通信網を利用します。

楽天モバイルのように、自社の基地局を中心として全国向けの通信サービスを提供する仕組みとは異なります。

日本通信が自社で持つのは、主にSIMやコアネットワークなど、通信サービスを管理するための設備です。

### 2. ネオキャリアだから必ず速いわけではない

自社で管理できる範囲が広がっても、それだけで通信速度が速くなるとは限りません。

実際の通信品質には、ドコモとの接続容量、利用者数、混雑時の通信制御、利用する場所や時間帯などが関係します。

blue mobileの通信速度や混雑時の制御方針は未発表です。通信品質は、正式な仕様やサービス開始後の状況を確認する必要があります。

### 3. 海外ローミングなどがすぐ使えるとは限らない

自社SIMを持つことで、海外ローミングやeSIM関連機能を柔軟に提供できる可能性があります。

しかし、対象国、料金、対象端末、提供開始時期などは発表されていません。

技術的に実現できることと、実際のサービスとして提供されることは分けて見る必要があります。

## 確定・予定・構想・未発表を分けて確認

現時点のblue mobileは、新ブランドと通信の仕組みが発表された段階で、料金プランの詳細はこれからです。

| 区分 | 内容 |
|---|---|
| 確定 | ブランド名は「blue mobile」 |
| 確定 | 日本通信が提供する |
| 確定 | ドコモと音声・SMS網の相互接続協定を締結 |
| 確定 | 自社SIM・自社システムを活用する構成 |
| 予定 | 2026年11月24日にサービス開始 |
| 構想 | 海外ローミングやeSIM関連機能などを柔軟に提供 |
| 未発表 | 月額料金 |
| 未発表 | データ容量 |
| 未発表 | プラン名・プラン数 |
| 未発表 | 通話料金・かけ放題 |
| 未発表 | 通信速度・混雑時の制御 |
| 未発表 | 既存の日本通信SIMからの移行方法 |

特に重要なのは、**月額料金、データ容量、プラン名が未発表**であることです。

既存の日本通信SIMには低価格なプランがありますが、blue mobileが同じ料金路線になるとは限りません。

現時点では「新しい格安プランが発表された」ではなく、「新しいブランドと通信サービスの基盤が発表された」と捉えるのが正確です。

## ahamo・povo・LINEMOなどとの比較はまだ早い

料金やデータ容量が分からないため、blue mobileと既存サービスの本格的な比較はまだできません。

今後は、次のような軸で比べることになります。

| 比較対象 | 主な比較ポイント |
|---|---|
| ahamo | 容量、通話、海外利用、通信品質 |
| povo | トッピングの柔軟性、利用しない月の料金 |
| LINEMO | 小容量プラン、通信品質、各種特典 |
| 楽天モバイル | データ使用量、通話、対応エリア |
| 日本通信SIM | 月額料金、通話、移行条件 |

blue mobileが有力な選択肢になるかは、料金だけでなく、通信品質や独自機能、サポートを含めて判断する必要があります。

料金や容量が発表されるまでは、各サービスより得かどうかを決めることはできません。

## blue mobile発表の意味

今回の発表で重要なのは、日本通信が料金に加えて、通信基盤やデジタル機能でも違いを打ち出そうとしている点です。

自社SIMや自社コアネットワークを活用することで、海外利用やeSIM、利用者ごとのサービス設計など、従来より柔軟な機能を作れる可能性があります。

ブランド名とロゴは、日本通信の技術基盤であるFPoSの思想を背景にしています。雲を抜けた先の青空をイメージし、さまざまな制約からの自由を表現したものです。

ただし、利用者にとっての価値は、最終的には料金や通信品質、使いやすさで決まります。

現時点では、次のように整理できます。

- 新しい料金プランの詳細が発表されたわけではない
- 一般的なMVNOより柔軟なサービスを設計できる土台が示された
- 料金・容量・プラン名は未発表
- 既存サービスより得かどうかは、今後の発表後に判断する
- 今すぐ乗り換えず、料金と機能の続報を待てばよい

blue mobileが有力な選択肢になるかどうかは、料金、データ容量、通信品質、独自機能のバランス次第です。
