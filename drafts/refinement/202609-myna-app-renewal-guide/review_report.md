# セルフレビュー: マイナアプリへの統合刷新

出所: Codexによる一般読者向けレビュー（2026-09-21 JST）

## 結論

公開前の必須7項目はすべて合格。数値・日付・固有名詞は一次情報に照合済み。将来機能と現在機能の境界をさらに明確にし、タイトルの「消えた？」が事実誤認にならないよう冒頭で更新だと即座に説明する。

## 項目別判定

1. **主題の説明が冒頭にある: 合格**
   - 旧マイナポータルアプリが2026年8月25日にマイナアプリへ更新された話だと冒頭2段落で説明している。
2. **30秒欄4項目だけで理解できる: 合格**
   - 「これは何？」「何があった？」「誰に関係ある？」「結局どうなの？」の4項目を順番どおり配置した。
3. **関係がある人・薄い人が分かる: 合格**
   - 旧アプリ利用者、手続きをする人、オンライン本人確認をする人を対象として明示。使わない人、今すぐ手続きがない人も分けた。
4. **専門語が初出で説明される: 合格**
   - マイナポータル、認証、電子署名、プッシュ通知、生体認証を初出または直後で普通の日本語に説明した。
5. **キャラが読者の疑問を代弁する: 合格予定**
   - MDX化で「消えたの？」「更新だけでよい？」「カード不要？」の3つをひまりの疑問、らぼまるの整理として配置する。
6. **噛み砕きが長文化していない: 合格**
   - 一文一情報を基本とし、機能一覧は3項目、利用手順は3段階に限定した。
7. **内部工程情報が公開文にない: 合格**
   - スカウト、生成指示、自動公開、veto、内部メモ等は公開用ドラフトに含めていない。

## 事実確認

- 提供開始日「2026年8月25日」: デジタル庁会見と公式案内で一致。
- 統合対象「マイナポータルアプリ」「デジタル認証アプリ」: デジタル庁会見・公式ストアで一致。
- 旧デジタル認証アプリの提供・利用終了: デジタル庁サポートで確認。
- 現行の主な機能: Google PlayとApp Storeの公式掲載で確認。
- 初回利用登録と端末ロック: ITmediaの利用体験に基づくため「報道では」と線引き。
- すべてのサービスでスマホ完結しない: 大臣会見で、カード本体が必要な場面が残る趣旨を確認。

## 修正した点

- 「新規インストールが必要」と誤読されないよう、旧マイナポータルアプリ利用者は更新で移行すると明記。
- 「実物カード不要」を一般化せず、対応サービスに限ると修正。
- お知らせ機能の今後の拡張時期は本文から外し、現行公式ストアの機能説明だけを採用。
- 初期登録手順は端末差があるため、細かな画面順ではなく「画面の案内に従う」に留めた。
- 偽アプリ対策として、提供元がデジタル庁か確認する実用的な注意を追加。

- タイトルは疑問形を残し、本文冒頭で「削除ではなく更新」とすぐ解消する。
