# セルフレビュー

## Pass 1: メタ表現・煽り・誤解・断定

- 禁則表現を点検し、公開本文に工程説明や内部指示が入っていないことを確認した。
- 「プロ品質」を編集結果の保証として使わず、具体的な機能へ置き換えた。
- Android版の生成AIは公式ページ間の矛盾を明記し、利用可能と断定しない構成にした。
- 最大4K対応と、個別端末で快適に動くことを分離した。
- 「無料」をコア編集機能の範囲として説明し、生成クレジットと追加ストレージは費用が発生し得ると補足した。

## Pass 2: すまラボらしさ・判断材料・スライド化

- 冒頭に結論を置き、30秒欄を4項目で構成した。
- 専門語の初出で、マルチトラック、タイムライン、4K、オーディオを強調、生成クレジットを普通の日本語で説明した。
- 関係がある人、あまり関係がない人を分けた。
- OS・RAM・空き容量・短い素材という、読者が実行できる確認項目を置いた。
- スライド8枚の役割を確定し、本文の繰り返しではなく、概念と判断を図で補う構成にした。

## Pass 3: 事実・数値・出典

- 発表日、Android 13以降、RAM 5GB以上、最大4K、透かしなし、ログイン不要範囲をAdobe公式情報で再確認した。
- 「近日予定」の機能を現行機能に混ぜていない。
- Android版生成AIの説明不整合をuncertain_pointsとして維持した。
- 参考情報にAdobe公式URLを3件置いた。

## article-ready-for-images 判定

- ① 記事の結論が明確: 合格
- ② 読者の判断材料が明確: 合格
- ③ 誤解されやすい点が整理済み: 合格
- ④ 事実・報道・未確定が分離済み: 合格
- ⑤ 禁則表現: 0件
- ⑥ スライド化論点: 8枚で確定

判定: article-ready-for-images
