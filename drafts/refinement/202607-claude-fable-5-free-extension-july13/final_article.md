# Claude Fable 5、サブスク無料枠が7月13日まで延長。何が変わって、いつまでに何をすればいい？

Claude Fable 5を「追加料金なしでサブスク内から使える期間」が、当初の7月7日から延長されました。前記事では「7月8日からusage credits制へ」と整理しましたが、その後の発表で無料で使える期間が数日のびています。この記事では、何がどう変わって、いつまでに何をすればいいのかを、公式情報と報道を分けてやさしく整理します。

## 先に結論：無料枠は7月13日昼まで延長。対象なら「その前に試す」でOK

lead: Claude Fable 5の「追加料金なしで使える期間」が、**日本時間7月13日(日)15:59:59まで**延長されました。対象プランなら**申請不要**で、**週間上限の最大50%まで**は追加料金なしで使えます。

- 期限：当初7月7日 → **米太平洋時間7月12日23:59:59（日本時間7月13日15:59:59）** まで
- 対象：**Pro / Max / Team ＋ Enterpriseのプレミアムシート**、週間上限の**最大50%**まで、**申請不要**
- 期限後：50%到達後・7月13日経過後は **利用クレジット（別課金）またはAPI経由**

補足：やることはシンプルです。対象プランで「Fable 5を試したい」なら、**期限内（7/13昼まで）に触っておく**。それだけで追加料金はかかりません。

## 何が変わった？無料で使える期間が約6日のびた

lead: 変わったのは**期限だけ**です。仕組み（対象・50%・申請不要）はそのままで、締切が後ろに動きました。

- 前記事時点：7月7日まで無料枠、7月8日からusage credits制へ切り替わる予定だった
- 今回の発表（7月7日）：無料枠を**7月12日（米太平洋時間）＝日本時間7月13日昼まで**延長
- 追加料金なしの条件（Pro/Max/Team＋Enterpriseプレミアム、週間上限の最大50%、申請不要）は据え置き

図解スライド：日付カレンダー（7/7発表 → 7/13締切 → 以降クレジット/API）

## 対象と条件：誰が・どこまで無料か

lead: 「無料で使える」といっても**無制限ではありません**。対象プランと、週間上限の50%という枠を押さえておきましょう。

比較表：
- Pro / Max / Team：対象。週間上限の最大50%まで追加料金なし（申請不要）
- Enterprise（プレミアムシート）：対象。同上
- Enterprise（標準シート）：対象外。利用クレジットが必要
- 上記いずれも：50%到達後・7/13経過後はクレジットまたはAPI

読み取りポイント：
- 「50%」は**週間の利用上限のうち半分まで**をFable 5に回せる、という意味。残り半分は他モデルで使う想定。
- 申請や設定変更は不要。対象プランなら自動で適用される。

## いつまでに何をすればいい？（やることチェック）

lead: 難しい手続きはありません。**期限内に試す**のが基本で、課金が不安な人だけ追加の一手を。

チェックリスト：
- ☑ 対象プラン（Pro/Max/Team/Enterpriseプレミアム）か確認する
- ☑ 7月13日(日)15:59:59（日本時間）までにFable 5を試しておく
- ☑ 週間上限の消費が気になる人は Settings > Usage で残り枠を確認する
- ☑ 期限後も使い続けたい人は、クレジット（別課金）の要否を考えておく
- ☑ 課金が不安なら、自動リロードはOFF・少額から（詳細は前記事へ）

## まとめ：対象なら「期限内に試す」、続けたいなら「クレジットの要否」を考える

lead: やることは2つだけ。**対象プランなら7/13昼までに試す**、**その後も使いたいならクレジット（別課金）の要否を決める**。

- 今すぐFable 5を試したい人 → 期限内（7/13昼）に触っておけば追加料金なし

- 様子見でよい人 → 「恒久離脱ではない」ので、戻ってくるのを待つ選択肢も
