# slide_plan — password-manager-guide

正本2枚（himari-canonical / labomaru-canonical）を厳守。認識アンカーは不変、衣装・小道具・ポーズ・背景はテーマ（鍵・錠前・金庫・スマホの自動入力）に合わせる。
漢字化け対策: 帯・見出し・吹き出しの短い語は化けやすい漢字（目/未/末/微）を避け、やさしい和語・ひらがなを優先。X直接投稿を見据え各スライドは文字量控えめ・数字正確・単体で意味が通ること。

## 演出ブロック（必須）
- **テーマ**: 「覚えない」を実現する道具＝パスワード管理アプリ。安全（鍵・錠前・金庫・盾）と、スマホでの自動入力という"体験"。
- **衣装（ひまり）**: 標準の白ワンピ＋ティール差し色パーカーをベースに、テーマ小物として鍵モチーフの首かけストラップ（小さな鍵のチャーム）を追加。8枚の本文スライドはこの標準衣装で一貫。サムネは鍵チャームを見せて演出強調。認識アンカー（金髪サイドテール・水色リボン・青い瞳・頭身）は不変。露出過多にしない。
- **小道具**: 鍵（複数の鍵→1本のマスターキーにまとまる）、南京錠、金庫（らぼまるが金庫番）、盾、スマホ（自動入力の画面）。らぼまるは素体のまま、鍵束や盾を持つ/示すことでテーマ表現（胸のオレンジのハート型ボタン・黄緑アンテナ・青い首カラー・卵型ボディは不変）。
- **ポーズ（動きを付ける・棒立ち回避）**: ひまり＝スマホをタップして自動入力を体験する/たくさんの鍵を1本にまとめる仕草。らぼまる＝金庫の扉に手を添える/盾で守る/鍵束を掲げて説明。
- **背景・状況**: セキュアで安心感のあるティール〜ミントのやわらかい背景に、鍵・盾・錠前の軽いモチーフ。暗く不安を煽るトーンにしない。
- **演出根拠**: 記事テーマの中心が「鍵・錠前・スマホ操作」。よって鍵をまとめる/金庫で守る/スマホで自動入力する体験を主役にする。標準衣装の棒立ち・汎用背景・指さし説明だけの構図は避ける。
- **スライド演出方針**: 本文8枚は標準衣装で一貫し、小道具（鍵・南京錠・金庫・スマホ）と背景モチーフでテーマを表現。感情は1枚1つ（危機感→安心→納得の流れ）。

## thumbnail（16:9・体験図／活用シーン型）
- 構図: ひまりがスマホを持ち、画面に自動入力でログインが完了する瞬間（安心の笑顔）。手前にバラバラの鍵が1本のマスターキーに束ねられるモチーフ。らぼまるが横で金庫の扉に手を添え、胸のオレンジのハートボタンを見せて安全に預かる金庫番。
- 感情: 安心（1つだけ覚えれば全部開く、を体験）。
- 入れる文字（最小限・正確に描く）: 主「パスワードは"覚えない"」／サブ「管理アプリで使い回し卒業」。
- 装い根拠: 鍵・錠前 → 鍵チャーム＋金庫＋マスターキー。標準衣装のままにしない。
- 禁止: 実在サービスのロゴ精密再現・日本円の金額・炎上風の不安演出。

## slide01（4:5・使い回しの危険）
- 図: 1本の鍵で「家・車・金庫」が全部開いてしまう絵。ひまりが「1つ漏れると全部…！？」と軽い驚き（不安を煽りすぎない）。らぼまるが横で注意を促す。
- 帯（短く）: 「使い回しは連鎖する」
- 感情: 軽い驚き。

## slide02（4:5・アプリの4つの仕事）
- 図: 4カードで「作る／自動で入れる／同じにする（同期）／見張る」。らぼまるが鍵束を持って整理。ひまりがうなずく。
- 帯: 「覚えるのは1つだけ」
- 注意: 「監視」等の硬い語より「見張る」等やさしい語。

## slide03（4:5・ゼロ知識の仕組み）
- 図: 端末（スマホ）の中で鍵を作る → サーバーには錠前付きの箱（暗号化された箱）だけが置かれる。運営会社も中を見られない、を矢印で。らぼまるが金庫を指して説明。
- 帯: 「会社も中を読めない」
- 感情: 納得・安心。

## slide04（4:5・誠実な比較）
- 図: 左「使い回し＝1つ漏れたら連鎖」／右「管理アプリ＝万一漏れても暗号化＋ゼロ知識で守られる」の対比。小さく添える「強いマスターパスワードは必要」。数字・実在名は出さず概念で。
- 帯: 「リスクゼロではない。でもはるかに安全」
- 感情: 冷静・納得。

## slide05（4:5・どれを選ぶ）
- 図: 3枠を中立に並列「無料で十分＝Bitwarden／手厚さ・家族共有＝1Password／内蔵で手軽＝Google・Apple」。ひまりが見比べ、らぼまるが用途で整理。
- 帯: 「使い方で選ぶ」
- 注意: どれも劣らせない中立トーン。

## slide06（4:5・運営者の実例）
- 図: ひまりがスマホでBitwardenの自動入力を実際に体験している図。「本サイトは無料のBitwardenを使用」の一言。宣伝でなく一例のトーン。
- 帯: 「まずは無料から」
- 感情: 等身大・安心。

## slide07（4:5・始め方3ステップ）
- 図: ①強いマスターパスワードを1つ ②自動入力ON ③今のを移す、の流れ。下に小さくつまずき「機種変更＝同期で復元／忘れ＝リカバリーキットが命綱」。ひまりが順に進める。
- 帯: 「3つで動く」

## slide08（4:5・まとめ・チェックリスト）
- 図: チェック5項目（マスターは1つ強く／リカバリー手段を保管／自動入力ON／弱いのは作り直す／漏えい警告を見る）。ひまり＆らぼまるが安心の笑顔で並ぶ。
- 帯: 「覚えないが正解」
- 感情: 安心・前向き。
