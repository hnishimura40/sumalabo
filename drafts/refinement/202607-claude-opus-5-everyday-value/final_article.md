# Claude Opus 5登場。「また新モデル？」でも課金者は今日から自動で得する

2026年7月24日、AnthropicはClaude Opus 5を発表しました。結論から言うと、Max利用者はデフォルトモデルがOpus 5へ、Pro利用者は使える最上位モデルがOpus 5へ更新されます。基本的に設定変更は不要です。

Opus 5は、Anthropicが「Fable 5の能力に近い」と説明する日常向けモデルです。API単価は入力$5・出力$25（100万トークン）で、Opus 4.8から値上げされていません。

ただし万能な最上位ではありません。長期間の自律作業はFable 5、攻撃的サイバー能力はMythos 5が上という位置づけです。AIの競争が「一番賢いモデル」だけでなく、「日常で払えるコストの中でどこまで賢いか」へ移っているニュースとして捉えるのがポイントです。
