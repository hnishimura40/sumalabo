# Research Report — Claude Opus 5

- 調査時点: 2026-07-25 10:05 JST
- 主根拠: Anthropic「Introducing Claude Opus 5」（2026-07-24）
- 公式URL: https://www.anthropic.com/news/claude-opus-5

## 公式で確認できた事実

- Opus 5は2026年7月24日から全プラットフォームで提供。
- Anthropicの表現は「Fable 5のフロンティア級知能に近い（comes close）」であり、「Fable 5を全面的に超えた」ではない。
- 価格は入力$5、出力$25（100万トークンあたり）。Opus 4.8と同額。
- Claude Maxでは新しいデフォルトモデル。Claude Proでは利用できる最強モデル。
- Frontier-Bench v0.1では他モデルを上回り、Opus 4.8の性能を2倍超にしたと公式説明。
- CursorBench 3.2のmax effortではFable 5のピークスコアから0.5%以内、1タスク当たりコストは半分。
- サイバーセキュリティと生物研究の危険な二重用途能力ではMythos 5に及ばない。脆弱性の発見は近いが、exploit開発は大きく下回る。

## 補助報道

- Reuters: 日常のオフィス業務とプログラミング向け、価値ならOpus 5、数日単位の自律作業ならFable 5というAnthropic幹部の説明。
- Axios: Fable 5に近い性能を半額、Maxのデフォルト、全有料プランで利用可能と整理。
- Bloomberg系報道: 顧客のコスト意識が高まる中で、日常業務向けの効率を前面に出した競争と位置づけ。

## 編集上の線引き

- 「Fable 5級」は見出しの煽りとして使わず、「多くの課題で近い」「公式評価ではclose to」と書く。
- 特定ベンチで上回る結果と、モデル全体の優劣を混同しない。
- Max/Proの恩恵は“追加操作なしでモデル選択肢が更新される”こと。利用上限やプラン料金そのものの変更とは書かない。
- API価格はモデル単価。Claude有料プランの月額料金と混同しない。
