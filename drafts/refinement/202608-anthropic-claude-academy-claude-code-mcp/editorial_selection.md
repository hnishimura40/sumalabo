## 採用する論点

### 主役にする

1. Claude Academyは、Claudeの機能一覧ではなく、AIの使い方と判断のしかたを目的別に学べる公式の入口である。
2. 初めて使う人は「Claude 101」か5〜7分の短い教材から始められる。
3. 仕事で使う人は、AIへ任せる範囲、回答の確認、利用を伝える姿勢まで学べる。
4. 開発者はClaude Code、MCP、API、Skillsなどへ進めるが、初めての人が最初からそこへ行く必要はない。
5. サインインは学習履歴、クイズ、バッジを残したい人向け。まず公開教材の内容を確認してから判断できる。
6. 日本語表示は経路や教材により差が出る可能性がある。英語表示なら、翻訳を補助にしながら重要部分は原文も確認する。

### 限定採用

- レッスン数・学習時間: 学び方の目安として使う。総教材数は変動するため見出しの主役にしない。
- バッジ・修了証: 学習の区切りとして紹介する。就職や資格上の効力はうたわない。
- Anthropic社内の教育方針: Academyが操作マニュアルだけではない理由を説明する範囲で短く使う。

## 採用しない論点

- Claudeのモデル性能比較や料金プランの詳細。学習サイトの選び方から外れる。
- コース数などを固定値で強調する見せ方。更新で古くなりやすい。
- 受講すれば仕事が自動化できるという効果保証。
- バッジが転職や昇進へ直結するという推測。
- Claude Code、MCP、APIの技術仕様を深掘りする構成。初めて読む人の入口を狭くする。

## facts

- 2026年8月20日に公式ブログでClaude Academyの学習方針が発表された。
- 製品別にClaude.ai、Claude Cowork、Claude Code、Claude Tag、Claude Platformの入口がある。
- 個人、仕事、開発の目的別にコース、短いチュートリアル、活用例が整理されている。
- AI Fluencyでは、任せる範囲、指示の伝え方、見極め、継続的な確認を扱う。
- 公式ブログはおすすめ、修了記録、バッジ、Claude Academy Skillを案内している。

## claims

- 国内報道は無料学習サイトとして紹介している。
- 国内報道は日本語翻訳を案内しているが、α版とされる。

## uncertain

- 全教材の日本語表示状況は一律ではない可能性がある。
- すべての教材をサインインなしで最後まで利用できるかは教材単位で確認が必要。
- 教材数や構成は今後変わる可能性がある。

## 読者翻訳設計

- 主題の一言説明: AIとClaudeの使い方を、目的と経験に合わせて学べるAnthropic公式の学習案内所
- 関係がある人: Claudeを初めて試したい人、仕事で安全に使う手順を学びたい人、Claude CodeやAPIの学習入口を探す人
- あまり関係がない人: すでに学習経路と社内ルールが固まっている人、Claudeを使う予定がない人
- Claude Academy → AIとClaudeの使い方を目的別に学べる公式サービス
- AI Fluency → AIへ何を任せ、どう伝え、どう確かめるかを学ぶ考え方
- Claude Code → パソコンの開発作業を会話で手伝うソフト
- Claude Cowork → ファイルを使うまとまった作業をClaudeへ頼む機能
- Claude Tag → チームの会話にClaudeを呼び、作業を頼む機能
- Claude Platform → Claudeを自社の製品や仕組みに組み込む開発サービス
- API → 別のソフトからClaudeを呼び出すための接続口
- Model Context Protocol（MCP） → AIと外部の道具や情報を共通方式でつなぐ仕組み
- Skills → 特定の作業手順をClaudeへ覚えさせる仕組み
- AIエージェント → 目標に向けて手順を考え、道具を使いながら作業を進めるAIの仕組み
- バッジ → 学習の区切りや修了を記録する印
- α版 → まだ改善途中で、表示や動作が変わる可能性のある試行版
- 事実から言えること: 初心者から開発者まで複数の入口があり、操作だけでなく判断と確認も学習対象になっている
- 事実から言えないこと: 受講すれば回答の正確さが保証される、仕事上の資格になる、全教材が自然な日本語で読める
