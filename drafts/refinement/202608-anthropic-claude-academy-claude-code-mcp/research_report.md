## facts（公式ページで確認済み）

1. Anthropicは2026年8月20日、Claude Academyを通じた学習方針を公式ブログで発表した。
2. Claude Academyは `academy.claude.com` で公開され、AIを初めて学ぶ人、Claudeを使い始める人、チーム導入を進める人を対象にしている。
3. 公式トップには、Claude.ai、Claude Cowork、Claude Code、Claude Tag、Claude Platformの製品別入口がある。
4. AnthropicのLearnページは「Build with Claude」「Claude for work」「Claude for personal」の3方向で資料を整理している。
5. 個人向けページには、Claude 101（13レッスン・クイズ1回・約2.5時間）、AI Fluency: Framework & Foundations（14レッスン・クイズ1回・約4時間）、AI Capabilities and Limitations（13レッスン・クイズ1回・約3.5時間）などが掲載されている。
6. 個人向けには5〜10分ほどの短いチュートリアルや、15分ほどの活用例もある。最初から長時間コースを選ぶ必要はない。
7. 開発向けページにはAPIとSDK、AIエージェント、Skills、MCP、Claude Code、ツール利用、プロンプト設計、評価、キャッシュ、画像理解、パソコン操作などの入口がある。
8. 仕事向けページにはClaude 101、AI Fluency、Claude Code in action、Introduction to Claude Coworkなどのコースが掲載され、修了証の取得案内もある。
9. 公式ブログは、関心分野と学習履歴に基づくおすすめ、コース修了とバッジの記録、Claude Academy Skillによる学習経路の提案を案内している。
10. 公式ブログは、AIへ任せる作業と人が担う判断を分けること、重要度に応じて回答を確かめること、AI利用を関係者へ適切に伝えることを学習方針として示している。
11. 2026年8月27日の確認では、トップ、コレクション、教材説明をサインイン前でも表示できた。料金入力や決済画面は確認されなかった。

## claims（報道で述べられていること）

1. 国内報道はClaude Academyを「無料学習サイト」と紹介している。
2. 国内報道は、Claudeアカウントでサインインすると学習進捗を管理できると説明している。進捗・バッジ機能の存在自体は公式ブログでも確認できる。
3. 国内報道は日本語翻訳を案内しているが、翻訳機能はα版とされる。調査時に取得できた公式本文は英語中心だった。

## uncertain_points（断定しないこと）

1. すべての教材が日本語で自然に読めるか。教材やアクセス経路により表示が異なる可能性がある。
2. サインインなしで全レッスンを最後まで受講できるか。公開ページの閲覧は確認できたが、クイズ採点、進捗保存、バッジはサインインが必要と考えられる。
3. コース数、チュートリアル数、活用例数。追加・整理が続くため固定数として記事の主役にしない。
4. 修了証やバッジが採用・資格審査でどのように評価されるか。公式は就職上の効力を保証していない。
5. Claude Academyを受講すればClaudeの回答が正しくなる、または仕事の確認が不要になる、という効果。学習サイトは使い方を学ぶ場であり、回答品質の保証ではない。
