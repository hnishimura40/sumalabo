## 演出ブロック

- 衣装: ひまりはミント色と紺の学習ガイド用ショートジャケット、肩掛けの小さな教材ポーチ、ティールのリボン。らぼまるは青い首輪と耳ビレ、黄緑アンテナ、胸のオレンジのハートを正本どおり保ち、テーマ演出として小さな斜め掛け案内ポーチだけを追加する
- 小道具: 光るコースカード、床に広がる学習ルート、短い教材カード、3つの入口ゲート、確認スタンプ、積み上げ型の学習ブロック
- 手・小道具: 壊れにくい手を自然に描く。自然な構図を優先し、開いた手かカードへ軽く添える手を小さめ・遠めにする。動作する手は片手だけ、もう片方は体側で自然に休ませる。強い握り、両手の別動作、指を組む・数えるポーズ、手のクローズアップを避ける
- ポーズ・動き: 2人が明るい学習ギャラリーを歩き、入口を見比べ、短い教材を選び、学んだ内容を確認して次の扉へ進む。一方向の視線と足運びで旅の連続性を出す
- 背景・状況: 机やノートPCを主役にせず、展示館のような立体的な学習ギャラリーを使う。半透明のゲート、壁面の教材タイル、床のルート、やわらかな自然光で奥行きを作る
- 表情: 新しい公式の学び場を見つけた「発見と安心」。ひまりは目を見開いて興味を示し、らぼまるは落ち着いて順路を案内する。はしゃぎすぎず、説明パネル横の棒立ちにしない
- 演出根拠: Claude Academyは複数の学び方から自分の入口を選ぶサービスなので、「講義室」ではなく「学習ギャラリーを巡る体験」に翻訳する
- 日付型判定: 非該当。公開日は事実欄で扱うが、日付や締切が主題ではない
- 変化の中身: 公式の学習資源が、個人・仕事・開発の入口として一か所に整理された
- 主要モチーフ: 3つの入口がつながる立体的な学習ギャラリー
- 日付ラベル: なし
- 直近10記事類型チェック: 類似なし。直近のClaude日本語記事と教材講座記事は机・ノートPC・教材カード中心だったため、今回は歩いて巡る展示館、床のルート、奥行きのある入口ゲートへ変更する
- スライド演出方針: 衣装と学習ギャラリーの世界観は8枚で一貫させる。小道具は各purposeに合わせ、カードを選ぶ、入口を見比べる、確認スタンプを押す、次の扉へ歩くなど一枚一動作にする
