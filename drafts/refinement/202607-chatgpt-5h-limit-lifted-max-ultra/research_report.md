# research_report: 202607-chatgpt-5h-limit-lifted-max-ultra

テーマ: ChatGPTの5時間制限が一時撤廃。GPT-5.6は今どこまで使って大丈夫? max/ultraの消費の仕組みもやさしく整理

## facts（一次情報・裏取り済み）
- 2026年7月12日(現地)/7月13日(日本時間)、OpenAI が Plus/Business/Pro の **5時間ごとの使用上限を一時的に撤廃**（製品責任者 Tibo 氏の X 投稿）。あわせて**全ユーザーの使用量をリセット**。
- **Sol の効率化（トークン消費削減）を展開中**。効果の定量値は「後日共有」とされ、現時点で数値は非公表。
- 背景: **直近48時間で Codex / ChatGPT Work の需要が急増**、アクティブ 600万人規模。
- **ChatGPT Work と Codex は同一の利用プールを共有**（Work で使うと Codex 側の枠も減る）。
- **max** = 1回の応答に最大の推論をかける設定。GPT-5.6 アクセスがあれば Work/Codex で利用可。
- **ultra** = 既定で 4 エージェントを並列に動かし作業を分担する設定。提供範囲は **Work=Pro/Enterprise、Codex=Plus以上**（Work と Codex で条件が違う）。
- 標準チャット: Plus 以上で Medium/High 選択時に Sol。**Extra High / Sol は Pro/Business/Enterprise 限定**。**Terra/Luna は標準チャットでは選べない**。
- 貯蓄リセットの Web/モバイル開放時に「10%未満で不適用」バグ → 対象期間の全員に**再付与済み**。
