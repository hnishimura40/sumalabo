# Editorial Selection — MetaのMuseで何を任せられるか

判定: 限定採用

- **カテゴリ**　ニュースをかみくだく
- **調査の基準日**　2026年11月23日（日本時間）
- **判断根拠**　同じ案件の `research_report.md`。日本のアカウントでの実機操作と購入画面の確認は未実施。
- **記事の主軸**　Museに頼める仕事を、調べる、資料にまとめる、決まった間隔で繰り返す、外部サービスで操作する、の順に解説する。ChatGPTとGeminiは、同じ仕事を頼むときの利用条件と、本人が確認する場面を比較する。

## なぜ今注目するか

Museは10月23日に日本で提供が始まり、11月6日には予定表や進捗表などを作って使える「スペース」が提供済みの地域に追加された。11月22日のITmedia Mobileの解説をきっかけに、日本で使える機能を整理する。報道日、国内提供開始日、機能追加日はそれぞれ明記する。採用情報の掲載3件には、同じ記事の転載と配信が含まれる。独立した3媒体の取材として数えない。 [Metaの日本提供発表](https://about.fb.com/ja/news/2026/10/muse-personal-ai-agent-launches-in-japan/)・[Metaのスペース発表](https://about.fb.com/news/2026/11/introducing-spaces-customize-muse-app/)・[ITmedia Mobile](https://www.itmedia.co.jp/mobile/articles/2611/22/news005.html)

## 答える疑問とAIの視点

- **「質問への回答以外に何ができる？」** 「毎週、公開情報を集めて表にする」を説明例にする。調査、ファイル作成、繰り返しの設定という三つの作業に分ける。Metaによると、処理はアプリを閉じた後も続けられる。例は機能の説明として扱う。 [Metaの日本提供発表](https://about.fb.com/ja/news/2026/10/muse-personal-ai-agent-launches-in-japan/)・[Metaの定期タスク案内](https://www.meta.com/en-gb/help/superintelligence/1484325780075655/)
- **「今使っているChatGPTやGeminiでも足りる？」** 作業を始める条件、読み取ったり書き込んだりできる情報、無料で使える範囲、本人の確認が入る操作を比べる。質問や文章の下書きで足りている人への判断材料は短く添える。 [OpenAIのWork発表](https://help.openai.com/en/articles/6825453-chatgpt-release-notes)・[OpenAIの定期タスク案内](https://help.openai.com/en/articles/10291617-scheduled-tasks-in-chatgpt)・[Googleのタスク機能案内](https://support.google.com/gemini/answer/17094507?hl=ja-JP)
- **「メールや家計の情報を渡したら、どこまで操作できる？」** AIが作業を進めるとき、情報を読む許可と、外部へ送信する許可がどう関わるかを説明する。ひまりの「つないだら、メールは送られる？ 家計のお金も動く？」という疑問から、らぼまるが送信前の確認と家計データの閲覧範囲を案内する。 [Metaの承認と権限の案内](https://www.meta.com/ja-jp/help/superintelligence/1385290430137537/)・[マネーフォワードの連携開始発表](https://corp.moneyforward.com/news/release/service/20261026-mf-press-2/)

## 採用する論点

- **Museの国内提供と作業範囲。** 日本語で使えるスマートフォンアプリとウェブ版、資料や表の作成、対応サイトの入力欄への記入、定期実行、スペースを扱う。フォームに情報を入れる段階と、送信や購入を確定する段階は個別に説明する。無料枠には利用量の上限がある。 [Metaの日本提供発表](https://about.fb.com/ja/news/2026/10/muse-personal-ai-agent-launches-in-japan/)・[Metaのスペース発表](https://about.fb.com/news/2026/11/introducing-spaces-customize-muse-app/)・[Metaの料金案内](https://www.meta.com/ja-jp/help/subscriptions/1021145227643680/)
- **日本でのChatGPT・Geminiとの比較。** ChatGPT Workはウェブ・スマートフォンでは対象の有料プラン向け。ChatGPTの定期タスクは無料でも設定でき、同時に有効にできるのは3件、繰り返しは1日1回まで。Geminiのタスク機能は日本で有料契約なしでも利用でき、18歳以上、個人のGoogleアカウント、履歴オンが条件。契約なしでは大まかな時間帯で1日1回まで。Gmailの受信をきっかけに実行する条件は、各社が案内する対象プランと機能の範囲で示す。 [OpenAIのWork発表](https://help.openai.com/en/articles/6825453-chatgpt-release-notes)・[OpenAIの定期タスク案内](https://help.openai.com/en/articles/10291617-scheduled-tasks-in-chatgpt)・[Googleの利用条件](https://support.google.com/gemini/answer/17094507?hl=ja-JP)・[Googleの実行条件](https://support.google.com/gemini/answer/17094710?co=GENIE.Platform%3DDesktop&hl=ja-JP)
- **日本での連携と確認できる設定。** GmailとGoogleカレンダーを身近な例に使う。マネーフォワード MEは本人の同意に基づく閲覧専用の連携で、支出の整理に使える。メール送信の例では宛先・本文・添付を確認する。AIの改善にやり取りを使うかは「データコントロール」で変更でき、Metaの案内では初期設定がオン。連携先の権限、AIの改善への利用、作業データの保存はそれぞれ別の項目として説明する。 [Metaの日本提供発表](https://about.fb.com/ja/news/2026/10/muse-personal-ai-agent-launches-in-japan/)・[マネーフォワードの発表](https://corp.moneyforward.com/news/release/service/20261026-mf-press-2/)・[Metaの承認と権限の案内](https://www.meta.com/ja-jp/help/superintelligence/1385290430137537/)・[Metaのプライバシー案内](https://www.meta.com/ja-jp/help/superintelligence/1047255454427887/)

## 限定採用する論点

- **円建て料金は日付と申込経路を付けた補足にする。** ITmediaが11月22日に報じた月額は、Powerがウェブ2,799円・iPhoneアプリ内3,499円、Maximumがウェブ13,990円・iPhoneアプリ内16,990円。Androidの金額と日本の無料枠の具体的な上限は未確認。実際の支払額は申し込み時の表示を確認する。 [ITmedia Mobile](https://www.itmedia.co.jp/mobile/articles/2611/22/news005.html)・[Metaの料金案内](https://www.meta.com/ja-jp/help/subscriptions/1021145227643680/)
- **アプリ順位は注目の一例にとどめる。** 調査時の11月23日午前4時32分ごろ、日本のiPhone向け「仕事効率化」の無料アプリ欄で、Museが1位、ChatGPTが2位、Geminiが3位だった。順位を載せる場合は時刻と対象を併記する。利用者数、継続利用、性能、順位が動いた理由は確認できていない。 [Appleの日本向けアプリランキング](https://apps.apple.com/jp/iphone/charts/6007?chart=top-free)

## 不採用とする切り口

- **性能ランキングと最上位モデルの利用保証。** Metaの公表値は自社の新旧モデルを特定の課題で比較したもの。日本語での作業、無料枠で実際に使われるモデル、ChatGPTやGeminiとの同条件での優劣を示すデータがない。 [Meta AI Researchの評価](https://research.meta.ai/blog/specialized-models-for-muse-and-metaai)
- **未確認の国内機能と仕様。** メルカリでの出品や購入、チケットぴあでの申し込み、高度な音声、独自メール、AIグラス対応、作業環境の約100GBという容量、Metaからも内容が見えない作業環境は、日本で現在使える機能や仕様として裏付けが取れていない。 [Metaの日本提供発表](https://about.fb.com/ja/news/2026/10/muse-personal-ai-agent-launches-in-japan/)・[Metaのプライバシー案内](https://www.meta.com/ja-jp/help/superintelligence/1047255454427887/)・[ITmedia Mobile](https://www.itmedia.co.jp/mobile/articles/2611/22/news005.html)
- **11月22日の国内提供開始、値下げ、設定変更。** この日に確認できるのはITmediaの解説公開。国内提供とスペース追加にはそれぞれ別の日付があり、同日の値下げや設定変更を示す根拠は確認できていない。 [ITmedia Mobile](https://www.itmedia.co.jp/mobile/articles/2611/22/news005.html)・[Metaの日本提供発表](https://about.fb.com/ja/news/2026/10/muse-personal-ai-agent-launches-in-japan/)・[Metaのスペース発表](https://about.fb.com/news/2026/11/introducing-spaces-customize-muse-app/)

## 読者翻訳設計

公開本文に転記せず、用語の初出説明と事実の範囲を決めるために使う。

### 主題の一言説明

調べものや表づくりをまとめて頼めるAIが日本でも使えるようになり、どの作業まで任せられるかは、使うサービスや操作の許可によって変わる。

### 関係がある人

毎週の情報収集や資料作成をまとめて任せたい人。メール、予定、家計の情報をAIに渡す前に、読み取り・書き込み・送信の範囲を知りたい人。

### あまり関係がない人

その場の質問や文章の下書きが主な用途で、繰り返しの作業や外部サービスの操作を任せる予定がない人。今の使い方で足りていれば、乗り換えや契約を急ぐ理由は薄い。

### 専門用語

公開本文では以下の表記を使い、初出の同じ文か直後の文で説明する。

- AIエージェント → 頼んだ仕事に合わせて、調査や資料づくりなど複数の手順を進めるAI
- Muse → Metaが提供する、調べものや資料づくりをまとめて頼めるサービス
- ウェブ版 → インターネットを見るアプリから開いて使う版
- 専用の作業環境 → 利用者ごとに用意され、資料の作成や保存に使うインターネット上の作業場所
- 定期実行 → 決めた間隔で同じ作業を繰り返すこと
- スペース → Museの中に作って使う、予定表や進捗表などの専用画面
- 連携 → 本人の許可を得て、別のサービスの情報や機能を使えるようにすること
- 権限 → 情報を読む、書き込む、送るなど、操作を許されている範囲
- 承認 → 送信や購入などを実行してよいか、本人が確かめて許可すること
- 無料枠 → 料金を払わずに使える範囲
- 有料プラン → 料金を払って使う契約
- Power → Museで週に使える量を増やす有料の契約
- Maximum → MuseでPowerより週に使える量を増やす有料の契約
- ChatGPT → OpenAIが提供する、質問への回答や文章づくりなどを頼めるサービス
- ChatGPT Work → ChatGPTで資料の調査や作成をまとめて任せる機能
- ChatGPTの定期タスク → ChatGPTに決めた日時や間隔で作業をさせる機能
- Gemini → Googleが提供する、質問への回答や文章づくりなどを頼めるサービス
- Geminiのタスク機能 → Geminiに調査や資料づくりなど、いくつかの手順がある作業を任せる機能
- Gmail → Googleのメールサービス
- Googleカレンダー → Googleの予定表サービス
- 個人のGoogleアカウント → 会社や学校が管理するものと区別した、個人用のGoogleの利用登録
- 履歴 → Geminiでのやり取りを記録する設定
- マネーフォワード ME → 支出や口座の明細をまとめて見られる家計管理サービス
- データコントロール → やり取りをAIの改善に使うかなど、データの扱いを選ぶMuseの設定画面

### 事実から言えること

- 日本で提供されているMuseには、対応範囲内で調べる、資料を作る、繰り返す、別のサービスの情報を使う、という使い方がある。
- 同じ「毎週の予定整理」でも、予定を読み取って表を作ること、決まった時刻に実行すること、予定を書き換えることでは、必要な機能や許可が異なる。三つのサービスを比べるときは、この違いを具体的に示せる。
- マネーフォワード MEとの連携は閲覧専用で、振込、出金、金融商品の売買は対象外。メール送信や購入の承認は、操作と権限の設定に沿って説明できる。

### 事実から言えないこと

- 無料で同じ量・同じ頻度の作業を三つのサービスに任せられることや、任意のサイトで操作できること。
- 外部に影響する操作のすべてで同じ確認画面が出ることや、AIの改善への利用をオフにすると、保存済みデータも削除されること。
- 日本の各アカウントに表示される料金・利用枠・対応機能が一律であること、日本語での作業精度や安全性でどれかが優れていること。
