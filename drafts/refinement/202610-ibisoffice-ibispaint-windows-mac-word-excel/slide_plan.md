# ibisOffice 図解計画

本文8枚: 4:5、公開WebP 1280×1600。サムネイル: 16:9、公開WebP 1600×900。画像内の文字は短くし、詳細は記事の読めるテキストに置く。正本はひまり・らぼまる各1人/1体。

## 演出ブロック

- 衣装: ひまりは文書を確認するティール色のベストと白シャツ。8枚で統一する。らぼまるは正本の青い首輪・耳ビレ・オレンジのハートを保持。
- 小道具: ノートPC、文書・表・スライドの汎用アイコン、印刷した文書。実在ロゴは描かない。
- 手・小道具: 壊れにくい手を自然な構図で描く。開いた手または軽く添える手を小さく遠くに置く。動作は片手だけ、もう片手は体側で自然に休ませる。握り・指を組む・数える・接写は避ける。
- ポーズ・動き: 机でファイルを開く、画面を覗く、二つの文書を見比べる。棒立ちと説明役だけの配置は避ける。
- 背景・状況: 明るい自宅の作業机。窓、植物、本棚で奥行きを出す。
- 表情: 新しい選択肢を見つけた発見、互換性を確かめる慎重さを場面ごとに描き分ける。
- 演出根拠: 受け取ったOffice文書を別のソフトで開き、保存後に自分で確認するという読者の体験を表す。
- スライド演出方針: 同じ衣装と作業机を保ち、各スライドで画面のファイル種別と人物の視線・行動を変える。文字は顔・胴体・手と重ねない。
- 日付型判定: 非該当。公開日は主題の条件変更ではない。
- 変化の中身: Office形式を扱う別の公開ソフトが増えた。
- 主要モチーフ: 三種類の文書を開いて確かめるノートPC。
- 日付ラベル: なし。
- 直近10記事類型チェック: 公開日順の直近記事のAI・通信テーマと異なる文書編集の机上体験。汎用の人物＋文字パネル構図から、PCを使う具体場面へ変更。
