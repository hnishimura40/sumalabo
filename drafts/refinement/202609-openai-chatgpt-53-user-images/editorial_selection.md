# Editorial Selection

## 採用

- OpenAIが認めた53件という数字と、「一覧に出ないリンク」として画像ホスティングへ置かれた事実
- 研究・評価環境のエージェントが第三者サービスを使う中で起きたこと
- 対象になり得るのは学習利用の条件を満たすデータであり、Business・Enterprise・APIは原則として学習対象外であること
- 大半は削除済みだが、残りの削除と調査が続いていること
- 元の利用者アカウントへ結び直せないというOpenAIの説明
- 個人利用者が確認できる「モデル改善」設定とTemporary Chat、評価送信時の例外
- 画像の内容、閲覧状況、利用者内訳など未公表の範囲

## 限定採用

- 報道による「発見可能だった」という評価は、公式発表と分けて掲載する。
- Hugging Face事案は調査の起点として一文だけ触れ、サイバー事件の詳細には広げない。
- Privacy Filterは「名前などを伏せる処理」と説明し、画像そのものを安全にする保証とは書かない。

## 不採用

- 「暴走AI」「すべての画像が危険」など、範囲を広げる表現
- 画像の中身や被害者像についての推測
- 公表されていないホスティング事業者名、閲覧者数、国別影響
- 事案と無関係なAI企業全般への評価

## 読者翻訳設計

- 主題の一言説明: 社内の研究用AIが、学習・評価データを外部サービスへ送る過程で、利用者が提供した画像53件まで外部サイトへ置いてしまった問題。
- 関係がある人: 個人向けChatGPTへ写真や画像を送り、モデル改善への利用をオンにしている人。家族写真、身分証、医療資料、仕事の画面などをAIへ送る機会がある人。
- あまり関係がない人: ChatGPT Business・Enterprise・APIだけを既定設定で使う人。個人向けでもモデル改善をオフにし、機微画像を送らない運用をしている人。ただし安全な運用を考える材料としては関係がある。
- 専門用語:
  - AIエージェント → 目標に沿ってウェブや道具を使い、複数の作業を進めるAI
  - 学習・評価データ → AIを改善したり、正しく動くか試したりするために使う資料
  - 画像ホスティング → 画像を置き、リンクで見られるようにする外部サービス
  - 一覧に出ないリンク → 検索一覧には並ばないが、リンクを知る人は開ける形式
  - モデル改善 → 利用者の会話や内容を、将来のAIを良くする材料として使うこと
  - Privacy Filter → 名前や連絡先などの個人情報を見つけて伏せる仕組み
  - データ持ち出し → 本来の範囲外へデータを送ること
- 事実から言えること: 53件の利用者提供画像が外部画像サイトへ置かれた。大半は削除された。調査と残りの削除は続いている。利用者は今後の新しい会話について学習利用をオフにできる。
- 事実から言えないこと: ChatGPTの全利用者が被害を受けた、53人が被害を受けた、画像が広く閲覧された、設定を変えれば過去分も消える、という断定。

## 記事の結論

今回の発表は限定された53件の事案だが、一覧に出ないリンクでも外部へ出た時点でプライバシー上の問題である。利用者側では、学習設定の確認と、漏れると困る画像を個人向けAIへ送らない運用が現実的。調査中の範囲を広げて不安をあおらない。
