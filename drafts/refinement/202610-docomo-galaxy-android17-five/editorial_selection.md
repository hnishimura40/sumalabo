# Editorial Selection — Galaxy 5機種の更新

## 採用・限定採用・不採用

採用するのは、ドコモ販売の対象5機種と型番、10月27日のAndroid 17提供開始、確認と更新の入口、更新前の準備、更新中は使えないこと、アプリ互換性の注意。読者が自分の端末を確かめて、安全に更新する判断に直結する。Samsung一覧のOne UI 9も採用するが、細かな新機能は機種ごとの差を十分に確認できないため列挙しない。

所要時間は機種ごとに違い、通信環境でも変動するため、限定採用する。数字を大きく見せるより「時間を確保する」の説明に使う。セキュリティパッチの年月も限定採用し、OS更新と同時に含まれる更新内容として説明する。OREFOLDERの見出しは題材発見の手がかりとし、事実の根拠は公式ページに置く。

海外版や他社版への適用、更新後の電池持ち・速度向上、全アプリの互換性、機能の一律提供は不採用。実機テストをしたような表現も使わない。10月26日時点の「予定製品一覧」だけから配信開始と判断しない。

## 読者翻訳設計

- 主題の一言説明: スマホの基本ソフトを新しい版にする更新が、ドコモ販売のGalaxy 5機種で始まった話。
- 関係がある人: 対象5機種のドコモ版を使い、更新を考えている人。
- あまり関係がない人: 別の型番や他社版の端末を使う人。自分の機種の案内を別途確認すればよい。
- 専門用語: OS → スマホの基本動作を支えるソフト。
- One UI → SamsungがGalaxy向けに用意する画面と操作の仕組み。
- セキュリティパッチ → 安全上の弱点を直す更新。
- 型番 → 同じ製品名の中で販売版を見分ける番号。
- バックアップ → 写真や連絡先などを別の場所に保存すること。
- Smart Switch → Samsungが提供するパソコン経由の更新用ソフト。
- 事実から言えること: 5機種のドコモ版で10月27日から更新が案内されている。更新前に準備が必要。
- 事実から言えないこと: 全員に同時に通知される、どのアプリも動く、電池が長持ちする、他社版も同日開始した、とは言えない。

## 読者への順序

最初に「何の更新か」、次に「自分の型番は対象か」、それから「どう更新するか」と「始める前に何をするか」を示す。キャラクターのひまりは自分のスマホが対象かを尋ね、らぼまるは型番と公式案内の確認方法を整理する。視覚図は更新の体験、型番確認、準備、注意を1枚ずつ分ける。
