# ChatGPTの中の「働くAI」、Codexって何？ ブラウザ内蔵の強みとClaude Codeとの違い

Codexは、質問に答えるだけでなく、ファイルを読み、コードを書き、ブラウザで確かめ、画像を作り、成果物として保存するところまで進めるAIエージェントです。違いが見えやすいのは、モデルの点数より「どの作業場所を渡すか」です。

## 先に結論

CodexとClaude Codeは、どちらも強力な作業AIです。違いは、Codexが内蔵ブラウザや画像生成まで同じ作業線に載せやすいこと、Claude側はClaude Codeと普段のChromeを使う拡張を組み合わせやすいこと。優劣ではなく、何をさせたいかで選びます。
