# Claude for Teachersとは？米国の先生に1年間無料、日本との関係をやさしく整理

Anthropicが、米国の教員向けに「Claude for Teachers」の無償提供を始めました。

授業案を作るだけでなく、教育基準に沿った教材探し、クラスデータの整理、毎日の定例作業の自動化まで想定したサービスです。

ただし、対象は米国の認証済みK-12教員に限られます。日本の先生が今すぐ無料で使える制度ではありません。

この記事では、何が始まったのか、なぜ注目されているのか、プライバシー面で何に注意すべきかを整理します。

## 先に結論

Claude for Teachersは、米国の教員にプレミアムClaude機能を1年間無償提供し、AIを授業準備から学校業務の自動化まで広げようとする取り組みです。

- 対象は米国の認証済みK-12教員個人で、日本は現時点で対象外
- 2027年6月30日までに登録すると、プレミアムClaude機能を1年間無料で利用できる
- 授業案の作成だけでなく、教育基準の参照、クラスデータ分析、定例作業の自動化まで含まれる

入力したデータはモデル学習に使わないとされています。ただし、生徒データを自由に入力してよいわけではなく、学校側の権限やルールの確認が必要です。

## 何が始まった？

今回始まったのは、米国のK-12教員向けに用意された専用のClaudeプランです。

Anthropicは2026年7月14日、「Claude for Teachers」を発表しました。

対象となるのは、米国のK-12学校で働く認証済みの個人教員や教育職員です。学校のメールアドレスなどを使って、対象者であることを確認する仕組みです。

K-12は、米国の幼稚園から高校卒業相当までの教育段階を指します。

### 利用条件

| 項目 | 内容 |
|---|---|
| 対象 | 米国の認証済みK-12教員・教育職員 |
| 申込期限 | 2027年6月30日まで |
| 無償期間 | 認証後から1年間 |
| 対象地域 | 米国のみ |
| 日本からの利用 | 現時点では対象外 |
| 生徒の利用 | 教員向けであり、生徒向けサービスではない |

ここで重要なのは、「教員なら誰でも無料」ではないことです。

米国の対象者向け制度であり、日本の学校に勤務する先生が、そのまま申し込めるサービスではありません。

また、1年間無料という案内であり、永久に無料で使えると決まったわけでもありません。無料期間終了後の料金や継続条件は、現時点では明らかになっていません。

## 無料で使えるのは何？

無償提供の中身は、単なるチャット機能だけではありません。

Claude for Teachersには、通常の無料版より利用枠の広いプレミアムClaude機能が含まれます。公式ヘルプでは、Claude Pro相当の機能を含む教員向けプランとして説明されています。

主な内容は次の通りです。

- プレミアムClaude機能
- 教員向けのスキル
- Learning Commonsとの接続
- Claude Code
- Claude Cowork
- クラスデータの分析
- 定例作業の自動化

ただし、利用回数やClaude Code、Coworkの正確な上限は公表されていません。

「有料版とまったく同じ条件で無制限に使える」とは書かない方が安全です。

## 授業準備だけではない

今回の注目点は、AIに授業案を書かせるだけで終わっていないことです。

Claude for Teachersでは、教材の整理や学校業務の流れそのものにAIを組み込む使い方が想定されています。

### Learning Commonsで教育基準を参照

Learning Commonsとの接続では、米国50州の教育基準や、学習の順序、前提となる技能、カリキュラム情報を参照できます。

たとえば、先生が授業案を考えるときに、単に「中学生向けの数学問題を作って」と頼むだけでなく、州ごとの教育基準に沿って内容を確認しやすくなります。

これは、一般的なAIチャットとの大きな違いです。

一方で、対応しているのは米国の教育基準です。

日本の学習指導要領や教科書、評価基準に対応しているとは発表されていません。

### クラスデータをまとめて分析

公式には、次のような情報をまとめて扱う例が示されています。

- 名簿
- 診断結果
- 出欠状況
- 教員のメモ
- 学習状況に関する記録

これらをもとに、つまずいている生徒の傾向を整理したり、クラス全体の状況を確認したりする使い方が想定されています。

ただし、データを入力できることと、入力してよいことは別です。

特に氏名、成績、出欠、診断情報などは慎重に扱う必要があります。

### 毎日の作業を自動化

Claude CodeやClaude Coworkを使い、定例作業を自動化する例も紹介されています。

公式発表では、毎日午後4時に退室チケットを確認する処理が例として挙げられています。

退室チケットとは、授業の最後に生徒が理解度や疑問点を書いて提出する短い振り返りです。

これまで先生が毎日手作業で確認していた内容を、AIが整理し、傾向をまとめる使い方が考えられます。

## なぜ話題になっている？

Claude for Teachersが注目される理由は、教育AIの役割が一段広がったためです。

これまで教員向けAIは、次のような使い方が中心でした。

- 授業案を作る
- 問題文を作る
- 保護者向けの文章を整える
- 教材の説明を簡単にする

Claude for Teachersは、そこからさらに踏み込み、データ整理や日々の業務フローまで対象にしています。

つまり、AIが「質問すると答えてくれる道具」から、「学校の仕事を一部支える道具」に変わり始めた動きと見られます。

Anthropicは、授業準備や事務作業の時間を減らし、先生が生徒と向き合う時間を増やせると説明しています。

ただし、これは現時点では企業側が示している狙いです。

実際にどれだけ作業時間が減るのか、授業の質や生徒の学習成果が上がるのかは、まだ十分に検証されていません。

## 生徒データはモデル学習に使われない

プライバシー面では、Claude for Teachersに入力したデータは、Anthropicのモデル学習に使わないとされています。

対象には、次のものが含まれます。

- チャットに入力した内容
- アップロードしたファイル
- 外部サービスから接続した情報
- Claudeが生成した出力

学校でAIを使う場合、生徒の情報がAIモデルの改善に再利用されるのではないか、という不安があります。

その点について、Anthropicは学習には使わないと明記しています。

これは重要な安心材料です。

ただし、「モデル学習に使わない」ことと、「どんな生徒情報でも入力してよい」ことは同じではありません。

## FERPA認証済みとは言えない

Anthropicは、米国の学校向けにK-12 Data Processing Addendumを用意しています。

これは、生徒データをどのように処理するかを定めた契約文書です。

公式には、米国の教育記録に関する法律であるFERPAに沿うよう設計された仕組みとして説明されています。

ただし、ここは表現に注意が必要です。

### 誤解しないための整理

- 「FERPAに沿うよう設計されている」  
  → 公式情報で確認できる

- 「FERPAの第三者認証を取得している」  
  → 確認できない

- 「FERPA認証済みだから絶対安全」  
  → そのようには言えない

そのため、「FERPA準拠の安全なサービス」と断定するより、「FERPAへの対応を意識した契約と設計が用意されている」と表現する方が正確です。

## 生徒データを自由に入力できるわけではない

Claude for Teachersの規約では、教員が生徒データを処理するための権限を持っていることが求められています。

つまり、個人の判断だけで生徒の氏名や成績を入力してよいとは限りません。

学校や学区のルール、契約、情報管理方針に従う必要があります。

日本で似たサービスが提供された場合も、確認すべき点は同じです。

### 入力前に確認したいこと

- 学校や教育委員会が利用を認めているか
- 児童・生徒の氏名を入力してよいか
- 成績や出欠情報を扱ってよいか
- 診断情報や支援記録を入力してよいか
- ファイルがどこに保存されるか
- 外部サービスと接続してよいか

モデル学習に使われないとしても、校内規程や個人情報保護の確認は別に必要です。

## 教員向けスキルは「巨大ライブラリ」とは限らない

Claude for Teachersでは、教員向けのスキルが用意されています。

授業計画の作成や、理解度に応じた授業内容の調整などが確認できます。

ただし、現時点で公開されている内容だけから、「大量の教育機能がそろった巨大ライブラリ」と断定するのは早いでしょう。

今後追加される可能性はありますが、現在確認できる機能と、将来の期待は分けて考える必要があります。

## AFT認証済みではない

Anthropicは、米国教員連盟AFTのGold Standardを踏まえた設計であると説明しています。

ただし、AFTの基準は策定中とされており、Claude for TeachersがAFTから正式認証を受けたと確認できる情報はありません。

そのため、次のように整理するのが安全です。

- AFTの考え方を参考にしている
- AFTと教育AIの基準づくりに取り組んでいる
- AFT認証済みとは言えない

企業や団体との協力があることと、第三者認証を取得していることは別です。

## 確定していること・未確定なこと

| 区分 | 内容 |
|---|---|
| 確定 | 米国の認証済みK-12教員が対象 |
| 確定 | 2027年6月30日までの登録で1年間無料 |
| 確定 | プレミアムClaude機能を利用可能 |
| 確定 | Learning Commons、Claude Code、Coworkを利用可能 |
| 確定 | 入力データはモデル学習に使わない |
| 確定 | 現在は個人教員向け |
| 未確定 | 日本向けに提供されるか |
| 未確定 | 日本の学習指導要領に対応するか |
| 未確定 | 無料期間終了後の料金 |
| 未確定 | 利用回数や各機能の正確な上限 |
| 未確定 | 学校・学区向けプランの開始日 |
| 未確定 | 実際にどれだけ業務時間を減らせるか |

学校・学区向けの専用提供は「coming soon」と案内されていますが、開始日や料金、管理機能は発表されていません。

## 日本の先生にはどう関係する？

日本の先生が今すぐClaude for Teachersへ申し込めるわけではありません。

そのため、現時点では「無料だから使ってみよう」というサービス紹介ではなく、海外で教育AIがどこまで進み始めたかを見るニュースとして捉えるのがよいでしょう。

特に注目したいのは、AIの利用範囲です。

- 授業案の作成
- 教材の整理
- 教育基準の確認
- クラス状況の分析
- 定例作業の自動化

AIの役割が、文章作成から学校業務の仕組みづくりへ広がっています。

日本で同様のサービスが始まる場合も、料金や性能だけでなく、学校単位で管理できるか、生徒データをどこまで扱えるかが重要になります。

## 今の段階で注目したい人

Claude for Teachersは日本では対象外ですが、次のような人には動向を追う意味があります。

- 学校でAI活用を検討している教員
- 教育委員会や学校の情報管理を担当している人
- 授業準備や校務の効率化を考えている人
- 教育向けAIサービスを比較している人

一部の研修教材や教員向けスキルは公開されているため、考え方や使い方を参考にすることはできます。

ただし、生徒データを使った実践を独自に始めるのではなく、まずは個人情報を含まない教材作成や業務整理から考えるのが安全です。

## まだ様子を見た方がよいこと

次の点は、追加情報を待つ必要があります。

- 日本向け提供の予定
- 日本語や学習指導要領への対応
- 学校・教育委員会向けの管理機能
- 無料期間終了後の料金
- 実際の業務削減効果
- 生徒データを扱う場合の運用ルール

特に、日本の法令や自治体の情報セキュリティ規程に合うかは、米国向けの説明だけでは判断できません。

## まとめ

Claude for Teachersは、米国の認証済みK-12教員に、プレミアムClaude機能を1年間無償提供する取り組みです。

授業案の作成だけでなく、米国50州の教育基準への接続、クラスデータの分析、定例作業の自動化まで含まれる点が大きな特徴です。

一方で、日本の先生は現時点で対象外です。

入力データをモデル学習に使わない設計は重要ですが、FERPA認証済みと断定することはできず、生徒データの利用には学校側の権限やルール確認も必要です。

今回のニュースで見えてきたのは、教育AIが「文章を作る便利なチャット」から、「学校の仕事の流れを支える仕組み」へ進み始めていることです。

日本で同様のサービスが登場したときは、無料かどうかだけでなく、誰が使えるのか、どのデータを扱えるのか、学校側が管理できるのかまで確認する必要があります。
