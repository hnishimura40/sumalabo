## 採用する主題と理由

**質問や情報収集を助ける既存サービスに、スマホから呼び出す専用アプリが加わった。その変化と、任せられる範囲を説明する。**

LINEヤフーは2026年11月10日、Agent iのiOS版アプリの提供開始を発表した。ホーム画面から利用する入口、ウィジェットによる機能の起動、タスク完了のお知らせが未読の場合のアプリ通知が、今回説明できる変化となる。[公式発表](https://www.lycorp.co.jp/ja/news/release/020972/)

専用アプリで何が変わるかは公式情報から説明できる。一方、回答性能の向上、競合に対する優位、利用者の増加を示す資料はない。**利用経路と通知の変化に範囲を限定して採用する。**

当サイトの試用や測定を核とする題材ではないため、カテゴリは「ニュースをかみくだく」とする。

## なぜ今注目するか

11月10日に専用アプリの提供開始が発表され、既存サービスの使い方に具体的な選択肢が増えたため。11月11日時点で、その変化を整理する意味がある。

Agent i自体は4月、情報収集のタスク機能は9月に開始済み。「サービスの登場」「あとで調べて知らせる機能の追加」「専用アプリの登場」を分けると、今回初めて可能になったことを読み違えずに済む。[サービス開始の発表](https://www.lycorp.co.jp/ja/news/release/020366/)、[タスク機能の発表](https://www.lycorp.co.jp/ja/news/release/020805/)

複数媒体への掲載は採用情報に含まれる観測結果として扱う。社会的な大流行、利用増加、アプリ順位の上昇を示す根拠にはしない。

## AIの視点で理解できること

AIの説明は、**その場で質問に答える使い方と、調べたい内容を登録してあとから知らせを受け取る使い方の違い**に使う。

そのうえで、今回増えた専用アプリやウィジェットは、こうした機能を呼び出したり、お知らせを受け取ったりする入口だと整理する。入口の追加を、回答の賢さの向上と結び付けない。

「AIエージェント」という名称だけから、あらゆる作業を自動で最後まで行うものと説明しない。確認できた機能ごとに、何を頼めるかを示す。

## 読者翻訳設計

### 主題の一言説明

質問に答えたり、頼んだ情報を調べて知らせたりするサービスに、スマホのホーム画面から呼び出せる専用アプリが加わった話。

### 関係がある人

- Agent iを繰り返し使い、ホーム画面から呼び出したい人。
- 登録した情報収集の結果を、アプリの通知で確認したい人。
- iPhoneで使えるAIサービスを探していて、質問への回答と情報収集の違いを知りたい人。

利用可能な機種や最低対応版は未確認のため、すべてのiPhone利用者が導入できるとは書かない。

### あまり関係がない人

- 既存のLINEやYahoo! JAPANアプリからの利用で足りている人。
- 情報収集の結果を通知で受け取る必要がない人。
- Android版の専用アプリを今すぐ使いたい人。提供開始日は未確認だが、既存経路からの利用とは分けて説明する。
- 今回の発表に、回答性能の向上や購入・予約の自動化を期待している人。その期待を裏付ける情報は確認できていない。

### 公開本文で使う専門語・固有機能名

以下の表記を使用予定語とし、初出の同じ文か直後の一文で説明する。

- AI → 質問への回答や情報の整理などをコンピューターに行わせる技術。
- Agent i → LINEヤフーが提供する、質問への回答や情報収集を助けるサービス。
- AIエージェント → 依頼に応じて調査などの作業を進める仕組み。できる作業はサービスごとに異なる。
- アプリ → スマホなどに入れて使う、目的に応じた機能を持つもの。
- iOS → iPhoneを動かす基本の仕組み。
- Android → さまざまなメーカーのスマホなどで使われる、端末を動かす基本の仕組み。
- ウィジェット → ホーム画面に置ける、機能を呼び出す小さな入口。
- チャット → 文章などをやり取りして相談すること。
- 画像入力 → 写真などの画像を渡して質問すること。
- 音声入力 → 話した内容で質問を入力すること。
- タスク機能 → 調べたい内容や条件を登録し、結果のお知らせを受け取る仕組み。
- ログイン → 登録した利用者としてサービスに入ること。
- LINEアカウント → LINEに登録した利用者情報。
- Yahoo! JAPAN ID → Yahoo! JAPANのサービスを登録した利用者として使うための識別情報。

本文で専門語や別表記を追加する場合は、この一覧にも一語ずつ追加する。採用しない詳細機能や技術用語を、説明のためだけに増やさない。

### 事実から言えること

- 既存サービスに専用アプリという利用経路が加わった。
- ウィジェットから、確認された三つの機能を起動できる。
- タスク完了のお知らせが未読の場合に、専用アプリから通知する仕組みが案内されている。
- 自由入力にはログインが必要。
- 専用アプリ以外の利用経路も案内されている。

### 事実から言えないこと

- 回答性能が向上した、競合より優れている。
- ホーム画面上だけで回答まで完結する。
- 通知が即時に、確実に届く。
- 商品価格を常時監視し、条件達成後も継続して知らせる。
- 購入や予約を自動で完了できる。
- 料金、対応機種、Android版の開始日が確定している。
- 国内企業のサービスであることを理由に、入力情報が国内だけで処理される。

## 本文へ引き継ぐ構成と注意点

冒頭は「これは何か」「何があったか」「誰に関係するか」「結局どう捉えるか」の四点で短く説明する。続いて、既存サービスと今回の追加点、ウィジェットと通知の働き、利用条件の順に進める。

図解や表では、**従来からあるもの／今回加わったもの**と、**機能を呼び出す／調べた結果を知らせる**を整理する。本文ではログイン条件、未読時の通知、未確認事項を補う。導入するかどうかの判断は後半の短い補助とする。

ひまりは「アプリができたら、買い物まで任せられるの？」という疑問を拾い、らぼまるは確認できた情報収集・お知らせの範囲を示す。試用したような発言は作らない。

料金と最低対応版は、調査で未確認であることを明示する。具体的な数値を追加する場合は公式表示の確認が必要。公式ガイドラインにある回答の誤りや入力情報への注意も、利用上の条件として短く扱う。[公式ガイドライン](https://search.yahoo.co.jp/chat/guidelines/generativeaiguideline)
