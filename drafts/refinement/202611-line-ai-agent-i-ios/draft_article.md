# 質問や情報収集を助ける「Agent i」、iPhone用の入口が増えた

## 30秒で分かる

- **これは何？**  
  Agent i（LINEヤフーが提供する、質問への回答や情報収集を助けるサービス）は、日常の疑問や調べものを相談できるものです。AI（質問への回答や情報の整理などをコンピューターに行わせる技術）を使っています。

- **何があった？**  
  LINEヤフーが2026年11月10日、専用のアプリ（スマホなどに入れて使う、目的に応じた機能を持つもの）の提供開始を発表しました。今回はiOS（iPhoneを動かす基本の仕組み）版で、ホーム画面からの起動や、調べた結果のお知らせに連動する通知に対応しています。[公式発表](https://www.lycorp.co.jp/ja/news/release/020972/)

- **誰に関係ある？**  
  Agent iをよく呼び出す人や、情報収集の結果を通知で受け取りたい人に関係します。今のLINEやYahoo! JAPANからの利用で足りている人は、追加を急ぐ必要は薄いでしょう。

- **結局どうなの？**  
  ふだん使うスマホから、相談を始めたり、お知らせに気づいたりするための選択肢が増えました。専用アプリを入れる意味は、自分がその入口や通知を使うかどうかで考えられます。

## そもそも、Agent iは何をするもの？

**その場で相談する使い方と、調べたい内容を登録してあとから知らせてもらう使い方があります。**

たとえば、家電選びの相談をしたり、おでかけ先の候補を考えてもらったりできます。Agent i自体は2026年4月20日に始まっており、LINEやYahoo! JAPANから利用できるサービスとして提供されてきました。[サービス開始の公式発表](https://www.lycorp.co.jp/ja/news/release/020366/)

もう一つが、タスク機能（調べたい内容や条件を登録し、結果のお知らせを受け取る仕組み）です。こちらは9月11日に提供開始済みで、気になるテーマの最新情報などを、指定したタイミングで確認できます。[タスク機能の公式発表](https://www.lycorp.co.jp/ja/news/release/020805/)

Agent iは「AIエージェント」と呼ばれています。**AIエージェントとは、依頼に応じて調査などの作業を進める仕組みです。** 任せられる作業は、サービスごとに異なります。

> **ひまり：** 専用アプリができたら、買い物や予約まで任せられるの？  
> **らぼまる：** 今回の発表で確認できるのは、情報収集やお知らせ、それを呼び出す入口だよ。購入や予約をどこまで自動で済ませられるかは、この発表だけでは分からないんだ。

## あなたに関係ある？

**ふだんAgent iをどう使っているかで、今回の変化の大きさは変わります。**

| 関係がある人 | あまり関係がない人 |
|---|---|
| 繰り返し相談し、ホーム画面から呼び出したい人 | 今のLINEなどからの利用で足りている人 |
| 情報収集の結果を通知で確認したい人 | 結果の通知を必要としていない人 |
| iPhoneで使う相談先を探している人 | 回答性能の向上を今回の発表に期待している人 |

これは、公表された機能から考えた使い分けです。専用アプリの操作性や回答性能を比較測定した評価ではありません。

Android（さまざまなメーカーのスマホなどで使われる、端末を動かす基本の仕組み）版の専用アプリは、11月10日の発表では順次提供予定とされています。開始日は確認できていません。[公式発表](https://www.lycorp.co.jp/ja/news/release/020972/)

AndroidのスマホでAgent iを使うことと、Android版の専用アプリを使うことは分けて考えましょう。LINEやYahoo! JAPANなど、既存の利用経路も案内されています。[公式の利用案内](https://events.yahoo.co.jp/agent-i/)

## 今回、何が変わった？

**専用アプリが加わり、ホーム画面から相談を始める入口が増えました。**

ウィジェット（ホーム画面に置ける、機能を呼び出す小さな入口）を設定すると、次の三つを起動できます。

| 起動できるもの | 何をするもの？ |
|---|---|
| 新規チャット | チャット（文章などをやり取りして相談すること）を新しく始める |
| 画像入力 | 画像入力（写真などの画像を渡して質問すること）を始める |
| 音声入力 | 音声入力（話した内容で質問を入力すること）を始める |

確認できたのは、これらの機能を呼び出せることです。ホーム画面上だけで回答の確認まで完結する、という案内ではありません。[ウィジェットの公式説明](https://www.lycorp.co.jp/ja/news/release/020972/)

## 何が便利になるの？

**「相談を始めたいとき」と「結果を受け取りたいとき」に、専用の入口を使えます。**

ウィジェットは、相談の始め方を選ぶ入口です。一方、通知は、登録しておいた情報収集の結果に気づくためのものです。

通知には条件があります。タスクの実行が完了すると、まずAgent iのトップ画面にお知らせが届き、**そのお知らせが未読の場合に、専用アプリから通知されます。** 通知が届く速さや確実さは、実機で検証していません。[通知の公式説明](https://www.lycorp.co.jp/ja/news/release/020972/)

情報収集の具体例には、気になるテーマのニュースを毎週確認する使い方があります。LINEヤフーは、同じ情報を自分で繰り返し探す手間を減らすことを目指しています。[タスク機能の公式説明](https://www.lycorp.co.jp/ja/news/release/020805/)

> **ひまり：** たまに質問するだけでも、専用アプリを入れたほうがいい？  
> **らぼまる：** 今の入口で困っていなければ、そのまま使う選び方もあるよ。ホーム画面から呼び出したいか、結果の通知を使いたいかが、追加を考えるポイントだね。

## 使う前に知っておきたい注意点

**自由に質問を入力するには、登録した利用者として入る必要があります。**

ログイン（登録した利用者としてサービスに入ること）には、次のいずれかを使えます。

- **LINEアカウント（LINEに登録した利用者情報）**
- **Yahoo! JAPAN ID（Yahoo! JAPANのサービスを登録した利用者として使うための識別情報）**

ログインしなくても一部の機能は利用できますが、専用アプリで自由に文章を入力するにはログインが必要です。[利用条件の公式説明](https://www.lycorp.co.jp/ja/news/release/020972/)

また、専用アプリの料金・追加料金の有無、対応機種、必要なiOSの最低バージョンは今回未確認です。導入前に公式の配布案内から、自分の端末で使えるかと料金表示を確認してください。LINEやYahoo! JAPANアプリの対応条件を、専用アプリにそのまま当てはめることはできません。

回答の内容にも確認が必要です。公式ガイドラインでは、回答に誤りが含まれる可能性を示し、機密情報や他人に知られたくない情報を入力しないよう案内しています。商品を買う前や施設へ出かける前には、販売元や施設の公式情報も確認しましょう。[公式ガイドライン](https://search.yahoo.co.jp/chat/guidelines/generativeaiguideline)

年齢については、13歳未満は利用を控え、13歳以上の未成年者は保護者などの同意を得るよう案内されています。[年齢に関する公式案内](https://search.yahoo.co.jp/chat/guidelines/generativeaiguideline)

## もう少し詳しく：サービス開始とアプリ登場は別の出来事

**4月・9月・11月の変化を分けると、今回加わったものが分かります。**

| 時期 | 起きたこと |
|---|---|
| 2026年4月20日 | Agent iのサービス開始 |
| 2026年9月11日 | 情報収集のタスク機能を提供開始 |
| 2026年11月10日 | iOS版専用アプリの提供開始を発表 |

出典：[4月の発表](https://www.lycorp.co.jp/ja/news/release/020366/)、[9月の発表](https://www.lycorp.co.jp/ja/news/release/020805/)、[11月の発表](https://www.lycorp.co.jp/ja/news/release/020972/)

値下がり通知も、9月に案内された機能です。当時の公表仕様では、指定したタイミングで価格を確認し、登録時より指定額以上下がった場合に一度通知します。その後は、その商品の価格追跡を終了します。ずっと価格を見張り続け、何度も知らせる仕組みとは異なります。[値下がり通知の公式説明](https://www.lycorp.co.jp/ja/news/release/020805/)

専用アプリの登場によって、こうした既存機能をスマホから呼び出し、お知らせを受け取る方法が増えた、と捉えると今回の意味がつかめます。

## すまラボまとめ

**Agent iをよく使う人には、ホーム画面からの起動と、未読のお知らせに連動する通知が検討材料になります。**

今のLINEやYahoo! JAPANからの利用で足りていれば、追加を急ぐ理由は薄いでしょう。試す場合は、自分の端末で使えるか、料金表示はどうなっているかを確認したうえで、ふだんの相談や情報収集に役立つ入口かを見てみてください。

*情報確認日：2026年11月11日。公式発表・案内に基づく説明です。専用アプリの実機検証は行っていません。*
