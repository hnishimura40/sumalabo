# Research Pass: Astra提供待ちのbanked reset

- 対象日: 2026-09-05 JST
- slug: 202609-chatgpt-astra
- 選定ソース: https://www.itmedia.co.jp/aiplus/article/2609/04/2000001165/

## facts

1. OpenAIは2026年9月3日にGPT-6 Astraを発表した。発表時点では一部組織から提供を始め、Plus、Pro、Business、Enterprise、APIなどへ数日かけて展開すると案内している。
   - https://openai.com/index/gpt-6-astra/
2. OpenAI Help Centerはbanked resetを「使うまでアカウントに保存される、1回限りのCodex利用上限リセット」と説明している。自動回復や購入クレジットとは別物で、利用者が設定画面から適用する。
   - https://help.openai.com/en/articles/20001498-how-banked-codex-resets-work
3. banked resetを使うと、対象となるCodexの5時間枠と週次枠が更新され、次回の週次リセット日が変わる場合がある。何も回復させる必要がない状態なら、権利は消費されない。
   - https://help.openai.com/en/articles/20001498-how-banked-codex-resets-work
4. OpenAIの現行ヘルプは、Astraの提供状況と利用上限がChat、Work、Codex、契約プランによって異なると案内している。
   - https://help.openai.com/en/articles/20001354-gpt-56-and-gpt-6-pro-in-chatgpt

## claims

1. OpenAIでCodexとChatGPTを担当するThibault Sottiaux氏は、Astraをまだ利用できない有料ChatGPTプランの利用者に対し、利用できない日ごとにbanked resetを1回分付与するとXへ投稿した。ITmediaとPC Watchが2026年9月4日に同じ投稿を報じている。
   - https://x.com/thsottiaux/status/2095651088502591861
   - https://www.itmedia.co.jp/aiplus/article/2609/04/2000001165/
   - https://pc.watch.impress.co.jp/docs/news/2138190.html
2. 投稿では最初の1回が約3時間後に届く見込みとされた。これは配布開始時点の案内で、個々のアカウントへの到着時刻を保証するものではない。

## uncertain_points

1. 告知文の「有料ChatGPTプラン」だけでは、すべての契約・地域・ワークスペースで同じ条件になるかまでは確定できない。Help Centerも対象条件は施策ごとに異なるとしている。
2. 今回付与分の有効期限は告知投稿だけでは確認できない。過去施策の30日を今回にも自動適用しない。設定画面に出る期限を正とする。
3. 「毎日リセット」は自動で利用枠が満タンになる意味ではない。日ごとに保存型の権利が付くという告知であり、適用操作が必要である。
4. Astraの全対象者への展開完了日は未確定。数日中という公式案内以上の日付を断定しない。

## 記事で守る境界

- 「ChatGPTの通常チャットが毎日無制限になる」とは書かない。
- banked resetと自動リセット、追加クレジット、Astraの提供枠を混同しない。
- 実際の対象可否、残数、期限は各利用者の「設定 → 使用量」で確認するよう案内する。
