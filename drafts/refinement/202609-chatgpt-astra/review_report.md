# セルフレビュー: Astra待ちのリセット権

## Pass 1: 表現・断定・線引き

- 合格: 「毎日リセット」を自動回復と誤認させず、保存型の権利と説明した。
- 合格: 配布方針はOpenAI担当者の公開投稿に基づく報道として距離を保った。
- 合格: 一律の対象条件、付与時刻、有効期限、展開完了日を断定していない。

## Pass 2: 読者向け説明・構成

- 合格: 冒頭で「自動回復ではない」という結論を先に示した。
- 合格: 30秒欄は「これは何？／何があった？／誰に関係ある？／結局どうなの？」の4項目だけで概要が分かる。
- 合格: banked reset、利用上限、5時間枠、週次枠、段階展開を初出付近で説明した。
- 合格: 関係がある人と影響が小さい人を分けた。
- 合格: 設定の「使用量」で残数・期限・現在枠を見るという実行可能な案内がある。
- 合格: 既存Astra発表記事とは役割が重ならず、内部リンクで補完できる。
- 合格: キャラクターは「自動なの？」「いつ使う？」という読者の疑問を代弁できる設計にした。

## Pass 3: 事実・数値・出典

- 合格: 2026年9月3日の発表、数日かけた段階展開はOpenAI公式発表と一致。
- 合格: banked resetの保存型・手動適用・5時間枠と週次枠への効果はOpenAI Help Centerと一致。
- 合格: 日ごとに1回分という配布告知はITmediaとPC Watchの2媒体で一致。
- 合格: 今回分の有効期限は不明として、過去施策の期限を転用していない。
