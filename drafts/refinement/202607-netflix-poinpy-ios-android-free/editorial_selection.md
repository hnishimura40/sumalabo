# Editorial Selection — Poinpy（ポインピー）Netflix限定終了→iOS/Androidで無料配信

## 採用方針の一言

**「Netflix契約なし・無料・広告なしで遊べるようになった」という実用的な変化を主軸にし、日本語対応など未確認の部分は断定せず補足にとどめます。**

| 対象論点 | 判断 | 理由・記事での扱い |
|---|---|---|
| (1) Poinpyの正体 | **採用** | どんなゲームか分からない読者向けに必要。「縦スクロール型のジャンプアクション」「Downwell作者のOjiro Fumoto氏が開発」「Devolver Digitalが販売」まで簡潔に紹介する。 |
| (2) Netflix Games限定だった経緯 | **採用** | 今回のニュースの前提として重要。2022年にNetflix Games限定で登場し、これまではNetflix契約が必要だったと説明する。契約終了の詳しい事情は触れすぎない。 |
| (3) Netflix契約なしでApp Store／Google Play無料配信 | **採用** | 日本のスマホユーザーにとって最も重要な変更点。現在はNetflixアカウントなしで単独アプリとして入手できる、と結論部分で先に伝える。配信開始日は「2026年7月23日ごろ」と慎重に書く。 |
| (4) 料金・広告・任意課金の整理 | **採用** | 「無料でも広告や課金が多いのでは」という疑問に直結する。本編無料・広告なし・必須課金なし、アプリ内課金は任意のチップと整理する。 |
| (5) 日本配信・日本語対応 | **限定採用** | Android版が日本向けGoogle Playに掲載されている点は採用。一方、日本のApp Storeでの配信状態とゲーム内の日本語対応範囲は未確認なので、「日本語で遊べる」とは断定しない。 |
| (6) 誤解されやすい点 | **採用** | 誤読防止に有効。「すべてのNetflixゲームが無料化されたわけではない」「アプリ内課金表示があっても強制課金ではない」「Netflix版から独立アプリとして再配信された形」と整理する。 |

### 不採用とする情報

| 情報 | 判断理由 |
|---|---|
| NetflixとDevolver Digitalの契約終了理由 | 詳細が未確認で、記事の中心にも不要。 |
| チップの具体的な価格帯 | 日本向け金額が未確認。料金表のように扱うと誤解を招く。 |
| Netflix版からのセーブデータ移行可否 | 未確認のため本文では断定しない。必要なら「引き継ぎ可否は確認できていない」と注意書きに限定する。 |
| 全開発スタッフや制作体制の詳細 | 日本のスマホユーザーが今回の変更を理解するうえで優先度が低い。 |
