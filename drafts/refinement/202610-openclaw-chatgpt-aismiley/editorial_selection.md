# Editorial Selection — OpenClawを始める前の判断軸

採用: OpenClawを「自分で動かすAIアシスタントの土台」と説明し、ChatGPTとの使い方、費用、権限の違いを整理する。日本のWindows利用者にも選択肢があるため、日本の読者の判断材料を提供できる。カテゴリ: ニュースをかみくだく。実機検証ではない。

限定採用: AIsmileyの見出しは関心の出発点としてのみ扱う。二次記事の料金や安全性評価は引用しない。

不採用: 「無料で使い放題」「ChatGPTより安全」「誰でも数分で導入できる」など、条件を欠く断定。

## 読者翻訳設計

- 主題の一言説明: OpenClawは、選んだAIを自分のPCなどで動く窓口につなぎ、チャットや作業の補助に使うための仕組み。
- 関係がある人: メッセージアプリを窓口にして作業を自動化したい人、自分で接続先と権限を管理できる人。
- あまり関係がない人: ブラウザで質問や文章作成ができれば十分な人、PC上で常時動かす仕組みを管理したくない人。
- 専門用語: Gateway → AIとチャットアプリをつなぐ常駐の窓口。
- 専門用語: モデル → 文章を考えて返すAI本体。
- 専門用語: API → アプリ同士がAIの機能を呼び出す接続方法。
- 専門用語: 認証 → 接続相手が本人・許可済みか確かめる仕組み。
- 専門用語: ループバック → 同じ機器からだけ接続できる設定。
- 専門用語: WSL2 → Windows上でLinuxの環境を動かす仕組み。
- 事実から言えること: OpenClawにはWindows向けの導入経路があり、接続先・使い方で費用とリスクが変わる。
- 事実から言えないこと: すべての人が無料で使える、ChatGPT契約だけですべての連携が使える、初期設定なら必ず安全、とは言えない。

## 読者への結論

会話中心ならまず既存のChatGPTを使い続ければよい。複数のサービスをつないで自分の環境で動かしたい人は、必要な連携を一つに絞り、公式資料で費用と権限を確認してから試す。
