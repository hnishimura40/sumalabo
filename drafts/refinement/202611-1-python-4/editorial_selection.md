## 判定理由と記事の核

無料講座の募集開始を入口に、「データから予測するとは何か」「4週間の講座で何を扱い、何までは保証されないか」を解説する範囲で採用する。

調査報告によれば、公式カリキュラムには決定木・ランダムフォレストと生成AIのコラムがある。AIの予測に関わる具体的な学習内容を根拠に、記録された数値と予測した数値の違いを説明できる。[講座紹介](https://gacco.org/stat-japan3/)

一方、生成AIの使い方を体系的に学べる講座、4週間で仕事に使える能力が身に付く講座としての紹介は採用しない。学習効果や受講体験の裏付けがなく、開講前でもある。

実受講・独自の操作検証は記事の核にしないため、`hands-on`は選ばない。

## なぜ今取り上げるか

総務省統計局は2026年11月10日に受講者募集を開始し、2027年1月12日の開講を案内している。日本の読者に、費用と学習内容を確認して受講を検討できる新しい選択肢ができたことにニュース性がある。[総務省の報道資料](https://www.stat.go.jp/info/guide/public/houdou/pdf/ho261110.pdf)

採用情報には、2026年11月13日19時30分ごろのGoogleニュース科学欄とITmedia AI+の掲載記録がある。ただし、Googleニュース側もITmedia記事への導線であり、独立した2媒体の報道とは数えない。「複数媒体で話題」「人気が急上昇」とする根拠には使わない。

注目する理由は募集開始と具体的な学習内容であり、採用スコアを講座の品質評価や世間の関心の大きさへ置き換えない。

## AIの視点で理解できること

中心にする疑問は、「AIが出した予測は、実際に起きたことを数えた数字とどう違うのか」。

説明は次の順にする。

1. 実際に記録されたデータを整理する。
2. 過去のデータにある関係を使い、まだ分からない値を予測する。
3. 学習に使っていないデータでも当たるか確かめる。

決定木は条件を順に分けて予測する方法、ランダムフォレストは多数の決定木の結果を組み合わせる方法として紹介する。仕組みの一般説明は、開発元の[手法解説](https://scikit-learn.org/stable/modules/ensemble.html#random-forests-and-other-randomized-tree-ensembles)に基づく。

予測結果が出ることと、その結果が信用できることは別である。過学習と評価の説明は、開発元の[評価ガイド](https://scikit-learn.org/stable/modules/cross_validation.html)を根拠にする。ただし、この講座で評価方法をどこまで実習するか、同開発元のソフトウェアを使うかは未確認。

この説明を除くと、講座の無料案内と日程紹介だけになる。記事では「予測を作る仕組みと確かめ方」を中心的な解説として残し、AIの名称を見出しに添えるだけの構成にしない。

## 誤解と未確認事項の扱い

- **4週間と開講期間を分ける。** 教材は4週間の構成。開講期間は2027年1月12日〜3月16日の予定であり、全員の学習所要時間を示すものではない。[報道資料](https://www.stat.go.jp/info/guide/public/houdou/pdf/ho261110.pdf)
- **登録期限と課題締切を分ける。** 登録期限は2月22日の予定だが、第1〜3週の課題締切はそれより早い。締切後の提出条件は未確認なので、期限直前の登録でも修了できるとは案内しない。[配信元の日程表](https://prtimes.jp/main/html/rd/p/000001477.000012383.html)
- **無料を拡大解釈しない。** 登録料・受講料が無料であることを述べる。教材・端末・通信などを含む費用全体がゼロとは書かない。
- **動画時間を総学習時間に換算しない。** 週あたりの動画本数に資料間の差があり、演習・復習・課題に必要な時間も未確認。
- **受講案内と操作検証を分ける。** スマートフォンだけで全演習を終えられるとは断定しない。
- **登録条件の表示差を推測で解消しない。** 公式は一般募集を案内しているが、調査報告には講座詳細の取得テキストに限定条件らしい表示が混在した記録がある。法人限定とも、登録制約が一切ないとも断定しない。
- **ITmedia記事固有の記述に依存しない。** 調査工程で本文を取得できていないため、確認済みの一次資料を記事の根拠にする。

## 読者翻訳設計

### 主題の一言説明

数字の整理や予測をコンピューターにさせる基礎を学ぶ無料のネット講座が新設され、2027年1月の開講に向けて募集が始まった話。

### 関係がある人

- 仕事や学習で数字を扱い、集計の先にある分析・予測の仕組みを知りたい人。
- Pythonに関心があり、費用を抑えて学習を始める候補を探している人。
- AIの予測結果を、実際に確認された事実と区別して読みたい人。

### あまり関係がない人

- 会話型AIへの質問の仕方だけを、すぐに学びたい人。
- 公的資格や大学の単位を得ることを目的にしている人。
- すでに同程度の分析手法を使っており、専門的な発展内容を求めている人。

### 専門用語

以下を公開本文で使う表記とする。初出の同じ文か直後に説明を添え、略称・別名を追加して説明対象を増やさない。

- 統計解析 → 集めた数字から、特徴や関係を調べること。
- データ分析 → 記録を整理して、傾向や違いを調べること。
- プログラミング → コンピューターにしてほしい処理を、手順として書くこと。
- Python → データの整理や計算にも使われる、コンピューターへの指示を書くための言語。
- gacco → インターネットで講座を受けられる学習サービス。
- Google Colaboratory → ブラウザーでPythonの処理を書いて動かせるサービス。
- Googleアカウント → Googleのサービスにログインするための利用者登録。
- AI → データをもとに、予測や文章作成などを行うコンピューター技術の総称。
- 機械学習 → データにある傾向をコンピューターに学ばせ、予測などに使う方法。
- 生成AI → 指示などに応じて、文章や画像などを作るAI。
- 決定木 → 条件を順番に分けて、予測や振り分けを行う方法。
- ランダムフォレスト → 多数の決定木の結果を組み合わせて、予測などを行う方法。
- 学習 → ここでのAIの説明では、データにある関係をコンピューターに取り込ませること。
- 過学習 → 学ぶときに使ったデータに合わせすぎ、別のデータではうまく予測できなくなること。
- 需要予測 → 商品などが、これからどれくらい必要とされるかを見積もること。
- 修了証 → 講座が定めた学習条件を満たしたことを示す書類。

「学習」は、人が講座を学ぶ意味とAIがデータから学ぶ意味を、文中の主語で区別する。詳しい週別項目を追加して専門語が増えた場合は、本文より先にこの一覧を更新する。

### 事実から言えること

- 登録料・受講料が無料の講座が新設され、募集が始まっている。
- Pythonによる分析・予測の基礎を扱う4週間の教材構成がある。
- 予測に使う具体的な手法と生成AIのコラムが、公式案内に含まれる。
- 他講座の履修は必須ではない。
- 修了を目指す場合は、登録期限だけでなく課題締切の確認も必要になる。

### 事実から言えないこと

- 誰でも4週間で仕事に使える能力を身に付けられる。
- 特定の生成AIサービスや、文章による指示だけで分析を終える方法を学べる。
- AIが講座運営や採点に使われている。
- 講座の予測結果が一定以上の正確さを持つ。
- スマートフォンだけで全課題を完了できる。
- 登録期限までに申し込めば、過ぎた課題締切にも対応してもらえる。
- 学習用と評価用のデータを分ける方法まで、この講座で必ず実習する。
