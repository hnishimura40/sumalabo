# スライド構成 — AI Security Check 2026

## 演出ブロック

- 衣装: ひまりはセキュリティ点検を表すティールと紺の監査ベスト。らぼまるは正本の素体を維持。
- 小道具: 業務用ノートPC、利用一覧カード、書類封筒、接続図、面談画面。
- 手・小道具: 壊れにくい手を自然に描く。小さめの開いた手・軽く添える手のみ。片手だけの単純な動作にする。
- ポーズ・動き: ひまりが画面と書類を覗き込み、らぼまるが点検対象を確認する。
- 背景・状況: 奥行きのあるオフィスの点検机。セキュリティを落ち着いて調べる場面。
- 表情: ひまりは真剣で調べ顔、らぼまるは冷静。恐怖を煽らない。
- 演出根拠: 「AI利用の点検」から、抽象的な警告図でなく実際に利用状況を洗い出す机上作業を描く。
- 日付型判定: 非該当。開始日の変更が主題ではない。
- 変化の中身: 無償の簡易点検が始まった。
- 主要モチーフ: AIの接続と入力情報を調べる点検机。
- 日付ラベル: なし。
- 直近10記事類型チェック: 直近記事のサムネイルを確認。スマホ通信、料金比較、モデル提供の構図と異なる企業の点検机に変更。
- スライド演出方針: 監査ベストを一貫させ、8枚でカード、書類、権限、接続、面談と題材を変える。

## thumbnail

- タイトル: 会社のAI、何につながる？
- 感情: 心配しつつ落ち着いて調べる。
- 行動: ひまりがノートPCの接続図を覗き込み、らぼまるが隣で確認。
- 場面: オフィスの点検机。活用シーン型。
- 手の動作: 片手を机に軽く添えるだけ。もう片方は体側。
- 装い根拠: AIの安全点検 → 監査ベスト。
- 主要事実: 企業のAI利用を確認するサービス。残枠を保証する表現は使わない。
