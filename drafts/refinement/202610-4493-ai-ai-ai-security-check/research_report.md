# Research Pass — AI Security Check 2026

調査日: 2026-10-08。一次情報はサイバーセキュリティクラウドの2026年10月7日付発表（同社がPR TIMESへ掲載した本文）とIPAの「情報セキュリティ10大脅威 2026」。

## facts

- 同社は「AI Security Check 2026」を、生成AI・AIエージェントを業務利用する、または導入を検討する法人の先着10社へ無償提供すると発表した。
- 方法は専門家のオンラインヒアリングによる簡易チェック。利用実態、入力・連携する情報、アクセス権限、利用ルール、外部接続、ログ・対応体制を確認する。
- IPAの2026年版の組織向け10大脅威では「AIの利用をめぐるサイバーリスク」が初選出で3位。
- 申込フォームは発表文に掲載。詳細な有償サービスへの案内も発表文にある。

## claims

- セキュリティ上の課題を整理し優先順位を付けられるというのは提供企業による説明。診断効果を独立に検証した結果ではない。
- 企業でのAI活用が急速に広がっているという背景説明は同社の見解。

## uncertain_points

- 2026年10月8日時点で先着枠の残数、受付終了日、所要時間、納品物、個別企業の診断結果は公表文から確認できない。
- 簡易ヒアリングのみで安全性を保証するものではない。実機検査、侵入テスト、継続監視が含まれるとは発表されていない。
- 個人向け無料サービスではない。
