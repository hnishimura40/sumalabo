# 自己レビュー

## Pass 1 — 事実と断定

- 先着10社、法人対象、無償、オンラインヒアリング、確認項目は企業の発表文で照合済み。
- IPAの3位は組織向けの脅威順位であり、このサービスの評価ではない。本文では背景だけに使う。
- 残枠、期限、詳細診断の範囲は未確認と明記。安全保証を示唆しない。
- 煽り、個人向け誤認、制作工程文言の混入なし。

## Pass 2 — 一般読者と構成

- 主題の説明が冒頭にある: 合格。
- 30秒欄が4項目で単独理解できる: 合格。
- 関係がある人と薄い人を区別: 合格。
- 専門語を初出で平易に説明: 合格。
- キャラクターが読者の疑問を代弁する: MDX化で追加する。
- 噛み砕きが長文化していない: 合格。
- 公開文への内部工程情報混入: なし。
