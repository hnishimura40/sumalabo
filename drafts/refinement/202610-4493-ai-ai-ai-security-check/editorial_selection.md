# Editorial Selection

## 採用

- 企業向けの無料・先着10社・オンラインでの簡易確認というサービスの正体。
- 何を確認するかを「誰が使うか／何を入れるか／何につながるか／どう管理するか」で説明。
- 無料チェックと詳細診断の違い、残枠未確認という注意。
- IPAの脅威順位は背景として短く紹介し、個別企業の被害確率には読み替えない。

## 限定採用

- 提供企業が説明する「課題の優先順位づけ」は期待される使い道として紹介し、効果を保証しない。
- 詳細な有償サービス名は申込後の選択肢としてだけ触れる。

## 不採用

- 特定企業への攻撃増加や漏えい件数を本サービスの効果に結びつける推測。
- AIエージェント、RAG、MCPの実装論の長い解説。
- 個人向けの利用手順に見える紹介。

## 読者翻訳設計

- 主題の一言説明: 会社で使うAIがどの情報や仕組みにつながっているかを、専門家との面談で大まかに点検する無料枠の話。
- 関係がある人: 仕事で生成AIを導入・管理する会社の担当者や経営者。
- あまり関係がない人: 個人でAIを使うだけで、会社の利用ルールを決めない人。
- 専門用語: 生成AI → 文章や画像を作る技術。
- AIエージェント → 指示を受けて複数の作業を進める仕組み。
- アクセス権限 → 見たり操作したりできる範囲。
- ログ → 利用や操作の記録。
- MCP → AIと外部の道具・データをつなぐ仕組み。
- オンラインヒアリング → 遠隔の面談。
- 簡易チェック → 詳細な技術検査の前に状況を大まかに確かめること。
- 事実から言えること: 対象・方法・確認項目・先着数は発表で示された。
- 事実から言えないこと: 申込枠がまだあること、受ければ安全になること、詳細な技術診断を無料で受けられること。
