# AIに旅を相談すると、予約や変更は誰が引き受ける？｜図解プラン

## 演出ブロック

- 衣装: ひまりはレンガ色の軽いフード付きジャケット、生成りの長袖シャツ、濃紺のストレートパンツ、歩きやすいスニーカー。週末の小旅行で街や空港を移動する服装として、本文8枚とサムネイルで統一する。らぼまるは正本の素体。
- 小道具: 自立する小型キャリーケース、スマホ、便と宿の予約確認、旅程の用紙。各図では、便の候補、店の空席、支払い前の明細、ツアーの契約書、出張の見積もり依頼と返信から、伝える事実に必要なものを選ぶ。端末と書類はロゴや個人情報を含まない概念図にする。
- 手・小道具: 壊れにくい手を自然に描く。開いた手や道具に軽く添える手を、小さめ・遠めに描く。動かす手は片手だけにし、もう片方は体側で自然に休ませる。保持が必要な場面だけ片手で軽く支える。強い握り、両手の別動作、複雑な指形、手の接写を避ける。手を隠すためだけの後ろ手、机の陰、フレームアウトを使わず、衣装・姿勢・視線・道具が一緒に見える距離を取る。
- ポーズ・動き: サムネイルでは、ひまりが空港の通路でキャリーケースの横に足を止め、片手のスマホで宿の予約確認を開き、連絡先を探す。らぼまるは半歩横へ回り、同じ箇所を見上げる。本文では、候補へ視線を移す、予約条件を読み直す、旅程の変更箇所を追う動きで、旅の段階ごとに確かめることを示す。
- 背景・状況: サムネイルは、駐機中の旅客機が見えるガラス張りの空港通路。本文は荷造り中の部屋、京都駅近くの街角、空港の待合席、旅行相談カウンターなど、各図の行動が自然に起きる場所を使う。
- 表情: 記事全体は中立の解説調。サムネイルは「宿にも連絡が要りそうだ」と気づいたときの軽い戸惑いを、少し寄せた眉と、予約確認の一箇所に留まる視線で表す。本文では候補を探すときの関心と、条件や窓口を読むときの集中を描き分ける。
- 演出根拠: AIが希望を読み取って候補を探す段階、利用者が予約を確定する段階、事業者が予約後の変更を受け付ける段階を、旅行者がたどる順に描く。サムネイルは、便と宿を個別に予約した旅行者が、欠航時に宿の連絡先を探す本文の例を使う。旅行会社に代わりの便や宿の手配まで頼めるかは、本文図で契約条件につなげる。[観光庁の旅行予約サイト利用案内](https://www.mlit.go.jp/kankocho/seisaku_seido/ryokochui/yoyakusite.html)・[観光庁の標準旅行業約款](https://www.mlit.go.jp/kankocho/content/810001369.pdf)
