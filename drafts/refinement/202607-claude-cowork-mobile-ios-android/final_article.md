# スマホのClaudeが「作業」までやるように。Coworkがモバイル対応、何を任せられる？

## 先に結論

**Anthropic が、AI に仕事を任せる「Claude Cowork」を、7月7日からスマホ（iOS / Android）とウェブでも使えるようにしました。従来はデスクトップ限定でした。**

要点は次の3つです。

- Cowork のセッションは**クラウドで動く**ので、スマホでタスクを頼んで端末を閉じても作業は続く
- 同じ7月7日に、Microsoft 365 連携へ**書き込みの機能**（メールの下書き・送信・整理、カレンダー管理、OneDrive / SharePoint のファイル作成）が追加された
- ただし**ベータ**で、スマホの Cowork は「作業の委任」。コードをターミナルで動かす Claude Code とは別物

「通勤中にスマホから下ごしらえを頼んでおく」ような使い方に一歩近づいた、という話です。

## 何が起きた？ スマホからも「作業」を頼めるように

<span>Anthropic は 2026年7月7日、Claude Cowork を **web と mobile（iOS / Android）でも提供開始**しました。これまではデスクトップ専用でした（web / mobile はベータ）。</span>

Cowork は、チャットで「答えてもらう」のではなく、**Claude に実際の作業を任せる**ための場所です。ファイルやツールを操作しながら、複数ステップの作業を最初から最後まで進めます。

今回のポイントは、その Cowork が**クラウドで動く**ようになったことです。スマホからタスクを頼めば、**端末を閉じても Claude はクラウド側で作業を続け**、スケジュールしたタスクは端末がオフでも実行されます。

## 通勤中にスマホから何を任せられる？ 実例3つ

上限が緩んだ今こそ、と言いたくなりますが、まずは「スマホから任せられる作業」を具体的にイメージしてみましょう。

### ① メールの下書き・整理

7月7日に Microsoft 365 連携へ書き込み機能が加わり、**メールの下書き・送信・整理**ができるようになりました。通勤中に「この件、返信の下書きだけ用意しておいて」と頼んでおく、といった使い方が想定できます。

### ② カレンダーの調整・会議の準備

同じく M365 連携で、**カレンダーの予定管理**が可能になりました。空き時間の確認や予定の調整を下ごしらえしておき、オフィスに着いたら確認するだけ、という流れです。

### ③ 資料の下書き・要約

**OneDrive / SharePoint のファイル作成・更新**にも対応しました。長い資料の要約や、提案書のたたき台づくりを移動中に頼み、戻ったら中身を詰める、という分担ができます。

## できないことの線引き（ここが大事）

<span>便利になった一方で、**「スマホで何でもできる」ではありません**。誤解しやすい点を整理します。</span>

- **Cowork ≠ Claude Code**。スマホの Cowork は「作業の委任・エージェント実行」であって、コードをターミナル（CLI）で直接動かす Claude Code の操作をスマホでやる機能ではありません
- **Teams は読み取り専用**のままです（メール・カレンダー・OneDrive / SharePoint は書き込み可）
- **まだベータ**です。web / mobile はベータ提供で、挙動や対象は変わりえます

「スマホの AI が“答える”から“作業する”へ」進んだのは確かですが、**万能ではない**という前提で使うのが安全です。

## 利用実態：9割超が「コード以外」の仕事

<span>Anthropic の利用実態データ（**2026年5月11〜31日 / 約120万セッション / 60万組織超**）を見ると、Cowork は**エンジニア以外の普段の仕事**で多く使われています。</span>

| カテゴリ | 割合 |
|---|---|
| 業務プロセス・オペレーション | 33.4% |
| コンテンツ作成・コピーライティング | 16.4% |
| ソフトウェア開発 | 8.7% |

上位2カテゴリで約半分を占め、**90%超がソフトウェア開発以外**でした。「コードを書く人のツール」ではなく、**誰の職場にもある“作業の周りの作業”**を任せる使われ方が中心、という裏付けです。

## 確定していること・未確定なこと

<span>ここは**確定・報道・未確定を分けて**見るところです。</span>

| 区分 | 内容 |
|---|---|
| 確定 | 7/7 に Cowork が iOS / Android・web に対応（web / mobile はベータ）。クラウド実行で端末を閉じても継続 |
| 確定 | 7/7 に M365 連携へ書き込みツール追加（メール・カレンダー・OneDrive / SharePoint）。Teams は読み取り専用 |
| 確定 | 利用実態（5/11–31・120万セッション・60万組織超）: 業務プロセス33.4% / コンテンツ16.4% / ソフト開発8.7% |
| 報道 | ロールアウトは Max プランから開始し順次拡大との言及（プラン別の細かな条件は変動しうる） |
| 未確定 | 日本での提供範囲・対象プランの細部（日本個別の公式記載は確認できていない） |

## どう見る？（補助）

<span>大事なのは、**「スマホでも作業を任せられる」入口が増えたこと**です。まずは軽いタスク（メールの下書き、予定の下ごしらえ、資料の要約）から試すのが向いています。</span>

- スマホからちょっとした作業を前もって頼んでおきたい人 → 相性がよい
- コードのターミナル操作をスマホでやりたい人 → それは Cowork ではなく別物なので期待しすぎない
- 日本での提供や対象プランが気になる人 → 公式の最新表示で確認するのが確実

同じ時期に、Claude の Fable 5 無料期間の延長や、ChatGPT の使用上限の一時撤廃といった動きもありました。各社が「まず触ってもらう」方向に動いている中で、**スマホから作業を任せる体験**が広がった、と位置づけられます。
