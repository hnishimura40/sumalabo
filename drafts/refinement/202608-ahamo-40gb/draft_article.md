# ahamoが40GBに増量、月額2,970円は据え置き　「値上げの布石」はどこまで本当？

## 先に結論

**ahamoは月額2,970円のまま40GB使えるようになりましたが、正式な40GBプランへの恒久改定ではなく、終了日未設定のキャンペーンです。**

- 2026年8月1日から、30GBに10GBを追加して**合計40GB**
- 月額料金はこれまでと同じ**2,970円**
- 「将来の値上げにつながるのでは」という見方はあるものの、**値上げは決まっていない**

今回のポイントは、「10GB増えてお得になった」というだけではありません。

ドコモは増量後の利用状況などを確認するとしており、その先の料金やデータ容量をどうするかはまだ決まっていません。

つまり今は、**40GBを使える期間に入ったが、その条件が将来そのまま続くかは未確定**という状態です。

## ahamoは8月1日から40GBに。料金は2,970円のまま

**2026年8月1日から、ahamoでは申込み不要で10GBが追加され、月40GBまで使えるようになっています。**

これまでのahamoは月30GBで2,970円でした。

今回始まった「データ増量おためしキャンペーン」では、この30GBに10GBが追加されます。

| 項目 | これまで | キャンペーン中 |
|---|---:|---:|
| 月間データ容量 | 30GB | **40GB** |
| 月額料金 | 2,970円 | **2,970円** |
| 申込み | ― | **不要** |
| 適用開始 | ― | **2026年8月1日** |
| 終了日 | ― | **未設定** |

利用者がエントリーしたり、料金プランを変更したりする必要はありません。対象なら自動的に増量されます。

ここで注意したいのは、プランそのものが「30GBから40GBへ正式改定された」わけではないことです。

ドコモが付けている名称も、あくまで**「データ増量おためしキャンペーン」**です。

終了日は現時点で設定されていませんが、これは「ずっと40GBが続く」という意味ではありません。

## なぜ「値上げの布石では？」と話題になっているのか

**40GB化を将来の値上げにつなげる見方はありますが、現時点では報道による分析であり、ドコモが値上げを発表したわけではありません。**

ITmedia Mobileでは、今回の40GB化について「値上げの布石ではないか」という観点から分析されています。

背景の一つとして挙げられているのが、スマートフォンで使われるデータ量そのものの増加です。

ドコモの前田義晃社長は、通信トラフィックが毎年20％程度増えているとの趣旨を説明しています。

動画の高画質化やアプリの大容量化などが進めば、同じ使い方をしているつもりでも必要なデータ量は増えていきます。

ITmediaの記事では、仮に30GBから毎年20％ずつ必要量が増えると、

30GB → 36GB → 43.2GB

となる例も示されています。

ただし、**43.2GBはドコモが発表した「2026年の平均利用量」ではありません。**

あくまで「毎年20％増えた場合」を分かりやすく示した試算なので、事実の数字とは分けて見る必要があります。

### UQ mobileやY!mobileとの競争も背景にある

もう一つの背景として、中容量プランの競争があります。

UQ mobileやY!mobileには35GB前後の料金プランがあり、スマートフォン料金では「20GBでは少ないけれど、無制限まではいらない」という層をめぐる競争が強まっています。

その中でahamoが**40GB・2,970円**になると、容量と料金のバランスはかなり目立ちます。

ただし、これも「UQ mobileやY!mobileへの対抗策として40GBにした」とドコモが公式に説明したわけではありません。

競争環境を踏まえた報道上の分析として見るのが適切です。

## 誤解しやすいのは「40GB化」と「値上げ」の2点

**「ahamoが正式に40GBプランになった」「このあと値上げすることが決まった」のどちらも、現時点では正確ではありません。**

今回のニュースは、見出しだけを見ると少し誤解しやすいところがあります。

### 「ahamoは40GBプランになった」わけではない

現在40GB使えること自体は事実です。

ただし、その仕組みは料金プランの恒久改定ではなく、キャンペーンによる10GB追加です。

そのため、

**30GBのahamo  
＋ キャンペーンで10GB追加  
＝ 現在は40GB**

と考えると分かりやすいでしょう。

終了日は未設定ですが、今後キャンペーンが終了すれば、現在の公式条件では通常のデータ容量へ戻ります。

「終了日未設定」と「恒久化」は別の話です。

### 「40GBにしたあと値上げする」とも決まっていない

もう一つ注意したいのが値上げの話です。

ドコモが今後の料金改定を検討していることは報じられていますが、ahamoについて、

- 月額料金をいくらにするのか
- いつ変更するのか
- 40GBを正式容量にするのか
- 既存利用者も値上げするのか

といった具体的な内容は発表されていません。

そのため、「40GBを体験させたあと値上げする」と決めつけるのは早い段階です。

一方で、ドコモは今回のキャンペーンを通じて、データ容量を増やした場合の利用状況や使い方の変化を確認するとしています。

その結果が将来の料金や容量設計に使われる可能性はあります。

現状は、**値上げ説には考える材料はあるが、結論はまだ出ていない**と整理するのがよさそうです。

## 確定していること・していないことを整理

**今確実に言えるのは「40GBを2,970円で使える」というところまでで、その先の料金や容量はまだ決まっていません。**

混ざりやすいので、現時点の情報を整理すると次のようになります。

| 内容 | 現時点 |
|---|---|
| ahamoで40GB使える | **確定** |
| 月額2,970円のまま | **確定** |
| 2026年8月1日から適用 | **確定** |
| 申込み不要・自動適用 | **確定** |
| キャンペーン終了日 | **未設定** |
| 40GBを恒久化する | **未確定** |
| ahamoを値上げする | **未確定** |
| 値上げする場合の時期・金額 | **未確定** |
| 40GBよりさらに増量する | **未確定** |

特に覚えておきたいのは、**「終了日が決まっていない＝永久に40GB」ではない**という点です。

逆に、「おためしキャンペーン＝すぐ終わる」と決まっているわけでもありません。

今はその間の状態です。

## 大盛りオプションは120GBに。月額4,950円は据え置き

**ahamo大盛りを利用している人も10GB増え、キャンペーン期間中は月120GBを4,950円で利用できます。**

通常のahamo大盛りは、

30GB＋大盛りオプション80GB＝110GB

です。

今回のキャンペーンでは基本容量側に10GBが追加されるため、

40GB＋80GB＝**120GB**

となります。

月額料金はこれまでと同じ**4,950円**です。

大盛りを契約している人にとっても、手続きなしで10GB増える形になります。

なお、海外で追加料金なしで利用できるデータ量まで40GBに増えるわけではありません。国内での増量とは条件が異なるため、海外利用が多い人は注意が必要です。

## いまahamo利用者はどうすればいい？

**現在ahamoを使っている人は基本的に何もする必要はなく、まずは40GBをそのまま利用すればOKです。**

今回の増量は自動適用なので、申込みのために設定を変更する必要はありません。

特に恩恵が大きいのは、これまで毎月30GB近くまで使っていた人です。

動画を見る時間が多かったり、外出先でテザリングを使ったりして月末に容量を気にしていたなら、10GB分の余裕はかなり使いやすくなります。

一方で、毎月10GBや20GB程度しか使っていない人は、容量が40GBになっても使い方そのものは大きく変わらないかもしれません。

また、「将来値上げされるかもしれない」という報道だけを理由に、今すぐ他社へ乗り換える必要もありません。

料金改定はまだ発表されていないためです。

現時点では、

**40GB・2,970円というメリットはそのまま受け取る。  
ただし、40GBの恒久化や将来の料金については今後の発表を見る。**

このくらいの距離感で考えるのがよさそうです。

今回の40GB化は、単純な「無料で10GB増えた」というニュースである一方、ahamoの今後の料金や容量を考えるうえでも気になる動きです。

ただ、**「40GBになった」は確定、「値上げする」は未確定。**

まずはこの2つを分けて見ることが、今回のニュースを理解する一番のポイントです。
