# ahamoが40GBに増量、月額2,970円は据え置き　「値上げの布石」はどこまで本当？

## 先に結論

**ahamoは月額2,970円（税込）のまま40GB使えるようになりましたが、正式な40GBプランへの恒久改定ではなく、キャンペーンによる10GB増量です。**

- 2026年8月1日から、通常30GBに10GBを追加して**合計40GB**
- 月額料金はこれまでと同じ**2,970円（税込）**
- 「値上げの布石では」という見方はあるものの、**ahamoの値上げは発表されていない**

今回のポイントは、「10GB増えてお得になった」というだけではありません。

ドコモは増量後の利用状況などを確認し、今後のサービス改善や設計の参考にするとしています。その一方で、40GBをこのまま続けるのか、その先に料金改定があるのかはまだ決まっていません。

まずは、**「40GBになった」は確定、「40GBがずっと続く」「値上げする」は未確定**と分けて考えるのが大切です。

## ahamoは8月1日から40GBに。月額2,970円はそのまま

**2026年8月1日から、ahamoでは申込み不要で10GBが追加され、月40GBまで使えるようになっています。**

これまでのahamoは、月30GBで2,970円（税込）でした。

今回始まった「データ増量おためしキャンペーン」では、この30GBに10GBが追加されます。

| 項目 | 通常 | キャンペーン中 |
|---|---:|---:|
| 月間データ容量 | 30GB | **40GB** |
| 月額料金 | 2,970円 | **2,970円** |
| 追加される容量 | ― | **10GB** |
| 申込み | ― | **不要** |
| 適用開始 | ― | **2026年8月1日** |
| 終了日 | ― | **現時点で未設定** |

利用者がエントリーしたり、料金プランを変更したりする必要はありません。対象者には自動的に適用されます。

ただし、ここで一番注意したいのが、**ahamoそのものが30GBプランから40GBプランへ正式改定されたわけではない**ことです。

仕組みとしては、

**通常30GB  
＋ キャンペーン10GB  
＝ 現在は40GB**

です。

キャンペーンの終了日は現時点で設定されていませんが、「終了日未設定」と「恒久化」は同じ意味ではありません。

## なぜ「値上げの布石では？」と話題になっているのか

**40GB化を将来の料金見直しにつなげて見る報道はありますが、これは分析や見立てであり、ドコモが値上げを発表したわけではありません。**

今回の増量をめぐっては、「なぜ料金を据え置いたまま10GBも増やすのか」という点が注目されています。

背景の一つとして挙げられているのが、スマートフォンで使われるデータ量の増加です。

ドコモの前田義晃社長は、通信トラフィックが毎年20％程度増えているとの趣旨を説明しています。

動画やアプリなどで使うデータ量が増えれば、これまで30GBで足りていた人でも、今後は余裕が小さくなっていく可能性があります。

報道では、30GBから毎年20％ずつ必要量が増えると仮定した場合、

**30GB → 36GB → 43.2GB**

になるという試算も示されています。

ただし、**43.2GBはドコモが発表したahamo利用者の平均使用量でも、2026年に必要になると公式に予測した数字でもありません。**

あくまで「毎年20％増えた場合」を分かりやすく示した計算例として見る必要があります。

### 35GB前後の料金プランとの競争も背景に

もう一つの背景が、中容量帯の料金プランをめぐる競争です。

UQ mobileやY!mobileには35GB前後のプランがあり、「20GBでは少ないが、無制限までは必要ない」という層の選択肢が増えています。

その中で、**40GB・2,970円**のahamoは、中容量帯の選択肢として比較されやすい条件になっています。

ただし、ドコモが「UQ mobileやY!mobileへの対抗として40GBにした」と公式に説明したわけではありません。

競争環境を踏まえた報道上の分析として分けて見るのが適切です。

## 誤解しやすいポイントは2つ

**今回のニュースでは、「正式な40GBプランになった」「値上げが決まった」と受け取らないことが重要です。**

### 1．恒久的な40GBプランへの変更ではない

現在40GB使えること自体は確定しています。

ただし、その40GBはあくまで「データ増量おためしキャンペーン」によって10GBが追加された結果です。

そのため、

- 現在40GB使える → **確定**
- 40GBが今後もずっと続く → **未確定**
- ahamoの基本容量が正式に40GBへ変更された → **現時点では違う**

という整理になります。

終了日が決まっていないため、いつまで40GBを使えるかは現時点では分かりません。

一方で、「おためしキャンペーンだからすぐ終了する」と決まっているわけでもありません。

### 2．「このあと値上げする」とも決まっていない

「40GBを体験してもらったあと料金を上げるのでは」という見方も出ています。

ただし、ahamoについて、

- 月額料金を変更するのか
- 変更するとすればいつなのか
- いくらになるのか
- 40GBを正式な基本容量にするのか
- 現在の利用者にも新料金を適用するのか

といった具体的な内容は発表されていません。

ドコモは今回のキャンペーンで、データ容量を増やした場合に利用状況や使い方がどう変わるかを確認するとしています。

その検証結果が、今後のサービス設計を考える材料になる可能性はあります。

ただし、そこから**「40GB化＝値上げの準備」と断定することはできません。**

## 確定していること・していないことを整理

**今確実に言えるのは「キャンペーン中は40GBを2,970円で使える」というところまでで、その先はまだ決まっていません。**

| 内容 | 現時点 |
|---|---|
| ahamoで40GB使える | **確定** |
| 月額2,970円（税込）のまま | **確定** |
| 2026年8月1日から適用 | **確定** |
| 10GB増量 | **確定** |
| 申込み不要・自動適用 | **確定** |
| キャンペーン終了日 | **未設定** |
| 40GBを恒久化する | **未確定** |
| ahamoを値上げする | **未確定** |
| 値上げする場合の時期 | **未確定** |
| 値上げする場合の金額 | **未確定** |
| 40GBよりさらに増量する | **未確定** |

今回のニュースを見るときは、**キャンペーンとして今使える条件**と、**将来どうなるかという予想**を分けるのがポイントです。

「終了日未設定＝永久に40GB」でも、「おためし＝近いうちに終了」でもありません。

現時点では、そのどちらも決まっていません。

## 大盛りオプションは110GBから120GB相当に

**ahamo大盛りを利用している人も10GB増量され、キャンペーン期間中は合計120GB相当を月額4,950円（税込）で利用できます。**

通常のahamo大盛りは、

**ahamo 30GB  
＋ 大盛りオプション80GB  
＝ 合計110GB**

です。

今回のキャンペーンでは基本容量側に10GBが追加されるため、

**ahamo 40GB  
＋ 大盛りオプション80GB  
＝ 合計120GB**

となります。

大盛りオプションは月額1,980円（税込）なので、

**ahamo 2,970円  
＋ 大盛りオプション1,980円  
＝ 月額4,950円**

という料金は変わりません。

大盛り利用者も、今回の増量のために特別な申込みは不要です。

なお、海外で追加料金なしで利用できるデータ容量まで40GBに増えるわけではありません。国内での増量とは条件が異なるため、海外利用が多い人は注意が必要です。

## いまahamo利用者はどう考えればいい？

**現在ahamoを使っている人は、今回の10GB増量のために特別な申込みをする必要はなく、まずは増えた容量をそのまま利用できます。**

### 30GB近くまで使っていた人

今回の恩恵を感じやすい層です。

これまで月末に残り容量を気にしていた人や、動画視聴・テザリングなどでデータ量が増えやすい人は、10GB分の余裕ができます。

月額料金は変わらないため、キャンペーン中は純粋に使える容量が増える形です。

### 10～20GB程度で収まっている人

40GBになっても、使い方そのものは大きく変わらない可能性があります。

「40GBになったからたくさん使わないともったいない」と考える必要もありません。

これまで通り使いながら、毎月どのくらい通信しているのかを確認しておけば十分です。

### 値上げが心配な人

現時点では、ahamoの値上げは発表されていません。

そのため、「値上げするかもしれない」という報道だけを理由に、急いで料金プランを変更する必要はありません。

今後、40GBの恒久化や料金改定について正式発表があった時点で、他社プランと比べ直せば判断できます。

今回のニュースは、

**40GB・2,970円という現在のメリットはそのまま受け取る。  
その一方で、40GBの恒久化や将来の料金については今後の発表を確認する。**

このくらいの距離感で見るのがよさそうです。

今回確定したのは、**ahamoがキャンペーンによって40GBに増え、月額2,970円（税込）は変わらないこと。**

「値上げの布石では」という見方はありますが、それは現時点では公式発表ではなく、将来の料金も決まっていません。

**「40GBになった」は確定。「値上げする」は未確定。**

この2つを分けて理解しておくことが、今回のニュースで一番大切なポイントです。
