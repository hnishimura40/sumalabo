# Editorial Selection

## 採用

- 3サービスに共通する「StandardとPremiumを同じ組織で混在できる」という変化
- 月払いの米国向け税別価格と、Premiumに含まれる利用枠の違い
- 「5倍」は性能、仕事量、生産性の5倍ではないという線引き
- 利用の多い人だけ上位席にする考え方と、管理者が確認すべき請求周期・未割り当て席
- Claudeの5倍相当はセッション単位の公開値からの計算で、週次倍率は未公表という注意

## 限定採用

- 席数上限は部署・中小チーム向けの目安として短く扱う。大企業全体の導入可否を断定しない。
- Cursorの無料管理者席は小さく始めやすい違いとして扱うが、勝敗を決める材料にはしない。
- 価格比較は米国向け税別と明記し、日本円換算は為替で動くため行わない。

## 不採用

- Premiumにすれば成果が5倍になるという表現
- 3社の利用枠が同じ量だとみなす比較
- 特定サービスを一律に最安・最得とする結論
- 画面操作の細かな手順。記事の中心を請求画面マニュアルにしない。
- 企業AI全体の将来を断定する予測

## 読者翻訳設計

- 主題の一言説明: 会社で使うAIの契約を、全員同じではなく、よく使う人だけ大きな利用枠へ替えられるようになった話。
- 関係がある人: ChatGPT Business、Claude Team、Cursor Teamsを会社や部署で契約する管理者、経理・IT担当、利用上限に頻繁に達する利用者。
- あまり関係がない人: 個人向け無料版・個人向け有料版だけを使う人、3サービスを会社で契約していない人、現在の利用枠で困っていない小規模チーム。
- 専門用語:
  - シート（会社の契約で一人に割り当てる利用枠）
  - Standard → 基本の利用枠を持つ通常席
  - Premium → よく使う人向けに含まれる利用枠を増やした上位席
  - ワークスペース → 会社やチームがメンバーと請求をまとめて管理する場所
  - 含有利用量（定額料金の中で追加料金なしに使える量）
  - 利用上限 → 一定期間に使える量の区切り
  - 日割り課金 → 月の途中で席を増やしたとき、残り日数分だけ請求すること
  - 従量課金 → 使った量に応じて追加料金が増える仕組み
  - クレジット → 含まれる利用量を超えた後に使う前払い・共有の追加枠
  - Unpaid Admin → Cursorを使わず管理だけをする無料の管理者席
- 事実から言えること: 3社で基本席と上位席を混在でき、利用量が多い人へ大きな枠を配りやすくなった。価格、枠、変更時の請求はサービスごとに異なる。
- 事実から言えないこと: 上位席で仕事が5倍進む、3社の5倍が同じ量、全員を上位席にすると得、日本での実請求が表のドル額と同じ。
