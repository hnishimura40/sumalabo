# slide_plan

## ① 全体方針

### 目的
- すまラボの記事本文を、**スマホでも読みやすい図解スライド**に落とし込む
- ニュースの主役は「**Fable 5は、Opusの上に来たMythos-classを安全装置つきで一般公開したモデル**」という点
- 「使うべきか」よりも、**何が起きたニュースなのかを理解できること**を優先する

### 画像仕様
- **本文スライド**：4:5縦長、**1280×1600**
- **サムネイル**：16:9横長、**1600×900**
- スマホ閲覧を優先し、**見出し・要点・数値が一目で読める**文字サイズにする
- 1枚に詰め込みすぎず、**1スライド1テーマ**で整理する

### デザイン方針
- 背景：**白〜淡いグレー**
- アクセント：**青系**
- 雰囲気：クリーン、落ち着いた、やさしい、整理型
- ビジネス資料っぽすぎず、ニュース図解として読みやすくする
- 実在ロゴ（Anthropic / Claude / OpenAI / Google など）は**精密再現しない**
- アイコンや抽象図形で整理する

### キャラクター方針
- **ひまり**：読者目線の疑問役  
  - 「それってどういうこと？」「結局どっちを見るの？」を代弁
- **らぼまる**：整理・比較役  
  - 図や比較表の横で要点を短く整理
- キャラは飾りではなく、**理解補助に使う**
- 各スライドで必要なときだけ短く入れ、**本文の代替にはしない**

### 内容方針
- **公式情報ベース**
- **外部評価・報道・未確定情報は混ぜない**
- 価格は**米ドルのみ**
- **日本円換算しない**
- 日本提供、日本語実力、サブスク復帰時期は**断定しない**
- サイバー/バイオ安全は**煽らず、落ち着いた注意点**として扱う
- ベンチマークは数値だけでなく、**「何を測る数字か」も併記**する
- *付きベンチは  
  **「一般利用のFable 5では、そのまま読まない」注記を必ず入れる**
