# Claude Fable 5 登場。Opusの上に来た新AIモデルは何がすごいのか

Claudeに、新しい最上位クラスのモデルが登場しました。  
ポイントは、単に「賢くなった」ではなく、強力なAIをどこまで安全装置つきで一般利用に出せるか、というところにあります。

## Claude Fable 5とは何か。Anthropicが6月9日に発表した新モデル

Claude Fable 5は、Anthropicが一般公開するClaudeの中で最も高性能な新モデルです。

Anthropicは2026年6月9日、新しいAIモデルとして「Claude Fable 5」と「Claude Mythos 5」を発表しました。

一般利用向けに公開されるのは、Claude Fable 5です。モデルIDは `claude-fable-5`。Anthropicはこのモデルを、同社が一般公開する中で最も高性能なモデルと説明しています。

ここで大事なのは、Fable 5が単なるOpusの小改良ではないことです。

これまでClaudeの上位モデルといえば、Opusが中心でした。今回のFable 5は、そのOpusの上に置かれた「Mythos-class」の一般公開版という位置づけです。

つまり、Claudeの中でさらに上の能力帯が用意され、その力を一般利用向けに調整したものがFable 5、という整理になります。

スペック面では、Fable 5は1Mトークンのコンテキストを標準で扱えます。最大出力は128kトークン。かなり長い文章、資料、コード、やり取りをまとめて扱える設計です。

また、Fable 5では「adaptive thinking」が常時オンになっています。これは、必要に応じてモデル側が考える深さを調整する仕組みです。利用者がextended thinkingを手動でオン・オフする形ではなく、基本的に常にこの仕組みが動きます。

ただし、生の思考過程がそのまま返ってくるわけではありません。必要に応じて要約として見せる形です。

## Opusの上に置かれた「Mythos-class」と、FableとMythosが分かれる理由

Fable 5とMythos 5の分かれ目は、能力の土台ではなく、安全装置の扱いです。

今回の発表で一番ややこしいのは、「Fable 5」と「Mythos 5」が同時に出てきたことです。

名前が違うので、別々のモデルに見えます。ですが公式の説明では、Fable 5とMythos 5の違いは基本的に「safeguards」、つまり安全装置の有無です。

Fable 5は、Mythos-classの能力を一般利用向けに安全化したモデルです。  
Mythos 5は、同じ土台を使いながら、一部領域の安全装置を外した限定提供モデルです。

ここを間違えると、記事全体の読み方がズレます。

Fable 5は「弱い版」というより、Mythos-classの力を一般利用に出せるように、安全装置を組み込んだモデルです。  
Mythos 5は「上位版」と表現したくなりますが、一般向けに解放されたモデルではありません。

名前の由来も公式で説明されています。Fableはラテン語の *fabula*、Mythosはギリシャ語の *mythos* に対応する言葉です。名前の違いはありますが、公式脚注の要点は明確です。両者を分けている理由は、安全装置です。

> ひまり「FableとMythosって、どっちが本物の新モデルなの？」
>
> らぼまる「土台は同じ方向だね。一般向けに安全装置をつけて出すのがFable、限定領域で安全装置を外すのがMythos、という見方が近いよ。」

## Fable 5とMythos 5の違い。一般ユーザーが使えるのはFable 5

Mythos 5は一般提供されず、承認された顧客向けに限られます。

Claude Mythos 5は、Fable 5と同じMythos-classの土台を持つモデルですが、一般利用向けには提供されません。

公式の説明では、Mythos 5はProject Glasswingに関わる承認顧客向けの限定提供です。Project Glasswingは米政府との協働に関わる枠組みで、一般ユーザーが通常のClaude画面やAPI利用で自由に選べるモデルではありません。

特にMythos 5は、サイバーセキュリティ分野で非常に高い能力を持つモデルとして説明されています。公式は、Mythos Previewの後継として、サイバーセキュリティ能力の強さを強調しています。

ただし、ここは煽って読むところではありません。

むしろ重要なのは、そうした強い能力をそのまま広く出すのではなく、一般利用向けには安全装置つきのFable 5として提供している点です。

一般ユーザーが触れる前提で考えるべきなのは、Claude Fable 5です。  
Mythos 5は「Fable 5のさらに強い版が自由に使える」という話ではありません。

## ベンチマークで見える強み。数字は「何ができるか」を読む材料

Fable 5 / Mythos 5の強みは、長い作業、資料理解、画面理解、研究支援のような複雑なタスクに出ています。

公式のベンチマーク表では、Fable 5 / Mythos 5は多くの項目で高いスコアを出しています。数字だけを見ると難しく感じますが、すまラボ的には「何を測っている数字なのか」に置き換えると見えやすくなります。

まず、コーディングです。

SWE-Bench Proでは、Mythos 5 / Fable 5の高い方が80.3、Fable 5が77.8とされています。Opus 4.8は69.2、GPT 5.5は58.6、Gemini 3.1 Proは54.2です。

これは、単に短いコードを書く力ではありません。実際のソフトウェア修正に近い課題で、長い作業を途中で投げず、原因を探し、修正し、確認する力を見る指標です。

FrontierCodeのDiamondでは29.3、Opus 4.8は13.4です。こちらも、より難しい開発タスクでどこまで粘れるかを見る材料になります。

次に、知識作業です。

GDPval-AAでは1932、Opus 4.8は1890、GPT 5.5は1769、Gemini 3.1 Proは1314です。GDPpdfでは29.8、Opus 4.8は22.5、GPT 5.5は24.9、Gemini 3.1 Proは16.7です。

知識作業のベンチマークは、資料、表、グラフ、PDFのような情報を読み取り、筋道を立てて判断する力に近いものです。AIが「知っていることを答える」だけでなく、渡された資料をもとに考えられるかを見る数字です。

ビジョン、つまり画像や画面の理解でも強さが示されています。

GDPpdfは資料ビジョンの力を見る指標でもあります。Blueprint-Bench 2では38.6、Opus 4.8は14.5、GPT 5.5は36.2、Gemini 3.1 Proは26.5です。

画像を見て説明するだけでなく、画面の構造を理解したり、図から数値を読み取ったり、スクリーンショットからWebアプリを再構築したりする力が評価されています。

OSWorld-Verifiedでは、Mythos 5 / Fable 5側が85.0、Fable 5が85.4とされています。Opus 4.8は83.4、GPT 5.5は78.7、Gemini 3.1 Proは76.2です。

これは、PC画面を見ながら操作し、作業を進める力に近い指標です。AIが文章で答えるだけでなく、画面を理解してタスクを進める方向へ近づいていることを示しています。

科学研究系では、Humanity’s Last Exam、BioMysteryBench、HealthBenchなどの数字が示されています。たとえばHumanity’s Last Examはno toolsで59.0 / 56.8、with toolsで64.5 / 64.7です。HealthBench Professionalは66.0 / 64.7です。

こうした数字は、難問への推論、専門的な知識、仮説を立てて複雑な条件を整理する力を見る材料になります。

ただし、ここには重要な注意点があります。

公式表で「*」が付いているベンチマークは、サイバー・バイオ系の安全装置の影響で、Mythos 5とFable 5の差が大きく出る領域です。公式注記では、こうした領域で一般利用できるFable 5は、フォールバックによりOpus 4.8寄りのスコアになると説明されています。

つまり、表の一番高い数字だけを見て「Fable 5でそのまま使える」と読むのは危険です。

とくにExploitBenchのようなサイバー系、BioMysteryBenchのようなバイオ系では、一般利用のFable 5は安全装置が働く可能性があります。ここは、能力の高さと利用できる範囲を分けて読む必要があります。

## コーディング・長期作業の実例。Fable 5は途中で止まりにくいAIを目指している

Fable 5の強みは、短い回答よりも、長い作業を進める力として打ち出されています。

Anthropicは、Fable 5について「どのClaudeより長く自律作動する」と説明しています。

これは、AIが一問一答で答えるだけではなく、調べる、分ける、直す、確認する、といった作業の流れを長く扱う方向に進んでいることを意味します。

公式が紹介している例のひとつがStripeです。

Stripeは、Fable 5によって数か月分のエンジニアリング作業を数日に圧縮できたとコメントしています。また、5,000万行のRubyコードベース全体の移行を1日で進めた事例も紹介されています。手作業ならチームで2か月超かかる作業だったとされています。

もちろん、これは公式が紹介した早期利用事例です。すべての開発作業で同じような結果になると読むべきではありません。

それでも、Fable 5の方向性はかなりはっきりしています。短いコード片を作るだけでなく、大きなコードベースを理解し、複数の工程をまたいで作業する力を狙っています。

もうひとつ面白い例が、Slay the Spireです。

公式は、永続メモリの効果がOpus 4.8の3倍、最終章到達も3倍と説明しています。これはゲームそのものが重要というより、長い文脈を保ち、前の判断を活かしながら次の行動を選ぶ力を示す例です。

AIの進化は、「その場でうまい回答を返す」から、「長い流れの中で作業を続ける」へ移っています。Fable 5は、その流れをかなり強く打ち出したモデルです。

## 価格と提供範囲。Fable 5は高性能だが、常に定額で使えるとは限らない

Fable 5のAPI価格はOpus 4.8の2倍で、サブスクでの扱いも期間限定の注意があります。

Fable 5とMythos 5の価格は、100万トークンあたり入力10ドル、出力50ドルです。米ドル表記です。

Opus 4.8は入力5ドル、出力25ドルなので、Fable 5はAPI単価で見るとOpus 4.8の2倍です。一方で、Mythos Previewと比べると半額未満と説明されています。

ここでも、円換算は主情報にしません。公式で日本円価格が示されていないためです。

提供範囲も少し複雑です。

Fable 5は、2026年6月9日からClaude API、Claude Platform on AWS、Amazon Bedrock、Vertex AI、Microsoft Foundryで一般提供されています。API利用については初日から提供されています。

一方、Claudeのサブスクでは扱いに注意が必要です。

6月9日から6月22日までは、Pro、Max、Team、シート型Enterpriseに追加費用なしで含まれます。  
しかし6月23日以降は、これらの標準サブスクから外れ、利用にはusage creditsが必要になります。

Anthropicは、容量が許せば標準サブスクへできる限り早く復帰させる方針を示しています。ただし、復帰時期は未確定です。

日本での表示、日本語での提供状況、日本円価格、6月23日以降のusage creditsの具体的な必要量や金額は、公式に特記がありません。国内の利用者向けには、実際の画面表示や公式案内を確認する必要があります。

## 安全分類器とOpus 4.8フォールバック。強いAIを一般公開するための仕組み

Fable 5は、危険だから怖いモデルというより、安全装置を組み込むことで一般公開されたモデルです。

Fable 5には、安全分類器が組み込まれています。

この分類器は、リクエスト時と応答生成中に動きます。対象は主に3つです。

1つ目はサイバーセキュリティです。特に攻撃的サイバーに関わる内容が対象になります。

2つ目は生物・化学です。研究や安全保障に関わるデュアルユース、つまり役立つ使い方も危険な使い方もあり得る領域が対象です。

3つ目はdistillationです。これは、Fable 5の能力を引き出して他モデルの学習などに転用するような使い方を指します。日本語では「能力抽出」と言い換えるとわかりやすいです。

分類器が対象領域だと判断した場合、Fable 5がそのまま答えるのではなく、Claude Opus 4.8が代わりに応答します。これがフォールバックです。

重要なのは、これを単に「制限が多い」と見るだけでは足りないことです。

Fable 5はMythos-classの強い能力を持つモデルです。その力を一般利用に出すために、危険になりやすい領域ではOpus 4.8へ切り替える仕組みを入れている。ここが今回の発表の本質です。

公式は、フォールバックが発生するのはセッションの5%未満と説明しています。つまり、95%超のセッションではFable 5のまま動くということです。

一方で、無害な依頼でも分類器が拾ってしまう可能性はあります。公式も、false positiveを減らしていく方針を示しています。

安全評価についても、公式は外部レッドチームとバグバウンティを行っています。1,000時間超のテストで、ユニバーサル脱獄は未発見だったとされています。また、30種類の脱獄手法による単発の有害リクエストに対して、Fable 5は応答しなかったと説明されています。

ただし、UK AISIは短い初期テストの中で「進展」があったと注記しています。これは脱獄成立と同じ意味ではありません。安全性については、強い対策が示されている一方で、継続的に検証される領域として読むのが自然です。

## この記事の見方まとめ。AIは「答える」から「任せる」へ近づいている

Fable 5のニュースは、高性能化だけでなく、AIにどこまで作業を任せられるかという変化を示しています。

Fable 5で見えてくる流れは、かなりはっきりしています。

AIは、質問に答えるだけの道具から、長い作業を段取りごと進める道具へ近づいています。

コーディングなら、短い関数を書くのではなく、大きなコードベースを読み、変更し、確認する。  
知識作業なら、資料や表を読み、根拠を整理し、判断の筋道を作る。  
ビジョンなら、画像や画面を見て、そこから次の作業につなげる。  
科学研究なら、複雑な条件を整理し、仮説を立てる。

これらは、単なるチャットの延長ではありません。

一方で、使える条件には注意が必要です。

Fable 5は一般公開モデルですが、Mythos 5は一般提供されません。Fable 5でも、サイバー・バイオ・化学・distillationに関わる領域では、安全分類器とOpus 4.8フォールバックが入ります。

また、サブスクでの扱いも固定ではありません。6月22日までは対象プランに含まれますが、6月23日以降はusage creditsが必要になります。将来の標準サブスク復帰は予定されていますが、時期は未確定です。

日本での見え方、日本語での実力、日本円価格も、公式情報だけではまだ断定できません。

公式情報、外部評価、報道、ユーザー検証は分けて読む必要があります。今回の本文では、公式発表とClaude API Docs、Release Notesで確認できる情報を中心に整理しています。公式表にない外部ベンチ数値は採用していません。

## まとめ。Fable 5は「強いAIをどう開放するか」のニュース

Claude Fable 5は、Opusの上に置かれたMythos-classの一般公開モデルです。

すごさは、単にベンチマークの数字が高いことだけではありません。長い作業を続ける力、資料や画面を理解する力、複雑な条件を整理する力が伸びている点にあります。

同時に、今回のニュースの中心には安全装置があります。

Fable 5は、Mythos-classの能力を一般利用に出すために、サイバー、バイオ・化学、能力抽出のような領域で安全分類器を使います。必要な場面ではOpus 4.8に切り替わります。

つまりFable 5は、「何でも自由にできる最上位AI」ではありません。

より正確には、非常に強い能力を持つAIを、一般利用できる範囲に収めて出したモデルです。

AIは「答える」から「作業を進める」方向へ進んでいます。Fable 5は、その変化をかなりわかりやすく示す発表です。

ただし、国内での提供状況、料金、サブスクでの扱い、実際の日本語利用は、今後の公式案内や実利用で確認する必要があります。過剰に期待しすぎず、能力と制限をセットで見るのがよさそうです。
