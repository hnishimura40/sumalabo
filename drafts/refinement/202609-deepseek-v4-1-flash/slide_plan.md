# Slide Plan: DeepSeek-V4.1-Flash

本文スライド8枚（4:5）とサムネイル1枚（16:9）。文字は一枚絵の中に含める。実在企業ロゴは描かず、製品名はテキスト情報としてのみ扱う。

## 演出ブロック

- 衣装: ひまりはティールの配線ラインが入った白い研究用ジャケットと小さなIDバッジ。AIモデル／性能／研究の話を、清潔な計算ラボの装いで表す。標準衣装にはしない
- 小道具: 透明な計算キューブ、細い光路、料金メーター、3つの処理トレイ、モデル名を書いた無地の端末。実在ロゴは使わない
- 手・小道具: 自然な構図で壊れにくい手を描き、開いた手・軽く添える手を優先する。手は小さめ・遠め。ひまりは片手を開いて計算キューブへ軽く添え、もう片方は体側で休ませる。らぼまるは短く太い片腕で端末へ軽く触れ、反対の腕は体側。強い握り、両手の別動作、指を組む・数える、手の接写は使わない
- ポーズ・動き: ひまりは計算キューブを覗き込み、料金の変化に気づいて身を乗り出す。らぼまるは短い腕で検品端末を確認。棒立ちや単純な案内役にしない
- 背景・状況: 奥行きのあるAI計算ラボ。太い旧データ流が細い新データ流へ変わり、処理トレイを通って端末へ届く。白〜淡いグレー、ティール、青、価格部分だけ明るい黄緑
- 表情: 値下げは朗報だが開発者向けの条件付きニュース。ひまりは驚きより「仕組みが分かった」明るい発見、らぼまるは落ち着いた確認顔
- 演出根拠: 「計算メモを軽くして料金を下げた」ため、比較表の横に立つのではなく、太いデータ流を小さくして料金メーターが下がる瞬間を2人が確認する体験図にする
- 日付型判定: 非該当。発表日や移行日は補足で、主題はモデル構造・料金・振り分け変更
- 変化の中身: 計算メモが軽くなり、Flash API料金が項目別に下がり、旧モデル名の接続先が変わる
- 主要モチーフ: データ圧縮レーンと3つの料金メーターを備えたAI計算ラボ
- 日付ラベル: サムネにはなし。移行スライドだけ「9/14 13時〜」
- 直近10記事類型チェック: 画像編集アトリエ、投稿調査端末、利用枠チャージ装置、PC連携、大型タンク、映画館ロビー、会計レーン、通信デッキと重複しない。今回はデータ圧縮レーンを主役に変更
- スライド演出方針: ひまりの研究ジャケットは8枚で一貫。各スライドでキューブ、料金トレイ、メモ保存棚、接続レーン、試験ベンチなど道具と動きを変える。文字は見出しと3点以内に絞る

- 場面: ひまりが文字カードと画像カードを透明キューブへ片手で軽く添え、らぼまるが出力端末を確認
- 必須: 2026年9月10日正式発表、100万トークン、画像対応、ロゴなし
- 避ける: 100万トークンなら全情報を完全理解できるという表現

## thumbnail 値下げを体験する計算ラボ

- 型: 変化実感型
- 大見出し: 「Flash API 安くなった」
- 短いサブ: 「3つの料金を確認」
- 感情: ひまりは料金メーターが項目別に下がる仕組みを理解した明るい発見。満面の笑みや驚きすぎではなく、目を輝かせて前のめり
- 行動: ひまりが太い計算メモの流れを圧縮レーンへ片手で軽く送り、らぼまるが3つの料金メーターを確認する
- 場面: 奥行きあるAI計算ラボ。左の大きな計算メモが中央の透明圧縮装置を通り、右の3つの小さな料金メーターへ流れる。背景・小物・2キャラが同じ作業に参加
- 手の動作: ひまりは開いた片手を圧縮レーンの手前へ軽く添え、もう片手は体側。らぼまるは短く太い片腕で確認ボタンへ軽く触れ、反対は体側。手は小さく遠めで接写しない
- 装い根拠: AIモデルと料金改善を、ティール配線の研究ジャケットと計算ラボで表す
- 構図: 16:9。左寄りにひまり、中央に圧縮レーン、右下にらぼまる。大見出しは上部の安全な余白、顔・胴体・動作と重ねない
- 必須: 値下げはAPI料金、3項目、実在ロゴなし。金額は本文スライドへ譲りサムネに詰め込まない
- 避ける: 比較表だけの紹介パネル、棒立ち、指さし、札束、日本円、炎、企業ロゴ、複雑な手
