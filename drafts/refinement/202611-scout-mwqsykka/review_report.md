# セルフレビュー｜六花亭オンラインショップのカード不正利用

対象は `draft_article.md`。2026年11月22日に、調査報告・論点整理と六花亭の第一報・第二報、解説に使った一次資料を照合した。

**総合判定：要修正。** 日付と件数は公式発表と一致する。30秒欄に心当たりのない請求を見つけたときの連絡先を加え、カード情報を入力する場面の説明を短くする。あわせて、AIの説明をGoogleの観測範囲とVisaの仕組みに絞る。

事件の事実と対応は、六花亭の公式ページに併載された第一報・第二報を根拠にできる。読売新聞の配信元本文は取得できず、ライブドアニュース掲載分で見出し・配信時刻・記事冒頭を照合した。採用記録のGoogle News順位は当時の観測値で、同じ読売新聞記事の2欄掲載。本文には順位や掲載媒体数を持ち込んでいない。 [六花亭の第一報・第二報](https://www.rokkatei.co.jp/news/info/20261121-25796/) [読売新聞配信・ライブドアニュース掲載](https://news.livedoor.com/article/detail/32870973/)

AIの段落は「Googleは、文章などを作る生成AIのGeminiが、人をだます文面の作成に使われた事例を報告しています」と、観測した範囲を示す。文面が実際に送られたか、被害に結び付いたかはこの資料からは判断できない。Visaの例は「Visaの決済ネットワークでは、支払いの申し込みが届くと、不正の疑わしさを点数にしてカード発行会社の判断を助けます」とする。画面を動かす仕組みの変更に気づく対策は、カード決済の安全基準を策定する団体の資料で裏付けられる。 [Googleの観測報告](https://cloud.google.com/blog/topics/threat-intelligence/adversarial-misuse-generative-ai) [Visaの公式発表](https://www.visa.co.jp/about-visa/newsroom/press-releases/nr-jp-1906190.html) [PCI SSCの決済画面保護ガイド](https://blog.pcisecuritystandards.org/new-information-supplement-payment-page-security-and-preventing-e-skimming)

**入力画面の節の修正例**

> カード番号を入れる決済画面では、入力した情報が支払いのために処理されます。六花亭は、カード情報を自社のサーバーに保存していなかったと説明しています。一方で、画面の動きを決めるプログラムが無断で書き換えられ、客が情報を入力した時点で外部に送られた可能性があるとしています。 [六花亭の第一報・第二報](https://www.rokkatei.co.jp/news/info/20261121-25796/)

**読者の判断と図解に使える論点**

通販を使った日時から、六花亭の相談室に確認する場合と、カード会社に再発行や不審な請求を相談する場合がたどれる。図解には、①事件の全体像、②対象期間と対象者、③1件と約8,000件の意味、④入力時と保存時の違い、⑤再発行と明細確認、⑥お見舞い金を名乗る連絡の確かめ方、⑦生成AIを使った文面作成の観測例、⑧支払い時にAIが疑わしさを点数にする範囲を使える。本文では、各数値の公表時点、未確認事項、窓口の使い分けを補う。 [六花亭の公式案内](https://www.rokkatei.co.jp/news/info/20261121-25796/) [国民生活センターの偽メール対策](https://www.kokusen.go.jp/news/data/n-20241119_2.html)

**判定：本文修正後に再照合。** 30秒欄の連絡先、入力画面の説明、AIの観測・適用範囲を修正したうえで、対象条件と一次資料の記述が保たれているか確認する。
