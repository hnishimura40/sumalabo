# Review Pass 1 / Pass 2 — Gemini Notebookの無料教科書

## Pass 1: 事実・表現

- 合格: 数百冊の出所を「米国・インドの提供元」と記し、利用者の対象国と混同していない。
- 合格: 無料は対象の教科書をノートに追加する範囲と説明。無制限や全教科書無料と拡大していない。
- 合格: 日本のサービス対応と今回のカタログ表示を分離。
- 合格: 具体的な出典3件を確認。日付はGoogle発表の2026-10-29。
- 修正: 初稿の「質問や復習に使えるようになった」を「対象教科書を新たに選べる」に明確化。

## Pass 2: 読者向け

- 合格: 主題の説明が冒頭にある。
- 合格: 30秒欄は4項目で単独理解できる。
- 合格: 対象の教科書が必要な人と、急がなくてよい人を区別。
- 合格: ソース、カタログ、インライン引用、フラッシュカードを初出で説明する。
- 合格: キャラクターは読者の「全部無料？」「日本で使える？」を代弁する。
- 合格: 短い段落とチェック項目で整理し、冗長な説明を削った。
- 合格: スカウト元や制作工程の言葉を公開文に入れない。
