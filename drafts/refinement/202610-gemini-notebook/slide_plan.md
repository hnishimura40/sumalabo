# Gemini Notebook 教科書記事 — 8枚とサムネ

本文確定後の設計。画像内文字は日本語を短く正確にし、文字を含む一枚絵として生成する。Googleのロゴ、実在教科書の表紙、実在UIを精密再現しない。

## 演出ブロック

- 衣装: 学びの場面に合うひまりの落ち着いた青いカーディガンと水色のリボン。標準の顔・髪型・頭身は固定。らぼまるは衣装なしで小さなしおり飾り。
- 小道具: 机に置いた無地の教科書、学習カード、タブレット、しおり。特定の出版社の表紙は描かない。
- 手・小道具: 自然な構図で壊れにくい手を描く。開いた手・軽く添える手を優先し、片手だけを動かす。もう片方は体側で自然に休ませる。手は小さめ・遠めで接写しない。強く握る、指を数える、両手で別動作をしない。
- ポーズ: ひまりが机上の教科書とタブレットを見比べ、らぼまるは机上の短い学習カードを見上げる。棒立ちや説明パネルのみにはしない。
- 背景: 日本の自宅の学習机。窓からの朝の光、棚、本、ペン立て。一般的な図書館ではなく実際に試す場面。
- 表情: 便利さへの興味と理解。過度な歓喜や驚きは不要。
- 演出根拠: 「教科書を選び、AIに質問し、原典を確認する」具体的な行動を表す。
- スライド演出方針: 8枚とも同じカーディガン・学習机の世界観。各枚で本棚、追加メニュー、引用矢印、学習カードなど道具と視線を変える。
- 日付型判定: 非該当。発表日より機能の使い方が主題。
- 主要モチーフ: 開いた無地の教科書とノート画面。
- 直近10記事類型チェック: 直近のAI記事はモデル性能や限定提供が中心。今回は学習机での教材追加と原典確認を主役にして構図を変更。

## slide01 — 何が増えた？
- 見出し（画像内の正確な文字）: 「無料で選べる教科書が増えた」
- 要点: 対象の数百冊をGemini Notebookに追加できる。全教科書の無料化とは書かない。
- 演出: 机上の本棚から教科書がノートへ一冊移る図。ひまりが軽く机に手を添える。
- 形式: 4:5の縦長、完成版1280×1600。

## thumbnail — 体験図
- 型: 活用シーン型。
- 大見出し（画像内の正確な文字）: 「教科書でAIに質問」
- サブ見出し: 「対象の本は無料」
- 感情: 学びが進みそうな興味。
- 行動: ひまりが開いた無地の教科書を見ながらタブレットの回答を確かめる。らぼまるは原典への短い線を見上げる。
- 場面: 自宅の学習机。朝の光、教科書、タブレット、復習カードが同じ学習状況に属する。
- 手の動作: ひまりの片手は開いた教科書に軽く添え、もう片方は体側で自然に休める。手は遠め。らぼまるの短い丸い腕も自然な本数と向き。
- 装い根拠: 教科書の学習という中心名詞に合わせ、落ち着いた青いカーディガンとしおり飾りを使う。
- 避ける: 棒立ち、説明パネル中心、ロゴ、実在表紙、手の接写、複雑な握り、全教科書無料という誤解。
- 形式: 16:9、完成版1600×900。
