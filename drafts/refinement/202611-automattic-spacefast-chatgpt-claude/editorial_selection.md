# Editorial Selection：Spacefastの一般公開

判定: 限定採用

## 採否の理由

**「AIで作ったページやアプリを、他の人に見せ、更新しながら使うには何が必要か」を説明するニュースとして採用する。**

調査報告では、Automatticが2026年11月9日にSpacefastを一般に開放したこと、ChatGPT・Claudeとの接続方法、公開範囲や更新履歴の管理が公式資料で確認されている。作成後の共有・管理という具体的な論点があり、発表の要約にとどまらない説明ができる。

一方、日本からの登録・決済・接続は未確認で、機能ごとの提供段階にも留保がある。日本向けの利用開始案内、導入手順、利用体験、おすすめサービス比較には広げない。日本の読者への価値は、AIで作ったものを継続して使うための仕組みを理解できる点に置く。

カテゴリは「ニュースをかみくだく」。当サイトによる作成・公開・実測を記事の核にできる証拠がないため、hands-onは選ばない。

本工程では外部資料を再取得していない。以下の事実判定は、引き継いだ調査報告の確認範囲に基づく。

## 採用する切り口

### 中心となる問い

**ChatGPTやClaudeでアプリを作れたら、それだけで他の人にも使ってもらえるのか。Spacefastは、その後の何を引き受けるのか。**

説明の中心は、作成したものをネット上に置くこと、見せる相手を決めること、更新した内容を管理すること。それぞれを分けて説明する。

記事の結論は次の範囲に収める。

> Spacefastは、AIで作ったサイトやアプリの公開・管理を支えるサービス。共有や更新の仕組みが用意されているが、動かせるもの、接続方法、料金には条件がある。

### なぜ今取り上げるか

公式発表は11月9日、採用された国内報道は11月11日であり、一般への開放という直近の変化がある。9月の先行公開と区別し、「今回初めて登場した」とは書かない。

編集上の注目点は、AIによる作成の先にある公開・管理まで扱うこと。「作れたものをどう使い続けるか」という疑問を説明する機会になる。

話題性の広がりは未検証。「大きな話題」「急速に普及」「利用者が殺到」といった表現は採用しない。

### AIの視点で理解できること

AIがページやアプリの内容を作る役割と、それをネット上で使える状態に保つサービスの役割を分けて理解できる。

Spacefastの発表から、ChatGPTやClaude自体の性能向上までは言えない。採用情報の新モデル発表を示す分類は、記事の事実として引き継がない。

## 情報の取捨選択

### 採用

- 一般への開放という発表と、その日付。
- サイトやアプリの公開先としての役割。
- 閲覧範囲の設定と、以前の版へ戻せる更新管理。
- ChatGPT・Claude向けの接続案内があることと、その条件。
- 無料の利用枠、匿名公開の期限、対応形式の制約。

料金と期限は、便利さを判断するための短い補足にする。記事全体を課金診断に寄せない。

### 限定して採用

- **料金の数値**：調査報告F6の公式料金文書に基づく数値だけを使い、確認日・税別米ドル建て・超過利用の条件を併記する。円換算やAI側の契約を含めた総額は示さない。
- **匿名公開の期限**：数値を出す場合は、原則33時間20分という期限と、更新による延長にも作成から30日の上限があることを一緒に説明する。
- **機能の提供段階**：一部が試験提供中または提供予定であることを説明する。サイトを見る人の制限と、アプリ内の利用者を確認する機能を混同しない。
- **別サービスへの移行**：詳しい補足で扱う場合だけ、公開用ファイルとアプリが保存したデータを分け、移し替えに作業が必要な場合があると説明する。

### 不採用にする切り口

- 「新しいAIモデルが登場」「ChatGPT・Claudeが高性能になった」。
- 「日本で正式提供開始」「日本の無料アカウントならすぐ使える」。
- 「どんなアプリでもそのまま動く」「設定も保守も不要」。
- 「完全無料・無制限」「アカウント不要で永久公開」。
- 公開速度、費用削減、生産性、安全性の実証としての紹介。
- 他の公開サービスより簡単・安い・優れているという比較。
- 利用者数、人気順位、普及の勢いを根拠にした紹介。
- 当サイトが作成・接続・公開を試したように読める描写。

いずれも、引き継いだ調査では裏付けられない。

## 読者翻訳設計

この節は内部の執筆設計であり、公開本文へコピーしない。

### 主題の一言説明

AIで作ったページや小さなアプリをネット上に置き、見せる相手や更新内容を管理するサービスの話。

### 関係がある人

- ChatGPTやClaudeでページや小さなツールを作り、誰かに使ってもらいたい人。
- 作成したものの共有先や、公開後の更新方法を知りたい人。
- AIによる作成と、その後の公開・管理の違いを理解したい人。

### あまり関係がない人

- AIとの会話、文章作成、調べものだけを使い、サイトやアプリを公開しない人。
- 現在の公開先で困っておらず、移行を検討していない人。

後者に乗り換えを促す根拠はない。ニュースを理解するために、登録や契約が必要な構成にしない。

### 専門用語

公開本文で使う用語の表記を以下に定める。各語は初出の同じ文か直後の一文で説明する。料金プランの固有名や開発者向けの接続規格名は本文へ持ち込まず、必要な条件を日常語で説明する。

- AI → 文章や指示をもとに、回答や作成物を出すコンピューターの仕組み。
- Automattic → 今回Spacefastの一般公開を発表した会社。
- Spacefast → 作ったページやアプリをネット上に置き、公開後の管理を助けるサービス。
- ChatGPT → 質問への回答や文章・プログラムの作成を頼めるAIサービス。
- Claude → 質問への回答や文章・プログラムの作成を頼めるAIサービス。
- Webサイト → ネット上で開いて読んだり使ったりするページのまとまり。
- アプリ → 入力に応じて計算や記録などの仕事をするソフト。
- アカウント → 利用者を識別し、自分の作成物などを管理するための登録。
- 共有リンク → 他の人が作成物を開くために渡すリンク。
- バージョン → 更新の前後を区別するために残される、それぞれの版。
- ベータ → 正式提供に向けて試験的に提供されている段階。
- 従量料金 → 使った量に応じて増える料金。

「一般公開」は、サービスを広く利用できるようにする意味と、作成物を誰でも見られる状態にする意味を、対象を明記して使い分ける。

### 事実から言えること

- 公式発表として、11月9日に一般へ開放されたこと。
- 公表仕様として、公開範囲や更新履歴を管理する仕組みがあること。
- ChatGPT・Claude向けの接続方法が案内されていること。
- 無料の利用枠、公開期限、対応形式などに条件があること。
- 編集上の整理として、AIによる作成の後に必要となる公開・管理を理解する題材になること。

### 事実から言えないこと

- 日本の読者が、現在の契約や端末ですぐ利用できること。
- AIで作ったものが、修正なしで必ず動くこと。
- 公開できれば、不具合や情報管理の問題も解決すること。
- 無料枠だけで、任意のアプリを継続運用できること。
- 全機能が正式提供され、同じ条件で使えること。
- 他サービスより安く、簡単で、速いこと。
- 当サイトが接続や動作を確認したこと。

## 本文への引き継ぎ

仮題は、**「AIで作ったアプリ、その後は？ Spacefastの公開・管理の仕組み」**。

本文は「これは何か → 自分に関係するか → 今回の変化 → 共有・更新でできること → 条件と未確認事項 → 詳しい補足」の順にする。

「30秒で分かる」は「これは何？」「何があった？」「誰に関係ある？」「結局どうなの？」の4項目。関係が薄い人も短く示す。詳しい利用判断は後半の1〜2ブロックに収める。

ひまりは「AIで作れたら、友だちもそのまま使えるの？」という疑問を出し、らぼまるは公開先・見せる範囲・更新管理を分けて答える。会話を架空の利用体験にしない。

図解に向く論点は「作成から公開・管理までの役割」「サービスの一般公開と作成物の公開範囲の違い」。本工程では本文、画像構成、画像生成へ進まない。
