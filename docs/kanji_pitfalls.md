# kanji_pitfalls.md — 画像生成で化けやすい漢字・語の回避リスト

画像生成（スライド・サムネ）では、AI が **形の似た漢字を取り違える**ことがある。
X 直接投稿で拡散するとリスクが大きいので、**slide_plan 段階で「化けやすい漢字を含む文言はひらがな・言い換えを優先」する**。
新しい化けを見つけたら、このファイルに 1 行追記して蓄積する（再発防止の恒久リスト）。

## 使い方（slide_plan 段階の恒久ルール）

- スライドの帯・見出し・吹き出しに入れる**短い文言**は、下表の「化けやすい語」を避け、**言い換え or ひらがな**にする。
- 特に **1〜4 文字の短い語**（帯・ラベル）は化けても気づきにくいので優先的に言い換える。
- 数字・固有名詞・日付は化けやすくないが、**助詞の欠落・重複**（「目的ことで」等）は別途 factcheck 項目11で検出する。
- 独立検品（Phase C 前）でも、下表のパターンに一致する文言が画像内にあれば重点確認する。

## 化けやすい漢字・語（実測ベース・追記していく）

| 化けやすい語 | 誤りやすい形 | 推奨（言い換え/ひらがな） | 出典・メモ |
|---|---|---|---|
| 目的 | 「自的」（目→自） | 「目的」を避け **「使い方」「ねらい」「何のため」** | 2026-07-14 Atlas slide06「目的別に」→「自的別に」が2回連続で化け。「使い方で入口が分かれたよ」に言い換えて回避 |
| 目 単体 | 自 / 日 | 文脈により **「見る」「チェック」** に置換 | 「目→自」「目→日」は頻出 |
| 未 | 末 | **「まだ」** とひらがな | 「未／末」は上下の横棒差で化けやすい |
| 末 | 未 | **「さいご」「終わり」** | 同上 |
| 千 | 干 | 数字は算用数字（1,000 等）にする | |
| 巳 / 已 / 己 | 相互 | 使わない・言い換え | ほぼ判別不能 |
| 微妙 | 徴妙 | **「びみょう」「ちょっと不安」** | 微/徴 は化けやすい |
| ణ・機種依存/絵文字 | 文字化け（□・豆腐） | スライド内テキストに絵文字・特殊記号を入れない | |

> **原則**: 帯・ラベルは「短い漢字語」より **やさしい和語・ひらがな**の方が化けにくく、すまラボのトーンにも合う。
> 迷ったら漢字を減らす。

## 記録の仕方（新しい化けを見つけたら）

1. 上表に 1 行追記（化けやすい語 / 誤りやすい形 / 推奨 / 出典）。
2. その記事の `logs/article/{slug}.images.json` の notes に「◯→◯ 化けを言い換えで回避」と残す。
3. 同じ語が 2 回以上化けたら、slide_plan 側の既定言い換えに昇格させる（表の「推奨」を強い表現にする）。
