## 今の3つの賭け（2026-07-14〜）

1. **サムネの「驚き」路線** — 注意・速報系は「えっ!?」の驚き顔でスクロールを止める（Claude 自動）。
2. **タイトルの感情強度アップ** — 主タイトルは「消える/変わる/損する＋あなた」で刺す。事実の裏付けは gate が担保（Claude 自動）。
3. **配信面を X の画像投稿に寄せる** — リンク付き投稿 1 本 →「スライド画像4枚を直接添付した本投稿＋リプライに記事リンク」（Claude 自動）＋ **はてブ 1 ブクマ目を人間が付ける**（← このドキュメントの主眼）。

## 公開直後（最初の30分）に人間がやること

### ① はてブの「1 ブクマ目」を自分で付ける（最優先・所要1分）

- 記事末尾の **「はてブ」ボタン** を押す（`https://b.hatena.ne.jp/entry/panel/?url=...` が開く）。
- 自分のはてなアカウントで **1 ブクマ**する（コメントは任意。付けるなら記事の要点を 1 行）。
- 理由: はてブは **3 users で「新着エントリー」入りの可能性**が出る足がかりになる。最初の 1 が無いと誰にも見えない。
- **やりすぎ禁止**: 自作自演の大量ブクマ・複数アカウントは規約違反かつ逆効果。**自分の 1 ブクマだけ**。

### ② X の本投稿（画像4枚）に人間が軽く反応する

- Claude が投稿した **画像4枚の本投稿**（1枚目=サムネの驚き顔）を開く。
- リプライに記事リンクが付いているか確認（付いていなければ Claude に指示）。
- 自分の個人アカウントがあれば **引用でなく「いいね + リポスト」**で初速を付ける（任意）。
- **本投稿にリンクを足さない**（リンクは必ずリプライ側。本投稿にリンクを入れると露出が絞られる）。

### ③ 最初のコメント/リプライで会話の呼び水を作る（任意）

- X の本投稿へのリプライで、記事リンクの下に **「特に◯◯が要注意でした」**など 1 行の補足を足す。
- はてブのコメント欄に **要点 1 行**を書いておくと、後続ブクマが付きやすい。

## 恒久ルール（人間側）

| やること | やらないこと |
|---|---|
| 公開直後にはてブの1ブクマ目を付ける | 複数アカウントでの自作自演ブクマ |
| X本投稿に「いいね+リポスト」で初速 | 本投稿にリンクを足す（リンクはリプライ） |
| はてブ/リプライに要点1行の呼び水 | 事実に反する煽り（gateが弾くが人間も足さない） |
| 反応が良い型をメモして次に活かす | 同じ記事を何度も投稿（二重投稿禁止） |

## 計測（どの型が伸びたか）

- X 投稿の型は台帳 `data/social/x-posted.json` の `variant` に記録される（`images4+reply` / `text_only` など）。
- 週次ダイジェスト（`npm run digest`）で PV / 投稿インプレの伸びを型別に見返し、
  **伸びた型（画像投稿 vs リンク投稿、驚きサムネ vs 従来）を次の既定に寄せる**。
- 判断材料が溜まったら、このプレイブックと `autonomy.json` の `xPostOptions` を更新する。

## Claude 側の自動化との対応（人間が手を出さなくてよい部分）

- タイトルの感情強度・裏付け → `phase-a-orchestrator.mjs`（write_mdx 指示）＋ `sumalabo-gate.mjs`（title-fact-backing 検査）
- サムネの驚きトーン → `assets/characters/character-sheet.md`（感情トーン）＋ factcheck 項目12
- X 画像4枚投稿＋リプライリンク → `autonomy.json` の `xPostOptions`（`attachSlides/leadWithThumbnail/linkInReply`）＋ `x-post-options.mjs` / `generate-x-post.mjs` / `phase-c-auto.mjs`
- はてブボタン設置 → `src/layouts/ArticleLayout.astro`（記事末尾のシェア行）

人間が担うのは **「公開直後の 1 ブクマと軽い初速付け」だけ**。それ以外は Claude が回す。
