# アフィリエイト導入ガイド（もしもアフィリエイト / A8.net）

作成: 2026-07-11 ／ 対象: すまラボ (sumalabo.com) 運営者

このドキュメントは、(1) ASP 2 社への申請に必要な情報と審査観点、(2) すまラボが要件を満たしているかのセルフチェック結果、(3) 画面単位の申請手順、(4) 審査通過後にやること、をまとめたものです。

> **注意**: ASP の画面・審査基準は変わることがあります。申請時に画面が本書と違う場合は、画面の案内を正としてください。ID・パスワード等の secret はこのリポジトリに置かないこと（公開ページに出力される a_id 等の ID のみ `src/config/affiliate.ts` に置く）。

## 0. すまラボの設計（前提の再確認）

- **二層構造**: ニュース記事（type: news）と「やってみた・検証」（hands-on）には当面広告を入れない。収益導線は資産記事（type: revenue / foundation の比較・選び方系）と「周辺機器・ガジェット」「スマホの選び方」「通信費を下げる」カテゴリ限定
- **主軸 = 物販**（Amazon / 楽天 / Yahoo!ショッピング、**もしもアフィリエイト**経由）
- **従 = SIM 系など高単価 ASP 案件**（**A8.net**、資産記事限定・CTABox 使用）
- 広告を含む記事は frontmatter `hasAffiliate: true` → 記事冒頭に広告表示ラベルが自動表示（景表法ステマ規制対応）。ラベル無し・ニュース混入は `sumalabo:gate` が不合格にする

## 3. もしもアフィリエイト 申請手順（画面単位）

物販（Amazon / 楽天 / Yahoo!）の本命。**W報酬制度**（通常報酬 +12% 上乗せ）があり、Amazon アソシエイト直よりも審査ハードルが低い。

1. **トップページ** https://af.moshimo.com/ → 「会員登録する（無料）」
2. **メールアドレス登録画面**: メールアドレスを入力 → 届いた確認メールの URL を開く
3. **アカウント情報入力画面**: ユーザー ID・パスワード・氏名・住所・電話番号を入力
4. **サイト登録画面**: サイト URL（https://sumalabo.com）・サイト名・カテゴリ（パソコン・家電など近いもの）・月間 PV（正直に）・サイト説明を入力
   - サイト説明例: 「スマホ・AI・ガジェットのニュースをやさしく解説するブログ。周辺機器の比較・選び方記事で商品を紹介」
5. **登録完了 → サイト審査**（数日〜1 週間程度）。結果はメールで届く
6. **サイト審査通過後、モールごとの提携申請**（管理画面 → プロモーション検索）:
   - 「**Amazon.co.jp 商品購入**」→ 提携申請（**Amazon 側の審査あり**。数日〜2 週間。落ちても記事を増やして再申請可）
   - 「**楽天市場 商品購入**」→ 提携申請（即時〜数日。通りやすい）
   - 「**Yahoo!ショッピング 商品購入**」→ 提携申請（通りやすい）
7. **銀行口座登録**: 管理画面 → マイページ → 口座情報

## 4. A8.net 申請手順（画面単位）

SIM 系など高単価案件用。**登録時サイト審査が実質なし**で始めやすいが、**案件（広告主）ごとの提携審査**がある。

1. **トップページ** https://www.a8.net/ → 「アフィリエイトをはじめてみる！」（無料会員登録）
2. **メールアドレス登録画面**: メールアドレス入力 → 仮登録メールの URL を開く
3. **基本情報入力画面**: ログイン ID・パスワード・氏名・住所・電話番号を入力
4. **メディア情報入力画面**: 「サイトをお持ちの方」を選択 → サイト名・URL・カテゴリ・月間訪問者数・サイト紹介文を入力
5. **口座情報入力画面**: 振込先口座を登録 → 登録完了
6. **案件との提携**: 管理画面 → プログラム検索 → 「格安SIM」「モバイル回線」等で検索 → 各案件の詳細を確認して提携申請（案件ごとに即時提携〜審査数日）
   - 選ぶ基準: 成果条件（新規契約のみか）／確定率／EPC より、**すまラボの記事文脈（比較・選び方）に自然に置ける案件**を優先

## 5. 審査通過後にやること（ID 設定箇所）

### 5-1. もしも（物販）の ID 設定 — 1 か所でサイト全体に反映

1. もしも管理画面 → 対象プロモーション（例: Amazon）→ どこでもリンク（または商品リンク作成画面）で生成されるリンク URL から `a_id` / `p_id` / `pc_id` / `pl_id` の 4 値を控える
2. **[`src/config/affiliate.ts`](../src/config/affiliate.ts)** の `affiliateConfig.moshimo.amazon / rakuten / yahoo` に 4 値を設定
3. **[`src/data/affiliateLinks.ts`](../src/data/affiliateLinks.ts)** の各商品に**素のモール URL**（商品ページの通常 URL）を入れる
4. `npm run build` → 既存の ProductCard / AffiliateLinks のリンクが**一斉にもしも経由のアフィリエイトリンク（rel="sponsored"）に切り替わる**（ID 未設定のモールは通常リンクのまま）
5. deploy（**4:00〜7:00 は回避**）

### 5-2. A8（案件）の設定 — 記事ごと

1. A8 管理画面 → 提携済み案件 → 広告リンク作成 → テキストリンクの URL（`https://px.a8.net/svt/ejp?a8mat=...`）を控える
2. 対象の資産記事に `<CTABox title="..." buttonLabel="..." href="（A8のURL）" note="..." />` を設置
3. 記事 frontmatter に `hasAffiliate: true` を付ける（無いと gate 不合格）
4. `npm run sumalabo:gate -- --slug <slug> --stage full` → build → PR → 通常の公開フロー

### 5-3. 最初に収益化する記事の候補 3 本

| 1 | [power-bank-comparison](../content/articles/power-bank-comparison.mdx)（モバイルバッテリー比較・type: revenue） | AffiliateLinks 9 商品が**配線済み**。URL を入れるだけで即収益化 | affiliateLinks.ts に素 URL 投入のみ |

## 6. 運用ルール（再掲・gate が機械的に強制するもの）

- アフィリエイトリンク / ProductCard / CTABox / AffiliateLinks を含む記事は **`hasAffiliate: true` 必須**（無いと gate 不合格）→ 記事冒頭に「本記事は広告（アフィリエイトリンク）を含みます」が自動表示
- **type: news または category: やってみた・検証 の記事にアフィリエイトは当面不可**（リンク・コンポーネント・hasAffiliate すべて gate 不合格）。将来解禁する場合も `hasAffiliate: true` と広告表示を必須にする。
- 台帳（ledger.json）に `hasAffiliate` が写像される（`ledger.mjs --sync`）。広告あり記事の流入・成果分析の下地
- リンクの rel は自動制御: アフィリエイト時 `nofollow sponsored noopener` / 通常リンク時 `noopener`
