character_assets_manifest.txt

[概要]
このファイルは、すまラボで使用するキャラクター画像素材の役割・用途・推奨配置位置を整理したマニフェストである。
Claude Codeや記事制作時は、このファイルを参照し、記事の役割・内容・配置位置に応じて最も適した画像を選ぶこと。
画像は装飾ではなく、理解補助・導線補助として使う。
原則として、1記事あたりのキャラクター画像使用は1〜3回までとする。
短い速報記事では無理に使わない。
スマホ表示を優先し、画像だけで意味を持たせず、短い補足テキストや吹き出しとセットで使うこと。

==================================================
[選択ルール]
==================================================

1. まず記事タイプを確認する
- 土台記事
- 収益記事
- 流入記事

2. 次に使う目的を確認する
- 導入をやわらかくしたい
- 用語の入口を作りたい
- 注意点を補足したい
- 比較の軸を整理したい
- 次の記事へ案内したい

3. 目的に合う画像を選ぶ
- 導入・疑問整理: Curious with a question mark.png / Curious conversation with a cute mascot.png
- 汎用導入: Adorable robot with mint accents.png / Joyful girl in a cute outfit.png
- 注意点: Worried chibi robot with antenna.png
- 比較整理: Adorable pastel robot mascot with chart icon.png / Friendly robot mascot with analytics chart.png
- 案内導線: Friendly guide duo with tech mascot.png

4. 配置回数を確認する
- 短めの記事: 1〜2回
- 通常の記事: 2〜3回
- 長い比較記事: 3回まで
- 4回以上は原則使わない

[実装上の注意]
==================================================

- 画像は装飾ではなく、理解補助・導線補助として使う
- 本文より目立たせない
- 画像だけで意味を持たせず、短い補足テキストや吹き出しとセットで使う

- 無理に使わない。不要なら使わない判断を優先する
