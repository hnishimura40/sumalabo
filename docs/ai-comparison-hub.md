# AI常設比較ガイドの初版と編集方針

入口は `/ai/`。最新ニュースとは別の常設ページとし、ヘッダーと既存のモデル・費用ガイドからたどれる。2026-11-15時点の初版は26件の機能概要と6つのベンチマークの入口。初版はnoindexのプレビューであり、網羅性・料金表・性能の独自実測が完成したとの表示はしない。

## 比較の単位

- サービス、実行ツール、モデル群を明示する。同じ点数で順位付けしない。
- 使える機能、作業の実行場所、モデル推論の場所、公開されているもの、ライセンスを別項目にする。
- オンラインとオープンソースを排他的に分類しない。重みの公開、アプリのコード公開、自己ホスト、OSIのOpen Source AI定義を混同しない。
- チャット、調査、資料、画像生成、動画生成、楽曲生成、音声、開発、実行を横断する。画像・動画の理解と生成、音声会話と曲の生成を混同しない。
- Dots、Muse、Claude Duetは常時動くAIの比較欄を設ける。会話を閉じた後の継続、記憶、接続、承認・活動記録、利用地域と枠を確認する。未実測の完走率を推測しない。

## 初版に実装したこと

検索、種類・機能・実行場所の絞り込み、比較項目の切り替え、3件までの選択比較、条件のURL共有、公式リンクと確認日、確認30日経過の表示。JavaScriptなしでも比較表の内容は読める。ライト・ダークは既存のトークンと切り替えを使う。

データは `src/data/ai-comparison.ts`。個別の型番・プランが未確定の箇所を系列や製品全体へ転用しない。「未確認」は非対応ではない。全ての行を実測済みと扱わない。

## 完成版で埋めるデータ

| 比較表 | 必須情報 |
| --- | --- |
| 料金・利用枠 | 月払い／年払い、通貨、税込区分、個人／法人、席数、無料枠、回数・期間、クレジット、超過時、API別課金、根拠と確認日 |
| 生成機能 | 正式モデル、画像の参照・編集・文字、動画の尺・画質・音声・参照、音楽の歌・長さ・編集・商用条件、音声の言語・同意、地域・年齢・プラン |
| エージェント | 単発／継続、実行環境、ローカル端末の起動条件、連携、メモリーの制御、送信・購入時の承認、履歴、停止・再開、費用上限 |
| 個別公開モデル | 正式モデルID・版・量子化・サイズ・入出力、配布元、ライセンス、用途制限、商用・再配布条件、実測機材・VRAM・速度 |
| ベンチマーク数値 | 名称と版、測定日、正式モデルID、推論設定、ツール・ハーネス、試行数、費用、測定主体、標本と不確実性、根拠URL |
| 日本語の独自実測 | 同一の公開課題、入力と条件、試行数、成功・所要時間・修正回数・実費、失敗例、実行日、再現手順 |

独自実測の課題例は、日本語PDFの出典付き要約、表計算の照合、実際に開ける資料の作成、同一素材からの画像・動画・楽曲、既存コードへの変更とテスト、承認を要する操作で止まれるか。権利のある入力とテスト用データを使う。未実施の成績・作品を作らない。

## 更新と公開

リリース、料金改定、モデルカードや提供地域の変更を確認して差分をPRにする。料金・提供条件は週次の確認を推奨するが、この作業で新しい定期実行は登録していない。本文では公開日ではなく項目の確認日を表示する。

初回の本番反映前に、日本利用・料金・商用条件など未確認欄の扱い、掲載範囲、確認日を編集上確認する。noindexを外す場合はsitemapとcanonicalも照合する。自動公開キューには登録しない。プレビューはmain以外のブランチへ正規のCloudflareヘルパーで配信し、PRはdraftで残す。

## 参考にした比較の見せ方

- [manapick AI](https://ai.manapick.app/compare/)：用途、無料枠、日本語、確認日を横断して読む入口。
- [AI Compare Ninja](https://www.aicompare.ninja/ja/)：ツール探しと料金・利用条件への導線。
- [Artificial Analysis](https://artificialanalysis.ai/methodology/intelligence-benchmarking)：測定条件と能力・費用・速度を分ける見方。
- [Arena](https://arena.ai/leaderboard)：用途ごとの比較評価。固定試験や公式仕様とは区別する。

構成上の参考として参照し、他サイトの文章・表・独自スコア・画像を転載しない。機能の事実は各行に掲載した提供元の一次情報から確認する。
