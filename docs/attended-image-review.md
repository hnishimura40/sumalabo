# 公開後の画像確認と即時差し替え

2026-08-01 Hiro決定。2026-07-29に導入した公開前30秒確認は廃止する。立ち会い・夜間とも、一次独立検品と手の二段検品を通過した画像は人の応答を待たず公開する。

## 現行手順

1. 一次独立検品、身体構造検品、手が見える画像の二段クロップ検品を機械実行する。
2. needs_revision が0件ならそのまま本番公開・厳格検証へ進む。warningは従来どおり報告する。
3. 公開後にHiroが画像を確認し、問題があれば該当画像だけを再生成→独立検品→差し替え→キャッシュパージする。

## 不変ルール

- すべてのrun-modeで公開前の人待ちは設けない。run-modeは監査上の経路識別だけに使う。
- 公開前に人の確認を待つゲートを新設してはならない。
- 品質・安全の機械ゲート不合格時は公開せず、自動修正後も残る場合だけ停止・報告する。

## 生成側の既定

自然な構図を優先し、手を隠すことを既定にしない。壊れにくい手として、開いた手・軽く添える手を優先する。手は小さめ・遠めに描き、クローズアップを避ける。動作する手は片手だけにし、もう片方は体側で自然に休ませる。物を強く握る、両手で別々の動作をする、指を複雑に組む・数えるポーズは避ける。小道具の把持が不可欠な場合だけ、片手で軽く持つ。手を消すためにフレームアウト・後ろ手・机の陰へ不自然に退避させない。テーマ衣装、小道具の配置、姿勢と視線、テーマ固有の背景は弱めず、現行の二段検品をバックストップとして適用する。
