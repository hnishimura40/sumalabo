## 認識アンカー（不変）と 衣装（可変）の区別 ★重要

すまラボのキャラは「**認識アンカーは絶対に固定・衣装や小道具はテーマに合わせて変える**」が基本方針。
アンカーさえ保てば同一キャラと認識できるので、衣装を変えても「別人化」にはならない。

## やってはいけない描き方（両キャラ共通）

- **認識アンカーを変える**（ひまりの髪色・髪型・顔立ち・頭身／らぼまるのボディ形状・アンテナ・目・ハートバッジ・体型）＝“別人化”禁止（blocking）。
  - ※ **服・上着・小道具・シチュエーションを変えるのは別人化ではない**（サムネではむしろ推奨）。アンカーが保たれていれば衣装変更は許容。
- 頭身を大きく変える（ひまりをデフォルメ 2 頭身にする等。正本の頭身を維持）
- 実在の企業ロゴ・実在人物と組み合わせて描く
- 恐怖・不安を煽る表情や構図（泣き叫ぶ・絶望など。困り顔は「軽い困惑」まで）
- キャラを「置物」として意味なく配置する（理解補助・感情表現の役割を持たせる）
- ひまりに**露出の多い/扇情的な衣装**・キャラ崩壊するポーズ（衣装は自由だが、この一線は不変）

## サムネイル方針（体験図・2026-07-04 恒久変更）

サムネイルは「内容の紹介図」ではなく「**内容を体験している絵**」とする。主役は使っている人またはひまり・らぼまる。

- **型は 3 つ**（毎回どれかを選ぶ）:
  1. **活用シーン型** — 題材を実際に使っている瞬間
  2. **変化実感型** — それがあることで変わった瞬間・戻ってきた瞬間
  3. **擬人化型** — 題材そのものをキャラ化して登場させる（キャラは正本の見た目を維持）
- **感情は 1 枚に 1 つ**（驚き・安心・困った→解決 など。混ぜない）
- **文字は最小限**（大見出し + 短いサブ程度。3 要点カードのような情報整理はしない — それはスライド 8 枚側の役割）
- **本文が約束していない体験は描かない**（煽り禁止・未確定断定禁止と同じ線）
- サムネも画像ファクトチェックの対象（文字・固有名詞・ブランド名の誤記検査）
- 16:9 1600×900。実在ロゴ精密再現なし・日本円なし・炎上風なし

### サムネの衣装は「変えることを基本とする」★恒久方針（2026-07-08）

サムネは体験図なので、キャラの**衣装・小道具・シチュエーションをテーマに合わせて変えるのを既定**とする。
標準衣装のまま出すのは「ひねりが不要なとき（時事の続報で前回と揃えたい等）だけの例外」。

- **サムネ生成時、記事テーマから連想される衣装・小道具・シチュエーションを必ず 1 つ選び、プロンプトに明記する。**
  「標準衣装のひまりが立っている」だけのサムネは原則作らない。
- **認識アンカー（ひまり=金髪ツインテール・顔立ち・頭身／らぼまる=白ボディ・アンテナ・ハートバッジ・体型）は不変**が大前提。
  変えるのは服・上着・アクセ・持ち物・背景・シチュエーションであって、キャラの同一性ではない。
- らぼまるは素体なので服は着せず、**帽子・小道具・持ち物・背景**でテーマを表現する。
- **露出の多い/扇情的な衣装は不可**（衣装は自由でもこの一線だけは不変）。

**テーマ→装い マッピング例（必ずしもこの通りでなくてよい。連想の起点）:**

| 記事テーマ | 装い・小道具の例 |
|---|---|
| AIモデル / 性能 / 研究 | 白衣・ラボゴーグル・試験管・グラフボード（研究着） |
| 料金 / プラン / サブスク | ビジネスカジュアル・電卓・料金表・財布/コイン |
| 発表会 / 新製品ローンチ | ジャケット・ステージ・スポットライト・登壇風 |
| 季節ネタ（夏/冬/年末 等） | 季節の装い（夏＝軽装・麦わら、冬＝マフラー/コート、年末＝和装 等） |
| セキュリティ / 注意喚起 | 探偵/ガード風の装い・虫めがね・盾アイコン |
| 時間 / 締切 / カレンダー系 | カレンダー・大きな時計・砂時計・「締切」メモを持つ構図 |
