ここで言う「エージェント機能」とは、AIに一問一答で答えてもらうだけでなく、**複数の手順がある作業を AIに進めてもらう機能** です。記事の構成を作って、比較表を整えて、必要な部分を修正して、最終案までまとめる──といった一連の作業を任せやすくします。最終確認は人間が必要ですが、**作業の下準備や修正案づくりをかなり速くしてくれる道具** と考えると安全です。

## Cursor と GitHub Copilot はどう見る？

今回の主役は ChatGPT Pro / Claude Max / Google AI Ultra ですが、エージェント型 AI やコーディング AI を考えるなら **Cursor と GitHub Copilot** にも触れておきます。

* **Cursor（カーソル）** — AI 前提のコードエディタ。Pro 20ドル、Pro+ は日常的なエージェント利用者向け、Ultra はエージェントをかなり重く使う人向け。
* **GitHub Copilot（ギットハブ・コパイロット）** — GitHub / VS Code 中心の開発支援 AI。Pro+ は月39ドル、すべてのモデルへのアクセス・月1,500のプレミアムリクエスト・追加リクエストは1件0.04ドル。

文章作成・画像生成・調査まで含めた総合 AI ではありませんが、開発作業に寄せるならかなり強い選択肢になります。

## まとめ：100ドル課金は「中心にするAI」を決めてから

月100ドル級のAI課金は、なんとなく入るプランではありません。大事なのは **20ドル級から何が増えるのか** を見ることです。

* ChatGPT なら Plus から Pro に上げると、Codex / Deep Research / Agent mode / 画像 / ファイル作業をより重く使える
* Claude なら Pro でも Claude Code は使える。Max に上げる意味は Claude Code や長文処理を毎日たくさん使うかどうか
* Google なら AI Pro から AI Ultra に上げると、Antigravity / NotebookLM / 20TB ストレージ / YouTube Premium まで含めて強化される

100ドル課金は「一番すごいAI」を選ぶというより、**自分が一番よく使うAIを強化する選択** です。まずは20ドル級で使い方を見極めて、上限に当たる・作業時間が大きく減る・もっと任せたいと感じたら100ドル級へ。この順番で考えると、かなり失敗しにくくなります。
