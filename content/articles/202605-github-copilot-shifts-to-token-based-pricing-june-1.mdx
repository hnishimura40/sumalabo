## 何が起きたのか

GitHubは、GitHub Copilotの料金体系を2026年6月1日から使用量ベースへ移行すると発表しました。

これまでのCopilotでは、「プレミアムリクエスト」という考え方が使われていました。かなりざっくり言うと、AIに頼んだ回数や種類を一定のルールで数える仕組みです。

新しい仕組みでは、それがGitHub AI Creditsへ置き換わります。Copilotの利用量を、AIが処理したトークン量や使ったAIモデルに応じて数える方向になります。

ただし、これは「月額プランが全部なくなる」という意味ではありません。各プランに毎月のAI Creditsが含まれ、その範囲を超えるような使い方では追加利用を意識する必要が出てくる、という整理が近いです。

## GitHub Copilotとは？

GitHub Copilotは、プログラミングを手伝ってくれるAIサービスです。

コードを書いている途中で次に書く内容を提案したり、エラーの原因を一緒に考えたり、複数のファイルを見ながら修正案を出したりできます。

以前のCopilotは「コード入力を少し助けるAI」という印象が強いものでした。最近はそこから一歩進んで、AIがまとまった作業を手伝うエージェント型の機能も広がっています。

つまり、短い質問に答えるだけでなく、長いコードを読み、複数のファイルを理解し、作業の流れそのものを手伝う方向に進んでいます。

## AI Creditsとは？

GitHub AI Creditsは、CopilotでAIを使った量を数えるための単位です。

買い物のポイントというより、「AIにどれくらい処理をお願いしたか」を料金計算へ反映するためのものだと考えると分かりやすいです。

GitHubの説明では、各Copilotプランに毎月のAI Creditsが含まれます。使い方がその範囲に収まるなら、基本的には月額プラン内で使えます。

一方で、AIに長時間の作業を任せたり、高性能なモデルで複雑な作業をさせたりすると、AI Creditsの消費が増えやすくなります。

## トークンって何？

トークンは、AIが読み書きする文字やコードの細かい単位です。

たとえば、短い質問をするだけなら、AIが読む量も返す量も少なめです。使われるトークンも少なくなりやすいです。

一方で、長いコードを読ませたり、大きなファイルをいくつも確認させたり、AIに長い修正案を書かせたりすると、トークンは増えやすくなります。

今回の料金体系変更は、この「AIが実際にどれくらい処理したか」を、より料金に反映しやすくする流れだと見ると理解しやすくなります。

## 従量課金とは？

従量課金とは、使った量に応じて料金が変わる仕組みです。

身近な例で言えば、電気代や水道代に近い考え方です。たくさん使えば負担が増え、あまり使わなければ少なく済みます。

GitHub Copilotの場合も、完全に月額料金が消えるという話ではありません。月額プランに一定量のAI Creditsが含まれ、その範囲を超えるような使い方では追加利用を考える形です。

ここで大事なのは、「AIへの軽い相談」と「AIに長時間作業を任せること」は、裏側の負荷がかなり違うという点です。

## 何が新しいのか

今回の変更で新しいのは、AIの料金が「回数」よりも「処理量」に近づくことです。

短い質問と、数時間にわたる自律的なコーディング作業では、必要な計算量がまったく違います。それを同じように扱うのは、AIサービスが高機能になるほど難しくなります。

GitHubは、Copilotが単なる補助ツールから、よりエージェント的な作業を担う存在へ進んでいることを背景として説明しています。

これは、AIサービスが「便利になるほど、料金の見方も変わる」段階に入っているということです。

## コード補完だけなら、すぐ大きな負担増とは限らない

今回のニュースを見て、「Copilotを少し使うだけでも追加料金がかかるの？」と不安になる人もいるかもしれません。

ここは落ち着いて見たいところです。

GitHubの説明では、標準的なコード補完やNext Edit Suggestionsは、有料プランに含まれる扱いとして説明されています。つまり、軽い入力補助だけの使い方なら、すぐ大きな負担増になるとは限りません。

一方で、Copilot Chatで長く相談する、複数ファイルの修正をAIエージェントに任せる、高性能モデルを使って重い作業をさせる、といった使い方ではAI Creditsの消費を意識する必要があります。

## どんな人に影響が大きい？

影響が大きそうなのは、Copilotを「ちょっとした補助」ではなく「作業を任せる道具」として使っている人です。

| 使い方 | 影響の見方 |
|---|---|
| コード補完を中心に使う | 影響は比較的小さい可能性があります |
| Copilot Chatで長く相談する | AI Creditsの消費を確認したい使い方です |
| AIエージェントに複数ファイルの作業を任せる | 消費が増えやすい可能性があります |
| 高性能モデルをよく使う | モデルごとのコスト差に注意が必要です |
| 会社やチームで使う | 予算管理や利用ルールが重要になります |

個人で使っている人は、自分のプラン、毎月含まれるAI Credits、追加利用の扱いを確認しておくと安心です。

会社で導入している場合は、人数が増えるほど全体の消費も大きくなります。管理者が予算上限や利用ルールを決めておく必要が出てきます。

## 普通の人にどう関係するのか

GitHub Copilotを使っていない人が、今すぐ何か設定を変える必要はありません。

ただし、このニュースはAIサービス全体の流れとして見ると重要です。

最近のAIは、質問に答えるだけでなく、文章を作る、コードを書く、画像を生成する、資料を読む、パソコン上の作業を進める、といった方向へ広がっています。

便利になる一方で、AIを動かすには大きな計算コストがかかります。そのため、今後は「月額料金だけで何でも無制限」ではなく、軽い使い方はプラン内、重い使い方は追加負担、という設計が増える可能性があります。

これは、スマホのAI機能やAIアプリを選ぶときにも関係してくるかもしれません。

## AIスマホやAIアプリにもつながる話

AIスマホやAIアプリでも、今後は似たような見方が必要になる可能性があります。

たとえば、スマホ本体の中で処理する軽いAIと、クラウド上の高性能AIを使う機能では、裏側のコストが違います。

画像生成、動画生成、長文の要約、大量のファイル分析のような重い処理は、ずっと無料・無制限で提供し続けるのが難しい場合があります。

AI機能を選ぶときは、これからは次のような点を見るのが大事になりそうです。

- 何が月額プラン内で使えるのか
- どこから追加料金になるのか
- 高性能モデルの利用に制限があるのか
- 自分の使い方だと上限に届きそうか
- 使いすぎを防ぐ設定があるのか

## まだ分からないこと

現時点で注意したいのは、実際の負担感は人によってかなり変わることです。

同じCopilotユーザーでも、コード補完中心の人と、AIエージェントに長時間作業を任せる人では消費量が違います。

また、プラン、契約形態、管理者設定、モデルの選び方によっても変わります。すべての人に対して「必ず高くなる」「必ず安くなる」と断定するのは早いです。

料金、含まれるAI Credits、追加利用の条件は、利用前にGitHubの公式案内や自分のアカウント画面で確認してください。

## すまラボ的な見方

今回のニュースは、単なる「GitHub Copilotの料金変更」ではありません。

すまラボ的には、AIサービスが本格的な作業道具になっていくほど、料金体系も「どれだけAIを働かせたか」に近づいていく流れとして見ています。

これは悪い話だけではありません。軽い使い方の人と、重い使い方の人を分けて考えやすくなる面もあります。

ただし、利用者側は「月額料金だけ見れば安心」とは言いにくくなります。AI機能を使う前に、プラン内で何ができるのか、追加負担はどこからなのかを確認する習慣が大事になります。

## まとめ

GitHub CopilotのAI Credits移行は、開発者向けのニュースに見えます。

でも本質は、AIサービスが便利になるほど、料金の考え方も「使った量」に近づいていくということです。

Copilotを使っていない人は、慌てる必要はありません。ただ、AIアプリやAIスマホを使う場面が増えるほど、こうした料金設計は身近になっていく可能性があります。

AI機能を選ぶときは、「何ができるか」だけでなく、「どこまでがプラン内か」「重い使い方で追加負担があるか」も見るようにしましょう。
