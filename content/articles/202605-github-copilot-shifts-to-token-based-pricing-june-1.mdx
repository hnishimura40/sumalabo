\# GitHub Copilot、6月1日から「AI Credits」方式へ。トークン課金って何が変わる？

GitHub Copilotの料金体系が、2026年6月1日から変わります。

結論から言うと、\*\*AIにプログラミング作業を手伝ってもらうサービスが、「月額料金＋使った量に応じたクレジット消費」という形へ近づく変更\*\*です。

完全に月額プランがなくなるわけではありません。

月額プランには一定量のGitHub AI Creditsが含まれ、その範囲を超えるような重い使い方をする場合に、追加負担を意識する必要が出てきます。

GitHub Copilotを使っていない人が、今すぐ何か対応する必要はありません。

一方で、仕事や副業、個人開発でCopilotをよく使っている人は、今後は「月額料金」だけでなく、\*\*どのAI機能をどれくらい使うか\*\*も気にした方がよくなります。

\## 先に結論：普通の人はここだけ押さえればOK

今回のポイントは、次の3つです。

| ポイント   | 内容                                                     |

| ------ | ------------------------------------------------------ |

| 何が変わる？ | GitHub Copilotの一部機能が、GitHub AI Creditsという使用量ベースの仕組みへ移行 |

| いつから？  | 2026年6月1日から                                            |

| 何が大事？  | AIサービスが「定額で何でも使い放題」から、「重い使い方は追加負担」へ向かう流れとして重要          |

GitHubの公式ブログでは、2026年6月1日からGitHub Copilotのすべてのプランが使用量ベースの課金へ移行し、従来のプレミアムリクエストユニットがGitHub AI Creditsへ置き換わると説明されています。

ただし、すべての人が同じタイミング・同じ形で完全に切り替わるわけではありません。

Copilot ProまたはPro+の月額プラン利用者は2026年6月1日に自動移行しますが、年額プラン利用者は契約期間が終わるまでは従来のプレミアムリクエスト方式が維持される扱いです。

\## GitHub Copilotとは？

GitHub Copilotは、ざっくり言うと\*\*プログラミングを手伝ってくれるAIサービス\*\*です。

プログラマーやエンジニアがコードを書いているときに、

\* 次に書くコードを提案する

\* エラーの原因を一緒に考える

\* コードの意味を説明する

\* 修正案を出す

\* 複数のファイルを見ながら作業を手伝う

といったことができます。

名前に「GitHub」とある通り、主にソフトウェア開発の現場で使われるサービスです。

普通のスマホユーザーが毎日使うものではありませんが、アプリやWebサービスを作る側ではかなり重要なAIツールになっています。

最近のCopilotは、単に「次のコードを予測する補助ツール」から、\*\*AIがまとまった作業を進めるエージェント型のツール\*\*へ広がっています。

つまり、昔のように「ちょっと入力を助けてくれるAI」だけではなく、AIが複数のファイルを確認したり、修正案を出したり、ある程度まとまった作業を進めたりする方向に進んでいるということです。

\## 今回、何が変わるのか

これまでのGitHub Copilotでは、「プレミアムリクエスト」という考え方が使われていました。

かなり簡単に言うと、AIに頼んだ回数を一定のルールで数える方式です。

これが2026年6月1日からは、\*\*GitHub AI Credits\*\*という仕組みに置き換わります。

GitHub AI Creditsは、Copilotを使った量を数えるための単位です。

Copilotを使うと、AIに送った内容、AIが返した内容、AIが再利用する情報などが「トークン」として数えられます。

そして、そのトークン量と使ったAIモデルに応じて、GitHub AI Creditsが消費されます。

\## 「トークン」って何？

トークンという言葉は少し難しく聞こえますが、ここでは\*\*AIが読み書きする文字やコードの細かい単位\*\*くらいに考えると分かりやすいです。

たとえば、AIに短い質問をするだけなら、使うトークンは少なめです。

一方で、

\* 長いコードを全部読ませる

\* 大きなファイルを何個も確認させる

\* AIに長い修正案を書かせる

\* 何度もやり取りしながら作業させる

\* 高性能なAIモデルで複雑な作業をさせる

と、使うトークンは増えやすくなります。

つまり新しい仕組みでは、\*\*AIにちょっと相談する使い方と、AIにがっつり作業を任せる使い方で、消費する量が変わる\*\*ということです。

> ひまり：

> 「AIに少し質問するのと、AIに長時間作業してもらうのでは、料金の重さが変わるってこと？」

>

> らぼまる：

> 「そうだね。これからは“AIをどれだけ働かせたか”が、料金に反映されやすくなると考えると分かりやすいよ。」

\## 「従量課金」ってどういう意味？

従量課金とは、\*\*使った量に応じて料金が変わる仕組み\*\*です。

身近な例でいうと、電気代や水道代に近い考え方です。

たくさん使えば負担が増え、あまり使わなければ少なく済みます。

ただし、GitHub Copilotの場合は、完全に月額料金がなくなるという話ではありません。

イメージとしては、\*\*月額プランに一定量のAI Creditsが含まれ、それを超える使い方をする場合は追加の負担が発生しうる\*\*という形です。

GitHubの公式ブログでは、基本料金は据え置きとされています。

Copilot Proは月額10ドル、Pro+は月額39ドル、Businessは1ユーザー月額19ドル、Enterpriseは1ユーザー月額39ドルのままです。

\## AI Creditsは「AI用のポイント」のようなもの

GitHub AI Creditsは、すごく簡単に言えば\*\*CopilotでAIを使うためのポイント\*\*のようなものです。

ただし、買い物のポイントというよりは、料金計算のための単位です。

GitHub Docsでは、1 AI Creditは0.01ドル相当と説明されています。

Copilot Proには月1,000 AI Credits、Copilot Pro+には月3,900 AI Creditsが含まれる形です。

| プラン          | 月額料金 | 含まれるAI Creditsの目安 |

| ------------ | ---: | ----------------: |

| Copilot Pro  | 10ドル |  1,000 AI Credits |

| Copilot Pro+ | 39ドル |  3,900 AI Credits |

このAI Creditsは、Copilot ChatやCopilot CLI、Copilotクラウドエージェント、Copilot Spaces、Spark、サードパーティのコーディングエージェントなどで消費されます。

一方で、すべてのCopilot利用がAI Creditsの対象になるわけではありません。

ここが今回のニュースで大事なところです。

\## コード補完だけなら、すぐ大きな負担増とは限らない

今回のニュースで不安になりやすいのが、

「Copilotを少し使うだけでも、すぐ追加料金がかかるの？」

という点です。

ここは少し落ち着いて見る必要があります。

GitHubの説明では、\*\*コード補完\*\*と\*\*Next Edit Suggestions\*\*は、引き続きすべての有料プランに含まれ、AI Creditsを消費しません。

コード補完とは、コードを書いている途中に「次はこう書くのでは？」とAIが提案してくれる機能です。

Next Edit Suggestionsは、次に編集しそうな場所や内容を提案する機能です。

つまり、Copilotを主に「入力補助」として軽く使っている人は、すぐに大きな負担増になるとは限りません。

一方で、Copilot Chatで長く相談したり、AIエージェントに複数ファイルの修正を任せたり、高性能モデルを使って複雑な作業をさせたりする場合は、AI Creditsの消費を意識する必要があります。

\## クレジットを使い切ったらどうなる？

ここも気になるところです。

AI Creditsを使い切った場合、知らないうちに無制限で高額請求され続ける、というよりは、追加で使うための予算を設定するか、次の月のリセットを待つ形になります。

スマホでたとえるなら、毎月のデータ容量に少し近いです。

決められた範囲内ならそのまま使えますが、たくさん使う人は追加の容量や上限設定を気にする必要が出てきます。

そのため、Copilotをよく使う人ほど、

\* 月内にどれくらいAI Creditsを使っているか

\* 追加利用の予算を設定するか

\* 軽い作業には軽量モデルを使うか

\* 重い作業をAIに任せすぎていないか

を確認しておくと安心です。

\## どんな人に影響が大きい？

今回の変更で影響が大きそうなのは、次のような人です。

| 人・使い方                     | 影響                     |

| ------------------------- | ---------------------- |

| Copilotをほぼコード補完だけに使う人     | 影響は比較的小さい可能性           |

| Copilot Chatで長いやり取りをよくする人 | AI Creditsの消費を気にした方がよい |

| AIエージェントに複数ファイルの作業を任せる人   | 消費が増えやすい               |

| 高性能モデルをよく使う人              | モデルによってコスト差が出やすい       |

| 会社で多人数がCopilotを使っている場合    | 予算管理が重要になる             |

やり取りのコストは、「使うモデル」と「使われるトークン数」の2つで変わります。

軽いチャットなら少ないクレジットで済む場合があります。

一方で、複数ファイルをまたぐ長いエージェント作業では、より多くのクレジットを消費しやすくなります。

\## 個人ユーザーが確認したいこと

Copilot ProやPro+を個人で使っている人は、まず次の点を確認しておくと安心です。

\* 自分が月額プランか年額プランか

\* Copilot Chatをどれくらい使っているか

\* AIエージェント機能を使っているか

\* 高性能モデルをよく使っているか

\* 6月以降の推定コストがどう変わるか

毎日Copilotを使っている人は、6月に入ってから慌てるより、事前に利用状況を確認しておく方が安心です。

特に、年額プランを使っている人は、月額プランの人とは切り替わるタイミングが異なる可能性があります。

自分の契約がどうなっているかは、GitHub側の請求画面や公式案内で確認しておきたいところです。

\## 会社で使っている場合は、さらに注意

会社やチームでGitHub Copilotを使っている場合は、個人利用よりも影響が大きくなる可能性があります。

理由はシンプルです。

1人あたりの利用量が少し増えるだけでも、人数が多いと合計の消費が大きくなるからです。

企業やチームでは、

\* 誰がどれくらい使っているか

\* どの機能でAI Creditsを消費しているか

\* 追加利用をどこまで許可するか

\* 高性能モデルを自由に使わせるか

\* 予算上限をどう設定するか

を決めておく必要が出てきます。

特に、AIエージェントを使った長時間の作業や、複雑なコードレビューを大量に行うような使い方では、従来よりもコストが見えやすくなる一方で、管理も重要になります。

\## 普通の人にはどう関係するのか

「GitHub Copilotを使っていないから、自分には関係ない」と思う人も多いはずです。

直接的には、その通りです。

GitHub Copilotは主に開発者向けのサービスなので、スマホを普通に使っているだけの人が、今すぐ何か設定を変える必要はありません。

ただし、今回の話は\*\*AIサービス全体の流れ\*\*として見ると重要です。

最近のAIは、単に質問に答えるだけではなく、

\* コードを書く

\* 長い資料を読む

\* 文章を作る

\* 画像や動画を生成する

\* パソコン上の作業を代行する

\* 複数ステップの作業を自動で進める

という方向に進んでいます。

便利になる一方で、AIを動かすには大きな計算コストがかかります。

そのため、今後は「月額料金を払えば何でも無制限に使える」というより、\*\*軽い使い方はプラン内、重い使い方は追加負担\*\*という設計が増える可能性があります。

これは、将来的にはスマホのAI機能やAIアプリを選ぶときにも関係してくるかもしれません。

たとえば、

\* 端末内で処理する軽いAI

\* クラウド上の高性能AIを使う機能

\* 長時間の作業を任せるAI

\* 画像・動画生成のように重いAI

で、料金や利用回数に差が出る可能性があります。

\## 「悲報」と言い切っていいのか

今回の変更は、使う人によって受け止め方が変わります。

たしかに、これまでCopilot Chatやエージェント機能をたくさん使っていた人から見ると、\*\*同じ月額料金でも使える量を気にする必要が出てくる\*\*ため、不満が出やすい変更です。

一方で、GitHub側は、簡単な質問と数時間にわたる自律的なコーディング作業が同じコストとして扱われる従来の仕組みは持続しにくくなっていたと説明しています。

使用量ベースにすることで、実際の利用量に料金を連動させる狙いがあります。

つまり、これは単なる「値上げ」や「改悪」とだけ見るより、\*\*AIが本格的に作業を代行する段階に入り、料金の考え方も変わり始めたニュース\*\*として見るのが分かりやすいです。

\## まだ分からないこと

現時点で注意したいのは、実際の負担感は人によってかなり変わることです。

まだ見えにくい点としては、

\* 普通の個人開発者がどれくらいでAI Creditsを使い切るのか

\* 高性能モデルを日常的に使うと月額内に収まるのか

\* 企業利用でどれくらい追加費用が出るのか

\* 利用者が軽量モデルと高性能モデルをどう使い分けるのか

\* 他のAI開発ツールも同じ方向へ進むのか

といった点があります。

特に、実際の請求額は「どの機能を、どのモデルで、どれくらい使うか」によって変わります。

そのため、すべての人に対して「必ず高くなる」「必ず安くなる」と断定するのは早いです。

\## 今すぐやるべき人、様子見でいい人

今回のニュースをどう受け止めればいいかを整理すると、次のようになります。

| タイプ                | 判断                             |

| ------------------ | ------------------------------ |

| Copilotを使っていない人    | 今すぐ対応不要。AIサービスの料金変化として知っておけばOK |

| たまにCopilotを使う人     | 6月以降の利用状況を軽く確認                 |

| Copilot Chatを毎日使う人 | AI Creditsの消費とモデル選びを確認         |

| AIエージェントに作業を任せている人 | 料金影響が大きくなる可能性あり                |

| 会社で導入している人         | 予算上限・利用ルールを決めておきたい             |

普通の人向けに言うなら、今回のニュースはGitHub Copilotだけの話で終わりません。

AIが「ちょっと便利な補助機能」から「実際に作業をこなす道具」になるほど、使い方によって料金差が出やすくなります。

これからAIサービスを選ぶときは、月額料金だけでなく、

\* 何がプラン内で使えるのか

\* どこから追加料金になるのか

\* 重いAI機能に制限があるのか

\* 自分の使い方だと足りるのか

\* 使いすぎを防ぐ設定があるのか

を見ることが大事になりそうです。

\## まとめ：AIは便利になるほど、料金の見方も変わっていく

GitHub Copilotの使用量ベース課金への移行は、一見すると開発者向けのニュースです。

でも本質は、\*\*AIが便利になるほど、料金体系も「どれだけ使ったか」を反映する方向へ進んでいる\*\*ということです。

Copilotを使っていない人は、慌てる必要はありません。

ただ、AIサービス全体で見ると、「月額だけ見れば安心」とは言い切れない時代に入りつつあります。

これからは、AI機能を選ぶときに、

\* 軽い使い方なら無料・定額で足りるのか

\* 高性能なAIは追加料金になるのか

\* 長時間の自動作業に制限があるのか

\* 自分の使い方に合ったプランなのか

を確認することが大切です。
