Pixel 11に搭載されるとみられるGoogleの次世代チップ「Tensor G6」について、少し気になる情報が出ています。

話題になっているのは、「かなり新しい世代のチップになりそう」という期待と、「でもゲーム性能はそこまで伸びないかもしれない」という不安が同時に出ていることです。

スマホのチップというと、専門用語が多くて一気に難しく見えます。

今回のTensor G6のリークは、この中でも特に「Pixel 11はAIや電池持ちには期待できそうだけど、ゲーム性能はどこまで期待していいのか」という点がポイントになります。

## 何が話題になっているのか

海外メディアのAndroid Authorityは、Googleの次期独自チップとみられる「Tensor G6」の詳細スペックに関するリーク情報を報じています。

情報の出どころとして挙げられているのは、TelegramチャネルのMystic Leaksです。つまり、Googleが正式に発表した仕様ではなく、現時点ではあくまでリーク情報です。

報道によると、Tensor G6はPixel 11シリーズ向けのチップとみられ、コードネームは「Malibu」。製造プロセスはTSMCのN2、いわゆる2nm世代になる可能性があるとされています。

ここだけ聞くと、かなり前向きなニュースに見えます。

TSMCのN2は、スマホやAI向けチップで注目される新世代の製造技術です。数字だけで単純比較はできませんが、一般的には製造プロセスが進むほど、同じ処理をより少ない電力でこなしやすくなります。

つまり、Tensor G6が本当にN2世代になるなら、Pixel 11では発熱や電池持ちの改善に期待できるかもしれません。

一方で、今回のリークで引っかかるのがGPUです。

GPUは、ゲームや3Dグラフィック、重い映像処理に関わる部品です。Android Authorityは、Tensor G6のGPUがImagination TechnologiesのPowerVR CXT系に由来する可能性を伝えており、Tensor G5からグラフィック性能が大きく伸びない可能性を指摘しています。

PowerVR CXT系は、2021年に発表されたGPU IPに関係する名前です。そのため、「新しい2nmチップなのに、GPUの土台は少し古いのでは？」という見方が出ています。

ただし、ここで大事なのは、まだ正式発表ではないということです。

この時点で「Pixel 11はゲームに弱い」と決めつけるのは早いです。GPUの名前だけで実際の性能がすべて決まるわけではなく、クロック、メモリ、冷却、ソフトウェア最適化、ゲーム側の対応などでも体感は変わります。

## Tensorとは何か。Pixelの中の「頭脳」のこと

Tensorは、GoogleがPixel向けに設計している独自チップです。

スマホの中には、アプリ操作、写真処理、通信、AI処理、ゲーム描画などをまとめて動かす中心部品があります。専門的にはSoCと呼ばれます。

SoCは「System on a Chip」の略で、スマホのいろいろな機能を1つのチップにまとめたものです。

普通の人向けに言えば、スマホの「頭脳」と考えると分かりやすいです。

<div class="table-card">

| 用語        | 短く言うと          | 普通の人への影響              |
| --------- | -------------- | --------------------- |
| SoC       | スマホの中心チップ      | スマホ全体の快適さに関係する        |
| CPU       | 基本処理をする部分      | アプリ起動、画面操作、ブラウジングの快適さ |
| GPU       | 映像や3D表示を処理する部分 | ゲーム、動画編集、なめらかな表示      |
| TPU / NPU | AI処理を助ける部分     | 音声認識、翻訳、写真補正、生成AI機能   |
| ISP       | カメラ画像を処理する部分   | 写真や動画の仕上がり            |
| モデム       | 通信を担当する部分      | 5G通信、電波のつかみ、通信時の電池持ち  |
| TSMC      | チップを作る大手メーカー   | チップの製造品質や省電力性に関係する    |

</div>

PixelのTensorシリーズは、単純に「ベンチマークの数字で最強」を狙うチップというより、GoogleのAI機能やカメラ機能をPixel上で動かすためのチップという色が強いです。

たとえば、写真の補正、音声認識、通話まわりの便利機能、翻訳、オンデバイスAIなど、Googleらしい機能をスマホ本体の中で動かすことが重視されています。

そのため、Pixelは昔から「ゲーム性能だけで選ぶスマホ」というより、「GoogleのAIやカメラ、Androidの新機能を使いやすく体験するスマホ」という位置づけに近いです。

今回のTensor G6リークも、このPixelらしい方向性の延長として見ると理解しやすくなります。

## 2nmとは何か。小さい数字だから絶対すごい、ではない

今回のリークで目立つのが「TSMC N2」、つまり2nm世代の製造プロセスになる可能性です。

2nmと聞くと、「数字が小さいほどすごいんでしょ？」と思うかもしれません。

大きく外れてはいません。

半導体では、世代が進むほど、同じ面積により多くの回路を詰め込めたり、同じ処理をより少ない電力でこなせたりする可能性があります。TSMCも公式に、N2では性能や消費電力の面で前進する技術だと説明しています。

ただし、ここで注意したいのは、「2nmだから必ずスマホの電池持ちが劇的に伸びる」とは言い切れないことです。

スマホの電池持ちは、チップだけで決まりません。

画面の明るさ、バッテリー容量、通信環境、カメラ処理、AI機能、OSの制御、冷却設計など、いろいろな要素が関係します。

たとえば、チップ自体が省電力になっても、より重いAI機能を常に動かす設計になれば、体感の電池持ちは思ったほど伸びないこともあります。逆に、チップの効率が良くなり、発熱が減り、OS側の制御もうまくいけば、普段使いでかなり快適になる可能性もあります。

つまり、2nm化は期待材料ではありますが、それだけでPixel 11の良し悪しを決める材料ではありません。

<p><strong>2nm：</strong>チップの製造世代を表す言葉。数字が小さいほど新しい世代を指すことが多いですが、実際の快適さはスマホ全体の設計で決まります。</p>
<p><strong>TSMC：</strong>Apple、AMD、NVIDIA、Googleなどの先端チップ製造でも名前が出る台湾の大手半導体メーカーです。</p>

Pixelシリーズは、過去に発熱や電池持ちで評価が分かれることもありました。

その意味では、Tensor G6が本当にTSMCのN2世代になるなら、Pixel 11にとってはかなり重要な前進になる可能性があります。

## GPUが古いと言われると、何が困るのか

今回のリークで不安視されているのは、GPUの部分です。

GPUは、映像や3Dグラフィックを処理する部品です。普通の使い方ではあまり意識しませんが、重いゲームや動画編集、3D表示ではかなり重要になります。

たとえば、次のような使い方をする人はGPU性能の影響を受けやすいです。

<div class="check-box">
<p class="box-label">GPU性能を気にした方がいい人</p>

* 原神、崩壊：スターレイル、鳴潮などの重い3Dゲームをよく遊ぶ人
* 高画質設定や高フレームレートでゲームをしたい人
* 長時間ゲームをして、発熱やカクつきが気になる人
* スマホを数年使い、将来のゲームにもある程度対応したい人
* 動画編集や重いグラフィック処理をスマホで行う人

</div>

一方で、SNS、LINE、YouTube、ブラウザ、カメラ、地図、キャッシュレス決済が中心なら、GPU性能の差を毎日強く感じる場面はそこまで多くないかもしれません。

もちろん、GPUが強いに越したことはありません。

ただ、普通の使い方では、GPUよりも電池持ち、発熱、カメラ、通信の安定性、アプリの起動速度、OSアップデートの長さの方が満足度に直結することも多いです。

今回のリークでは、Tensor G6のGPUがPowerVR CXT系に由来する可能性があるとされています。PowerVRはGPUのブランド名の1つです。

スマホ向けGPUでは、Androidでよく見るAdreno、Mali、PowerVRなど、いくつかの系統があります。

AdrenoはQualcommのSnapdragonでよく使われるGPUです。
MaliはArm系のチップでよく見かけるGPUです。
PowerVRはImagination TechnologiesのGPUブランドです。

今回のTensor G6で話題になっているのは、MaliではなくPowerVR系のGPUです。

ここが少しややこしいのですが、「GPUの名前が何か」だけで性能が決まるわけではありません。同じ系統でも、構成、クロック、メモリ帯域、冷却、ソフトウェア最適化で実際の性能は変わります。

それでも、2021年世代のCXT系に由来する可能性があると聞くと、最新のハイエンドAndroidと比べてゲーム性能に不安が出るのは自然です。

## 「古いGPUベース＝Pixel 11はダメ」とは言い切れない

ここで一番大事なのは、GPUの話だけでPixel 11全体を評価しないことです。

スマホの体感性能は、GPUだけでは決まりません。

普段使いの快適さにはCPUやメモリ、ストレージ、OSの最適化が関係します。写真や動画にはISPやAI処理が関係します。音声認識、翻訳、文字起こし、写真補正などにはTPUやNPUのようなAI処理部分が関係します。

Pixelの場合、特にこの「AI処理」と「カメラ処理」が重要です。

GoogleはTensor G5でも、AI機能、オンデバイス処理、Pixel独自機能、カメラ体験などを強く打ち出していました。Tensor G6でもその流れが続くなら、Googleは「ゲーム性能で最強になること」よりも、「AIやカメラを日常で便利に使えること」を優先している可能性があります。

これは、悪いこととは限りません。

たとえば、ゲームをほとんどしない人にとっては、GPU性能が多少控えめでも、写真がきれいに撮れて、翻訳や文字起こしが便利で、発熱が少なく、電池持ちが良い方が満足度は高いかもしれません。

ただし、高価格帯のスマホとして見ると話は別です。

Pixel 11がハイエンドモデルとして登場するなら、多くの人は「カメラもAIも良くて、ゲーム性能もそれなりに強い」ことを期待します。

高いスマホなのに、重いゲームで競合ハイエンドに大きく負けるなら、ゲーム重視の人には選びにくくなります。

つまり今回の話は、「Pixel 11がダメ」というより、「Pixel 11が誰に向くスマホになるのかを見極める材料」と考えるのがちょうどよさそうです。

ゲーム性能は、スペック表やリークだけでは分かりません。実際に30分以上プレイしても安定するのか。発熱した後に性能が落ちないのか。高画質設定でカクつかないのか。ゲーム側の最適化は十分なのか。

だから、ゲーム重視の人は「Pixel 11が出たらすぐ予約」ではなく、実機レビューを待つ方が安全です。

## すまラボ的な見方

すまラボ的には、今回のTensor G6リークは「Pixel 11が失敗するかどうか」という話ではなく、「GoogleがPixelで何を優先しているのか」が見えてくる話だと考えます。

Pixelは、スペック表の数字だけで勝負するスマホではありません。

GoogleのAI、カメラ処理、Androidの新機能、長期アップデート、Googleサービスとの相性をまとめて体験として出すスマホです。

そのため、Tensor G6でも、Googleはゲーム性能の最大化より、AI処理、電池持ち、発熱、カメラ、コストのバランスを優先している可能性があります。

この方向性は、普通の人にとっては悪くないかもしれません。

スマホで一番よく使うのは、ゲームではなく、カメラ、SNS、ブラウザ、動画、地図、決済、メッセージという人も多いからです。

ただし、ゲーム重視の人にとっては、GPU性能の伸びが小さい可能性は無視できません。

特に、ハイエンドスマホを買う理由が「重いゲームを快適に遊びたい」なら、Pixel 11だけを見て決めるより、Snapdragon搭載の高性能Androidや、他社のゲーミング寄りモデルも比較した方が安心です。

大切なのは、Pixel 11を「良い・悪い」で単純に判断しないことです。

Pixel 11が目指している方向と、自分の使い方が合うかどうか。

ここを見れば、今回のリークもかなり実用的な判断材料になります。
